> [!note]- 书籍简介\
> 豆瓣内容简介称"中国证券教父阚治东的人生是中国股市 20 年沉浮的一个缩影"。书分上海篇与深圳篇：上海篇写证券业务部诞生、国库券买卖、股票黑市、申银证券成立、上交所成立、万人抢购新股、申银万国合并与深沪金融中心之争；深圳篇写深创投、南方证券的窟窿，以及他因"涉嫌操纵股价"被捕、羁押 21 天的经历（这段约占全书三分之一篇幅）。

> [!warning] 本笔记的性质
> 这是**资料整理型笔记，尚未通读原书**。以下判断来自该书目录与试读章节、2010 年前后的媒体报道，以及豆瓣 524 条短评 / 83 篇书评。个人体会待读完后补充。

## 一句话结论

**8.3 分是"史料分"，不是"写作分"。** 这本书是极少数由当事人亲笔写就的中国资本市场早期内部记述，信息密度高、可读性好；但它最大的毛病恰恰来自同一个地方——**立场单一，辩解太多**。看它写"事情怎么发生的"很值，看它写"责任该谁负"要打折扣。

## 二、这本书写了什么

时间跨度约 1986—2007，几乎覆盖中国资本市场从无到有的全过程。

| 时间 | 事件 |
|---|---|
| 1979 | 进入中国人民银行上海分行，后转入工商银行上海宝山区分行 |
| 1987 秋 | 赴日本研修证券一年（据书中第一章自述） |
| 1980s 末 | 任工商银行上海信托投资公司副总经理，主管证券与投资；旗下**静安证券业务部是中国第一个证券业务部**；利用外地国债价格低于上海的差价跨地区买卖，把国债做活 |
| 1990 | 出任申银证券总经理（注册资本 3000 万元）；同年 12 月 19 日上交所开业 |
| 1992 | 申银改制增资扩股，成为全国第一家股份制证券公司 |
| 1995-02-23 | **327 国债期货事件**：万国证券巨亏 13 亿元、管金生入狱、尉文渊请辞；申银因自营部经理不敢擅自做空而幸免 |
| 1996 | 申银与万国合并为申银万国，出任总裁（他向市政府提议合并以化解万国困局） |
| 1997 | **陆家嘴事件**：沪深金融中心之争，申银万国被罚款并暂停股票自营业务 1 年，他被免去一切与证券市场有关的职务 |
| 1999 | 应深圳市政府邀请，任深圳创新科技投资公司（深创投）总裁，任内 34 家被投企业上市 |
| 2002 | 空降南方证券任总裁，上任后才发现"病入膏肓，已濒临破产" |
| 2003-12-08 | 深圳市委组织部批准其辞职 |
| 2006-03-02 | 在上海被捕，理由"涉嫌操纵股价"，羁押 21 天 |
| 2007 | 起诉被撤销；同年 9 月组建奥锐万嘉创投，后以东方汇富为核心布局多家基金 |

书里记下的几个细节，是别处看不到的：

- 被免职时，国务院秘书局有人捎话：**"我知道这件事与阚治东没多大关系，但是也只能这样了。"**
- 转到深圳看守所后，他遇到的狱友是原大鹏证券总裁徐卫国、原南方证券董事长刘波，他写道——**"如果把管金生、张国庆、陈浩武等人也关在这里，那么几乎可以开一次中国证券业的开创者大会了。"**
- 他自述创下的多个"第一"：主承销第一只 A 股、第一只 B 股，发行第一张金融债券、第一张企业短期融资券，设立第一个证券交易柜台，参与发起设立上交所，编制国内第一个股票指数和全国第一份股票年报。

## 三、写得好的地方

- **可读性远超预期**。[《中国经济周刊》的书评](https://www.ceweekly.cn/article/2010/0125/41612.html)说它"并不是一本历史书，而更像是故事书，虽然牵涉人物繁多、关系复杂却能够做到娓娓道来，实属难得"。
- **众生相写得准**。最受认可的一条短评：*"作者的境界于公于私都难称上乘，但是笔下的众生相还是让人读来哭笑叹皆不得也。"*（15 人有用）
- **制度细节的真实感**。读者普遍承认它"对股市投机也许一点用没有，但认识中国特色的资本市场倒是大有裨益"，有人直接称它是"一部中国股市、证券市场的编年史"（16 人有用）。

## 四、争议：差评几乎只说同一件事

| 好评 | 差评 |
|---|---|
| "让对中国证券业的起源、发展和中间波澜壮阔的改革史和权力斗争有更清晰和理性的认识" | *"书里只是给自己辩解，本来可以写得更好的。"* |
| "笔下的众生相让人读来哭笑叹皆不得也" | *"不喜欢这种很主观、很个人色彩浓厚的书……而不是将自己凸显，为自己辩解。"*（[书评《不客观》](https://book.douban.com/review/3113631/)） |
| "对认识中国特色的资本市场大有裨益" | *"上海篇写得还蛮不错，深圳篇已经变成了一种解释。"* |
| "一部中国股市、证券市场的编年史" | *"前半段不停感叹自己生不逢时，后半段就他祥林嫂了。"* |

其中最有洞察力的一篇书评，把缺点和价值说成了一回事（[《阚治东二十年股市人生 书写中国真实世界》](https://book.douban.com/review/2901642/)）：

> 正因为把自己的责任撇得太清，给人一种不真实感；然而从这本书中我反而看到了中国证券业乃至中国国有企业、中国官场的真实世界。

还有两条需要放在心上的提醒：多条短评在暗示**"那些没写的或被删掉的还不知道有多少"**；以及作者复出后与尉文渊合伙投资的**华锐风电**后来盈利腰斩、股价暴跌——书中那个自我定位，与后来的结果要分开看。

## 五、怎么读

| 目的 | 建议 |
|---|---|
| 学投资方法 | **别读**，读者共识是"对股市投机一点用没有" |
| 了解中国资本市场早期史 | **值得读**，但当作"一手材料"而非"信史" |
| 理解政商关系 / 国企困境 | 有参考价值，**必须交叉验证** |
| 时间有限 | 精读**上海篇** + 327 / 陆家嘴事件 / 南方证券三段，21 天羁押部分快读 |

> [!tip] 核心用法是对读
> 凡涉及**制度细节、事件经过、人物关系**的部分，它信息密度高、可信度不错；凡涉及**责任归属、自我评价**的部分，一律打折。差评说的不是它写错了，而是**它只写了一半**。

## 六、人物与事件速查

| 人物 | 身份 | 与本书的关系 |
|---|---|---|
| 管金生 | 万国证券总经理 | 327 事件主角，入狱；"上海滩证券三猛人"之一 |
| 尉文渊 | 上交所首任总经理 | 327 后请辞；后与作者合伙做创投 |
| 张国庆 | 原君安证券创始人 | 作者在看守所联想到的"开创者"之一 |
| 陈浩武 | 原湖北证券创始人 | 同上 |
| 徐卫国 | 原大鹏证券总裁 | 深圳看守所狱友 |
| 刘波 | 原南方证券董事长 | 深圳看守所狱友 |

关键事件三条线：**327 国债期货事件**（1995，万国出局、申银幸免）→ **申银万国合并**（1996）→ **陆家嘴事件**（1997，沪深金融中心之争，作者出局）；后半程则是 **南方证券破产**（2004 前后行政接管）与其后的 21 天羁押。

据豆瓣条目：`序言` / `上海篇`（第一章 东渡日本：母亲让我走上证券生涯、"洋插队"的生活、收获梦想；第二章 筚路蓝缕：新的岗位、国债交易、股票黑市交易的兴起）/ 其余章节豆瓣未展开；试读章节另见 **更大舞台**、**南征北战**。
