# 查找所有已经删除但是还在占用空间的文件
`lsof +L1` 是一个用于列出当前系统中所有被删除但仍被进程占用的文件的命令。具体来说：

- **`lsof`**：表示 "list open files"，用于显示当前打开的文件及其相关信息。
- **`+L1`**：这个选项表示列出所有链接计数为 1 的文件，即那些已经被删除但仍被某个进程打开的文件。

### 具体功能

- **链接计数**：文件的链接计数表示有多少个硬链接指向该文件。当链接计数为 0 时，文件会被系统完全删除。链接计数为 1 的文件表示文件已经被删除，但仍然有一个进程在使用它。
- **用途**：这个命令可以帮助系统管理员识别和管理那些被删除但仍占用磁盘空间的文件，便于进行后续的清理或处理。

### 示例输出

执行 `lsof +L1` 后，你可能会看到类似以下的信息：

```
COMMAND   PID USER   FD   TYPE DEVICE SIZE/OFF   NODE NAME
mysqld  3499110 mysql  10u  REG  8,1  12345678 123456 /path/to/deleted_file (deleted)
```

在这个输出中，`mysqld` 是进程名，`/path/to/deleted_file` 是被删除的文件路径，`(deleted)` 表示该文件已被删除但仍在使用中。

### 总结

使用 `lsof +L1` 可以有效地帮助你查找和管理被删除但仍占用空间的文件。
