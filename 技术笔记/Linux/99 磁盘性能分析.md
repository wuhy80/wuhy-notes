# Ubuntu
在 Ubuntu 系统上，你可以使用多种工具来监控磁盘 IO 的使用情况，以确定是否存在磁盘瓶颈。以下是一些常用的工具和命令：

## iostat
`iostat` 是一个常用的工具，用于报告CPU统计信息和所有磁盘的输入/输出统计信息。你可以使用 `iostat` 来查看磁盘的读写速度、等待时间和服务时间等。

安装 `iostat`（如果尚未安装）：
```bash
sudo apt-get install sysstat
```
使用 `iostat` 查看磁盘 IO 统计信息：
```bash
iostat -xm 2
```
这个命令会每2秒更新一次磁盘统计信息，并显示扩展信息（`-x`）和以MB为单位的数据（`-m`）。

![image.png](https://wuhy-1258420163.cos.ap-shanghai.myqcloud.com/obsidian/images/2024/group_1/202405100947620.png)

## iotop
`iotop` 是一个类似于 `top` 的工具，用于实时监控各个进程的磁盘 IO 使用情况。

安装 `iotop`：
```bash
sudo apt-get install iotop
```

使用 `iotop`：
```bash
sudo iotop -o
```
这个命令会显示当前正在执行磁盘 IO 的进程，并按 IO 使用率排序。
![image.png](https://wuhy-1258420163.cos.ap-shanghai.myqcloud.com/obsidian/images/2024/group_1/202405100948731.png)

## dstat
`dstat` 是一个多功能系统资源统计工具，可以用来替代 `vmstat`、`iostat` 和 `ifstat` 等工具。

安装 `dstat`：
```bash
sudo apt-get install dstat
```

使用 `dstat` 查看磁盘 IO 统计信息：
```bash
dstat --disk
```
这个命令会显示每个磁盘的读写速度。
![image.png](https://wuhy-1258420163.cos.ap-shanghai.myqcloud.com/obsidian/images/2024/group_1/202405100948445.png)

## sar
`sar` 是 `sysstat` 包的一部分，可以用来收集、报告或保存系统活动信息。

使用 `sar` 查看磁盘 IO 统计信息：
```bash
sar -d 1 5
```
这个命令会每 1 秒收集一次磁盘活动信息，共收集 5 次。
![image.png](https://wuhy-1258420163.cos.ap-shanghai.myqcloud.com/obsidian/images/2024/group_1/202405100949948.png)

## atop
`atop` 是一个全屏的性能监控工具，可以显示系统资源的使用情况，包括磁盘 IO。

安装 `atop`：
```bash
sudo apt-get install atop
```

使用 `atop`：
```bash
sudo atop
```
![image.png](https://wuhy-1258420163.cos.ap-shanghai.myqcloud.com/obsidian/images/2024/group_1/202405100949697.png)

## nmon
`nmon` 是一个系统管理员、调谐器、基准测试人员和分析师使用的工具，用于监控 Linux 系统的性能。

安装 `nmon`：
```bash
sudo apt-get install nmon
```

使用 `nmon`：
```bash
nmon
```
![image.png](https://wuhy-1258420163.cos.ap-shanghai.myqcloud.com/obsidian/images/2024/group_1/202405100951080.png)

通过这些工具，你可以监控磁盘的读写速度、IOPS（每秒输入/输出操作数）、延迟等指标，从而判断是否存在磁盘瓶颈。如果磁盘的读写速度远低于磁盘的理论最大速度，或者 IOPS 和延迟非常高，那么可能存在磁盘瓶颈。此外，还可以检查是否有进程长时间占用大量磁盘 IO 资源，这可能是性能问题的根源。
