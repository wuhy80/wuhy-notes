## 如何让Ubuntu上面root可以远程登录

在 Ubuntu 上默认情况下，禁止了 root 用户的远程登录。为了让 root 用户可以进行远程登录，你可以按照以下步骤进行设置：

1. 使用一个普通用户登录到 Ubuntu 服务器。
    
2. 编辑 SSH 配置文件 `/etc/ssh/sshd_config`：
    
    ```
    sudo nano /etc/ssh/sshd_config
    ```
    
3. 在文件中找到以下行：
    
    ```
    #PermitRootLogin prohibit-password
    ```
    
4. 将其修改为：
    
    ```
    PermitRootLogin yes
    ```
    
5. 保存文件并退出编辑器。
    
6. 重启 SSH 服务，使配置更改生效：
    
    ```
    sudo service ssh restart
    ```
    

现在，你应该能够使用 root 用户通过 SSH 进行远程登录到 Ubuntu 服务器了。请注意，允许 root 用户进行远程登录可能增加系统的安全风险。因此，在启用远程 root 登录之前，请确保你已经采取了适当的安全措施来保护服务器。

## **Ubuntu 22.04 版本中设置静态IP**

在Ubuntu 20.04中设置静态IP的步骤如下：

1. 打开终端并输入以下命令以编辑网络配置文件：
    
    ```
    sudo vim /etc/netplan/00-installer-config.yaml
    ```
    
2. 文件中应该有以下内容：
    
    ```
    network:
      ethernets:
        enp4s0f2:
          dhcp4: true
      version: 2
    ```
    
    其中“enp0s3”是网卡的名称
    
3. 将内容替换为：
    
    ```
    network:
      ethernets:
        enp4s0f2:
          dhcp4: false
          addresses: [192.168.1.100/24]
          optional: true
          routes:
            - to: default
              via: 192.168.1.1
          nameservers:
            addresses: [192.168.1.1]
      version: 2
    ```
    
4. 保存并关闭文件。
    
5. 输入以下命令以应用更改：
    
    ```
    sudo netplan apply
    ```
    
6. 确认静态ip是否设置成功：
    
    ```
    ip addr show enp4s0f2
    ```
