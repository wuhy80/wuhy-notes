# Obsidian 结合豆瓣使用

通过豆瓣插件，可以在 Obsidian 中管理你的书籍、电影等收藏，并使用 Dataview 进行统计分析。

## 例:显示所有图书
下面这段命令用dataview建立一个表格，展示所有图书信息：
````text
```dataview
TABLE without id
    “![bookcover|50]("+封面+")” AS “封面”,
    file.link as “书名”,
    作者,
    出版社,
    elink(豆瓣页面, string(豆瓣评分)) AS “豆瓣评分”,
    总页数,
    (date(读完时间) - date(开始时间)) AS 阅读用时,
    阅读状态 + " " + round(已读页数/总页数, 3)*100 + "%" AS “阅读进度”,
    我的评级,
    定价,
    买入价,
    round((买入价/定价), 2) AS “折扣”,
    date(购买时间) AS “购买时间”,
    购买渠道 AS “平台”, 
    file.etags AS “标签”
FROM “藏书/纸质书籍”
Sort 购买时间 desc
```
````

## 例: 执行统计功能
````text
```datavieww
    Table 
        rows.file.link AS 书单,
        rows.定价 As 定价,
        rows.买入价 AS 花费,
        length(rows) as 数量, 
        round(sum(rows.买入价),2) as 总花费,
        round(sum(rows.买入价)/sum(rows.定价), 2) as 总折扣
    From “藏书/纸质书籍”
    Group by dateformat(购买时间, "yyyy-MM") as “购买时间（月）”
    Sort 购买时间 Desc
```
````
