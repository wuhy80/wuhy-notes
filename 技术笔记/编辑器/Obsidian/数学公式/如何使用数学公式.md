在 Obsidian 中，可以使用 LaTeX 语法来表示数学公式。Obsidian 支持 Markdown，并且内置了对 LaTeX 公式的支持，以下是具体的方法：

### 行内公式
使用美元符号（`$`）包围行内公式。例如：

```
这是一个行内公式：$E=mc^2$。
```

显示效果：这是一个行内公式：$E=mc^2$。

### 块级公式
使用双美元符号（`$$`）包围块级公式。例如：

```
$$
E = mc^2
$$
```

显示效果：

$$
E = mc^2
$$

### 复杂公式示例
以下是一些复杂的公式示例：

#### 行内公式
```
行内公式：$a^2 + b^2 = c^2$。
```

显示效果：行内公式：$a^2 + b^2 = c^2$。

#### 块级公式
```
$$
\begin{aligned}
a^2 + b^2 &= c^2 \\
x &= \frac{-b \pm \sqrt{b^2-4ac}}{2a}
\end{aligned}
$$
```

显示效果：

$$
\begin{aligned}
a^2 + b^2 &= c^2 \\
x &= \frac{-b \pm \sqrt{b^2-4ac}}{2a}
\end{aligned}
$$

### LaTeX 基础语法

- **分数**：`\frac{a}{b}`
- **平方根**：`\sqrt{x}`
- **求和**：`\sum_{i=1}^n i`
- **积分**：`\int_{a}^{b} f(x) \,dx`
- **上下标**：`a_i, b^2`
- **矩阵**：
  ```
  \begin{pmatrix}
  a & b \\
  c & d
  \end{pmatrix}
  ```

### 示例
行内公式和块级公式的组合示例：

```
这是一个行内公式：$x = \frac{-b \pm \sqrt{b^2-4ac}}{2a}$。

这是一个块级公式：
$$
\sum_{i=1}^n i = \frac{n(n+1)}{2}
$$
```

显示效果：

这是一个行内公式：$x = \frac{-b \pm \sqrt{b^2-4ac}}{2a}$。

这是一个块级公式：

$$
\sum_{i=1}^n i = \frac{n(n+1)}{2}
$$

通过这些方法，你可以在 Obsidian 中轻松地表示各种数学公式。


在 Obsidian 中，默认的 LaTeX 公式字体大小无法直接调整。但是，你可以通过一些变通的方法来调整公式的字体大小。以下是一些常见的方法：

### 使用 LaTeX 命令调整字体大小

你可以在公式内部使用 LaTeX 命令来调整字体大小。例如：

- `\tiny{}` - 极小的字体
- `\scriptsize{}` - 小的字体
- `\footnotesize{}` - 脚注大小
- `\small{}` - 小字体
- `\normalsize{}` - 正常字体
- `\large{}` - 大字体
- `\Large{}` - 更大字体
- `\LARGE{}` - 非常大字体
- `\huge{}` - 超大字体
- `\Huge{}` - 最大字体

### 示例

#### 行内公式

在行内公式中使用字体大小命令：

```markdown
行内公式：$\Large{E = mc^2}$。
```

显示效果：行内公式：$\Large{E = mc^2}$。

#### 块级公式

在块级公式中使用字体大小命令：

```markdown
$$
\Large{
E = mc^2
}
$$
```

显示效果：

$$
\Large{
E = mc^2
}
$$

### 组合示例

你可以将这些字体大小命令组合使用，以便调整公式的不同部分：

```markdown
这是一个组合示例：
$$
\Large{
\sum_{i=1}^n i = \frac{n(n+1)}{2}
}
$$

行内公式示例：$\Large{x = \frac{-b \pm \sqrt{b^2-4ac}}{2a}}$。
```

显示效果：

这是一个组合示例：

$$
\Large{
\sum_{i=1}^n i = \frac{n(n+1)}{2}
}
$$

行内公式示例：$\Large{x = \frac{-b \pm \sqrt{b^2-4ac}}{2a}}$。

### 使用 CSS 调整公式字体大小

如果你希望统一调整 Obsidian 中所有公式的字体大小，可以通过自定义 CSS 的方式来实现。你可以在 Obsidian 的设置中加载自定义 CSS 文件。以下是一个示例 CSS 代码：

```css
/* 调整行内公式字体大小 */
span.math {
    font-size: 1.5em; /* 调整为1.5倍大小 */
}

/* 调整块级公式字体大小 */
div.math {
    font-size: 1.5em; /* 调整为1.5倍大小 */
}
```

1. 创建一个名为 `obsidian.css` 的文件，并将上述 CSS 代码粘贴到文件中。
2. 将该文件放在Obsidian的配置文件夹中，一般位于 `<vault>/.obsidian/snippets/` 目录下。
3. 在 Obsidian 中，打开设置，找到“外观”选项，然后在“CSS Snippets”部分启用刚刚添加的 CSS 文件。

通过这些方法，你可以在 Obsidian 中更灵活地调整公式的字体大小。
