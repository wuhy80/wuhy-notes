## 核心方法：三步法

![[01-开场-算法刷题速成指南三步法.jpg]]

视频给出的刷题方案分三步：

1. **浏览路线图**——科技树式的刷题路径，梳理核心思路；
2. **配套题库**——按知识点归类题目，支持 ACM 模式；
3. **进阶章节**——覆盖更多算法思维。

定位上（"本站简介"页的表述）：**满分 100 分，无论基础如何，用最短时间打造 85 分的水平**——面向笔试/面试的应试型刷题，而不是竞赛。

## 一、刷题路线图 = 一棵科技树

![[02-刷题路线图-科技树全景.jpg]]

- 整个知识体系画成一张依赖图：**数组 → 链表 → 哈希 → 栈与队列 → 双指针（数组双指针/滑动窗口/二分搜索）→ 递归 → 二叉树 → 回溯/DFS → 分治/动态规划/BFS → 最短路径 → 堆/字典树/图**，含力扣 Hot 100。
- 每个节点有状态标记（绿=已完成、黄=进行中、灰=未学），学完自动点亮，整棵树的进度一目了然；左下角有"视频导读"和"报名打卡"。

## 二、节点详情三件套：教程 + 代码模板 + 习题

![[03-节点详情-前缀和的模板与习题.jpg]]

点击任意节点弹出侧栏，固定三段式：

- **教程**：讲解正文 + 前置知识链接（如"前缀和 6/9"进度、先修要求）；
- **代码模板**：该知识点的核心模板，多语言折叠（C++/Go/Java/JavaScript/Python），一键复制；
- **习题列表**：按状态打勾、区分力扣 CN/EN、附通过率与难度，做完即点亮节点。

视频里依次演示的节点包括：前缀和（370 区间添加/1109 航班预订统计/1094 拼车）、差分数组、设计（LRU/最小栈等）、图（环检测/拓扑排序/二分图判定/并查集/Dijkstra 各自成组）、深度优先搜索（200 岛屿数量、695 岛屿最大面积、494 目标和等，7/18）、动态规划（3/28，**核心 5 条 + 遍历过程中 8 条常见变形**：最长递增子序列、base case、0-1 背包、子数组问题、贪心、编辑距离、最长公共子序列等）、最短路径（743 网络延迟时间、1631 最小体力消耗路径、1514 概率最大的路径）。

![[04-节点详情-动态规划系列.jpg]]

每个节点侧栏还有一个 AI 按钮——**"直接用小拉 Code 解决题目"**（他们家的 AI 刷题助手，需小拉 Code 会员），即"AI 时代"的题解入口。

## 四、ACM 模式：核心代码与输入输出分离

![[07-ACM模式-核心代码与输入输出模板分离.jpg]]

以「和为 K 的子数组」演示题库的 ACM 模式：

- 题面明确给出**数据范围**与**输入格式/输出格式**（笔试题风格，而非力扣的核心代码模式）；
- 编辑器里代码被注释自动分成两段：`// -- core code template start --` 与 `end` 之间是**核心解题代码**（`class Solution`），之外自动生成 **ACM 输入输出外壳**（`Main` 类 + `Scanner` 逐行读入）；
- 测试用例直接给多组样例（如 `3 2 / 1 1 1 / 2 2 / 1 2 3 / 3 6 / 0 0 0`），可自定义用例后运行/提交。

价值：**力扣刷题习惯的是"填函数"，而校招笔试（牛客等）普遍是 ACM 模式**——从读输入、选容器到处理边界都要自己写。这套题库把核心逻辑与 IO 外壳分离，让你既能专注算法本身，又能按笔试标准练习。

## 五、配套插件与本地调试

![[08-Chrome插件集成-LeetCode热题100.jpg]]

- **Chrome 谷歌插件**：嵌入力扣页面，左侧多出"题目/探险模式/LearnBook/学习计划"栏，可追踪 LeetCode 热题 HOT 100 等官方题单的刷题进度（67303 人收藏的那份题单）；
- **vscode/cursor/JetBrains 编辑器插件**：把题单搬进 IDE，支持本地调试（视频演示了 IDE 的 PROBLEMS 面板批量挂题目）；不配置本地环境时，代码提交到力扣 API 在线评测；
- 另有"本站免登录登录"等便利功能，站点目录里专门有"起手学习工具使用指南"一节（配置 Chrome 插件、vscode/cursor 插件、JetBrains 插件）。

## 六、学习方法配套

![[09-本站简介-85分方法论.jpg]]

- **本站简介**：85 分定位 + 本站目录结构 + 按读者类型的阅读方法（应试读者走"递归学习计划"，在校生/找工作按需选路）；

- **打卡系统**：按天打卡、进度可视化、支持月度排名；还有华容道等**游戏化栏目**（用算法控制棋盘，附代码模板 `solveHuarongRoad(board, gameHandler)`）。

## 速刷工作流总结

1. 打开**路线图**看进度，挑一个未点亮的知识点节点；
2. 读节点**教程** → 背/抄**代码模板**（多语言）；
3. 做**习题列表**里的题（题库内直接做 ACM 模式，或用插件在力扣/本地 IDE 做）；
4. 卡住了用**小拉 Code**（AI）讲题/解题；
5. 做完节点点亮，打卡，沿科技树推进——"横向点亮所有能力"的路径管理。
