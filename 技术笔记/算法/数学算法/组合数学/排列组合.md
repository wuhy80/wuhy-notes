# 排列组合

## 📌 核心概念

- **排列（Permutation）**：从n个元素中取m个进行排列，**顺序重要**
- **组合（Combination）**：从n个元素中取m个，**顺序无关**

## 💻 基本公式

### 排列数

```
P(n, m) = n! / (n-m)!
        = n × (n-1) × ... × (n-m+1)
```

### 组合数

```
C(n, m) = n! / (m! × (n-m)!)
        = P(n, m) / m!
```

## 💡 组合数性质

### 1. 对称性
```
C(n, m) = C(n, n-m)
```

### 2. 递推公式（杨辉三角）
```
C(n, m) = C(n-1, m-1) + C(n-1, m)
```

### 3. 求和公式
```
C(n, 0) + C(n, 1) + ... + C(n, n) = 2^n
```

### 4. 范德蒙德恒等式
```
C(m+n, k) = Σ C(m, i) * C(n, k-i)
```

## Go 代码

```go
// 计算组合数
func combination(n, m int) int {
    if m > n || m < 0 {
        return 0
    }

    if m > n-m {
        m = n - m
    }

    result := 1
    for i := 0; i < m; i++ {
        result = result * (n - i) / (i + 1)
    }

    return result
}

// 杨辉三角
func generate(numRows int) [][]int {
    triangle := make([][]int, numRows)

    for i := 0; i < numRows; i++ {
        triangle[i] = make([]int, i+1)
        triangle[i][0], triangle[i][i] = 1, 1

        for j := 1; j < i; j++ {
            triangle[i][j] = triangle[i-1][j-1] + triangle[i-1][j]
        }
    }

    return triangle
}
```
