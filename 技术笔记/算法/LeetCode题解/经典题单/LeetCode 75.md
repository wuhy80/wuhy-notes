# LeetCode 75

> LeetCode 官方 Study Plan 中的 75 题路线，适合用作算法面试的第一轮系统训练。

## 📌 题单定位

LeetCode 75 的特点：

- 题量适中，适合 4-8 周完成
- 覆盖数组、字符串、链表、树、图、堆、二分、DP 等核心主题
- 难度以 Easy 和 Medium 为主，少量 Hard
- 更适合建立稳定的题型识别能力，而不是追求大题量

官方入口：

- [LeetCode 75 Study Plan](https://leetcode.com/studyplan/leetcode-75/)

## 🎯 推荐刷题方式

### 第一轮：顺序完成

目标是把题单完整刷完，重点记录：

- 第一眼能否识别题型
- 是否能写出基础解法
- 卡住的位置是思路、边界还是代码实现

### 第二轮：按专题复盘

建议按下面主题重新整理：

| 专题 | 重点能力 |
|------|----------|
| 数组与字符串 | 双指针、前缀和、滑动窗口 |
| 哈希表 | 频次统计、去重、快速查找 |
| 栈与队列 | 单调栈、模拟、括号匹配 |
| 链表 | 快慢指针、反转、删除节点 |
| 二叉树 | DFS、BFS、递归返回值 |
| 图 | BFS、DFS、连通性、拓扑排序 |
| 堆 | TopK、优先队列 |
| 二分查找 | 边界查找、二分答案 |
| 动态规划 | 状态定义、转移方程、空间优化 |

### 第三轮：错题重做

只重做这些题：

- 第一次完全没思路
- 看题解后才知道关键技巧
- 写代码时边界出错
- 过了但复杂度不是最优
