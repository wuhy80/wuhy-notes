# 算法模板

> [!summary] 模板不是用来背诵的，而是帮你在高压做题时快速把“状态、不变量、边界”搭起来。

## 🧭 模板怎么读

模板不是背代码，而是记住三个问题：

1. **这个模板维护了什么不变量**：例如二分维护“答案仍在搜索区间里”，单调栈维护“栈内元素保持单调”。
2. **每次循环排除了什么**：被排除的区间、元素或状态以后不会再成为答案。
3. **边界为什么这样写**：循环条件、遍历方向、初始化值都要服务于不变量。

```mermaid
flowchart LR
    A[识别题型] --> B[选择模板]
    B --> C[确认状态与不变量]
    C --> D[调整输入输出]
    D --> E[用边界样例验证]
```

## 怎么用模板

### 先识别题型

| 关键词 | 对应模板 |
|--------|---------|
| 有序数组、查找 | 二分查找 |
| 两数之和、回文 | 双指针 |
| 子串、子数组 | 滑动窗口 |
| 区间和、矩形和 | 前缀和 |
| 下一个更大 | 单调栈 |
| 连通性、合并 | 并查集 |
| 最大价值、装满 | 背包问题 |
| 最短路径 | 图算法 |
| 只有0/1边权 | 0-1 BFS |
| 多模式匹配 | AC自动机 |
| 区间修改查询 | 线段树 |
| 动态前缀和 | 树状数组 |

### 再按这个顺序套

1. 找到最接近的模板。
2. 先确认模板维护了什么不变量。
3. 再改初始化、循环边界和返回值。
4. 最后用最小样例和边界样例验证。

### 常见陷阱

| 模板 | 易错点 | 正确做法 |
|------|--------|---------|
| 二分查找 | 边界条件 | 统一区间定义 |
| 滑动窗口 | 窗口何时收缩 | 明确收缩条件 |
| 单调栈 | 栈存值还是索引 | 通常存索引 |
| 背包问题 | 遍历顺序 | 0-1后向前，完全前向后 |
| 并查集 | 忘记路径压缩 | find时压缩 |

## 优先掌握顺序

1. 先吃透二分、双指针、滑动窗口、前缀和。
2. 再掌握单调栈、堆、并查集。
3. 然后补 DFS、BFS、回溯、背包。
4. 最后看图算法和字符串算法的专项模板。
