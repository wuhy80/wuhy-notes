# 如何创建使用venv
Ubuntu 下面可以执行 `python -m venv .venv` 来创建一个虚拟环境，使用 `source .venv/bin/python` 来激活虚拟环境

# 配置国内镜像
## Ubuntu
永久修改：修改`~/.pip/pip.conf`文件（没有就新建一个），内容如下：

```ini
[global]
index-url = https://pypi.tuna.tsinghua.edu.cn/simple
```

此后每次运行 `pip install` 都会默认去这个镜像源下载包。

## Windows
在 Windows 系统中设置 Python 的 pip 源，可以通过修改 pip 的配置文件来实现。以下是设置步骤：

1. **打开命令提示符**：
按下 `Win + R` 键，输入 `cmd`，然后按 `Enter` 键打开命令提示符。

2. **创建或编辑 pip 配置文件**：
如果 pip 配置文件不存在，需要先创建它。在命令提示符中输入以下命令来创建或编辑 pip 配置文件：
```
notepad %HOMEPATH%\pip\pip.ini
```
如果系统提示找不到路径，可能是因为没有 `%HOMEPATH%\pip` 这个目录。您可以先创建这个目录，然后再创建 `pip.ini` 文件：
```
mkdir %HOMEPATH%\pip
notepad %HOMEPATH%\pip\pip.ini
```

3. **编辑 pip 配置文件**：
在打开的记事本中，输入以下内容来设置 pip 源为国内镜像，例如阿里云的镜像：
```ini
[global]
index-url = https://mirrors.aliyun.com/pypi/simple/
```
您也可以选择其他镜像源，如清华大学的镜像源：
```ini
[global]
index-url = https://pypi.tuna.tsinghua.edu.cn/simple
```
保存并关闭记事本。

4. **验证设置**：
在命令提示符中输入以下命令来查看当前的 pip 源设置：
```
pip config list
```
如果设置成功，应该能看到类似以下的输出：
```
global.index-url='https://mirrors.aliyun.com/pypi/simple/'
```

5. **使用 pip 安装包**：
现在您可以使用 pip 安装 Python 包，它会自动从您设置的镜像源下载：
```
pip install 包名
```

请注意，设置 pip 源时，确保您信任所使用的镜像源，因为镜像源可能会影响包的下载和安装。此外，如果您使用的是 Python 的虚拟环境，可能需要在每个虚拟环境中单独设置 pip 源。

# MAC 上安装 python 环境
# 1. 安装 pyenv
`brew install pyenv`

# 2. 配置 shell（添加到 ~/.zshrc 或 ~/.bashrc）
```bash
echo 'export PYENV_ROOT="$HOME/.pyenv"' >> ~/.bashrc
echo 'command -v pyenv >/dev/null || export PATH="$PYENV_ROOT/bin:$PATH"' >> ~/.bashrc
echo 'eval "$(pyenv init -)"' >> ~/.bashrc
source ~/.bashrc
```


# 3. 安装 Python 3.12
```bash
echo ' export PYTHON_BUILD_MIRROR_URL="https://registry.npmmirror.com/-/binary/python"' >> ~/.bashrc
echo 'export PYTHON_BUILD_MIRROR_URL_SKIP_CHECKSUM=1' >> ~/.bashrc
source ~/.bashrc

pyenv install 3.12
```

# 4. 创建 3.11 专属虚拟环境
`$(pyenv prefix 3.12)/bin/python -m venv unsloth_env`

# 5. 激活环境
`pyenv activate unsloth_env`

# 6. 验证版本
`python --version`
