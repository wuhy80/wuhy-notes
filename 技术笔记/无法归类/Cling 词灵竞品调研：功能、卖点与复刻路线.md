# Cling 词灵竞品调研：功能、卖点与复刻路线

> [!info] 调研对象
> **Cling 词灵**（clingword.com）——AI 背单词产品，运营主体：北京德雷莫科技有限公司（2010 年成立，京ICP备19054918号-2，北京市 2025 年第二批拟入库科技型中小企业）。信息来源：公开页面、用户协议 v3.0（2026-09-16 生效）、匿词落地页。应用本体在登录墙后（微信扫码登录），未实测。

---

## 1. 产品矩阵：一个闭环，三个入口

```
匿词 (macOS/全局摘词)  →  云端多词本仓库  →  词灵 (Web 学习引擎)
   Collect                  Organize              Review (FSRS)
```

| 产品 | 入口 | 角色 |
| --- | --- | --- |
| **词灵 (Cling Next)** | next.clingword.com | Web 学习主站：词书、学习、复习、统计 |
| **匿词 (NEATH)** | neath.clingword.com + macOS 客户端 (v2.0.5) | 阅读中摘词：全局快捷键、多词本、自动同步 |
| **会员收银台** | cashier.clingword.com | 统一账号、微信支付、手动续费 |
| **文档中心** | doc.clingword.com | 用户协议、隐私政策、帮助文档 |

## 2. 功能清单（据用户协议 v3.0 与落地页）

**词灵学习主站**
- 词书选择、单词学习、拼写练习、复习安排
- FSRS 调度（现代间隔重复算法）+ 根据学习记录/作答/掌握情况给复习建议
- 学习进度与统计、记忆能力分析、学习目标调整
- **ClingAI 辅助学习**（与普通学习分开计量、分开记录进度）：AI 评测、讲解、翻译、错题复习；AI 生成释义/翻译/题目/讲解/**语音**（含 TTS）；AI 输出带「AI 生成」标识
- 自定义词本（承接匿词同步），网页控制台支持重命名/新建/批量移动/复制/导入/导出
- **API Key 机制**：用户可创建接口密钥（第三方工具/自动化接入）

**匿词 (macOS)**
- 全局快捷键：`Option+Z` 选中即查+收藏、`Option+X` 想到即录入——浏览器/PDF/任何可选中文本处，不切换窗口
- 多词本体系：Default 默认词本承接所有新词 → 整理成个性化词本（雅思阅读高频/计算机表达/物理教材生词/经济学人摘录/原著生僻词…）
- 免费版限额：50 个单词、10 本自建词本
- 收藏静默同步到词灵「自定义」栏目，构成 Collect→Organize→Sync→Review 闭环

**会员与计费**
- 档位：**词灵 Pro**（学习服务付费权益）、**词灵与匿词完整版 Mix**（+匿词与词本联动）
- 免费额度（截至协议 v3.0）：普通学习账号累计 200 次学习请求（不每月重置）；ClingAI 体验仅跨词书合计 **5 个单词**；匿名限额如上
- 支付：网页收银台微信支付；**单次购买、手动续费、无自动扣款**；月卡按 30 天、年卡按 365 天；有升级抵扣、退款与发票条款
- 计量方式：普通学习 / ClingAI / 匿词分别计量

## 3. 卖点分析

1. **闭环叙事是最大差异点**：不做「又一个背单词 App」，而是「阅读摘词（无感、不打断心流）→ 结构化词库 → 科学复习」的完整流水线。文案原话："阅读的心流，本不该被打断"、"收藏不是终点，而是学习的上游"。
2. **FSRS 调度**：采用开源 FSRS（Anki 新一代调度算法）而非 SM-2 老古董，对学习效率人群有说服力。
3. **AI 深入学习流且独立计量**：ClingAI 与普通学习分账户记录，AI 讲解/出题/错题复习/语音是增值层，免费额度极小（5 词）——保护毛利的典型设计。
4. **面向高阶用户**：词本样例全是雅思/经济学人/计算机/物理教材——瞄准大学生、留学、职场深度阅读人群，而非 K12。
5. **macOS 原生摘词体验**：全局快捷键是护城河型功能（浏览器扩展做不到系统级全局捕获）。
6. **合规成熟度异常高**：协议 v3.0 涵盖 AI 内容标识义务、未成年人保护、退款原则、API 反滥用条款——超出小团队平均水准。
7. **设计品味**：匿词落地页的暗色视觉、自定义光标、canvas 背景、文案节奏，独立开发者里属于上乘。

**弱点（即复刻者的机会）**：
- **无移动端**（next 登录页明确写「移动端暂不支持」）——手机端空白；
- 知名度极低：无任何第三方评测、社区口碑、媒体报道；
- AI 免费额度抠门（5 个单词），上手体验门槛高；
- 产品依赖用户有「深度阅读+电脑」场景，天然受众窄。

## 4. 技术架构（公开信息推断）

- 前端：Alpine.js + Tailwind CSS（轻量路线，非重型 SPA）；应用在 next 子域，登录后加载真正的 SPA 包
- 服务端：nginx/1.24.0 (Ubuntu)，JSON API；服务器在国内（北京/湖北飞讯、电信云）
- 登录：微信 OAuth 扫码 + 辅助用户名密码；TLS 用 Let's Encrypt 多子域 SAN
- 支付：微信支付（网页收银台，手动续费）
- 客户端：macOS 原生 App（自动更新走 releases 路径带 build hash）
- AI：第三方 LLM API 做讲解/出题/评测 + TTS 语音
- 复习算法：开源 FSRS 库（无需自研）

## 5. 复刻路线

### 5.1 定位建议

不要复刻成「又一个背单词 App」——要复刻的是**「无感摘词 → 词库 → FSRS 复习 → AI 讲解」闭环**。同时打它的两个弱点：**做移动端**（PWA 或小程序，它没有）、**AI 额度大方一点**（让用户先体验到价值）。

### 5.2 技术选型（一个人 + AI coding 可行）

| 模块 | 建议 |
| --- | --- |
| Web 前端 | Vue3/Next.js + Tailwind；复习卡片 UI 是核心打磨对象 |
| 后端 | FastAPI (Python) 或 Node + PostgreSQL |
| 复习调度 | 直接用开源 **ts-fsrs / py-fsrs** 库，不要自研算法 |
| 词库数据 | ECDICT 等开源词典 + 公开考试词表（四六级/雅思/托福）；发音用 Edge TTS / OpenAI TTS |
| AI 讲解 | DeepSeek/OpenAI API：单词讲解、语境例句、错题出题；按用户计量（仿其 Pro 设计） |
| 摘词入口 | **MVP 用 Chrome 扩展**（选中即查+收藏，一周量级）；macOS 全局快捷键（Swift + Accessibility）放第二阶段 |
| 支付 | 虎皮椒/面包多等聚合支付起步；做正了再注册主体 + 微信支付商户号 |
| 账号 | 起步用手机号/邮箱；微信扫码登录需要企业开放平台，后置 |

### 5.3 分阶段路线

1. **MVP（4–8 周）**：词书导入 → FSRS 学习/复习循环 → AI 例句与讲解 → Chrome 扩展摘词 → 简单订阅支付
2. **第二阶段**：多词本管理（导入/导出/批量）、学习统计面板、TTS 跟读、PWA 移动端
3. **第三阶段**：macOS 原生全局摘词、API Key 开放、词书商城/UGC 词本分享

### 5.4 合规清单（照抄它的成熟度）

- ICP 备案（个人或企业主体）
- 用户协议 + 隐私政策：**AI 生成内容标识义务**（2026 年已强制）、未成年人保护、退款规则（周期类服务不要写死「不适用七日无理由」）
- 支付走正规商户或合规聚合；用户内容授权条款（存储/同步/评测的必要范围，不占用户内容所有权——直接参考它的 7.2 写法）

### 5.5 成本量级

- 研发：一个人 + AI coding，MVP 4–8 周
- 运行：LLM API 按用量（用计量/会员制转嫁）+ 服务器（国内轻量云 ~百元/月）+ 词书数据（公开词表免费；正版出版词书需授权，起步避开）

## 6. 自用版（不做产品，只给自己用）

自用砍掉账号/支付/备案/多端后，剩下三选一：

1. **Anki 直接用（首选试水）**：内置 FSRS；AI 批量生成词表牌组（释义/例句/词根记忆法）导入；AnkiConnect 插件 + 脚本实现摘词入卡；AnkiDroid 免费同步。投入一个晚上。
2. **自建单机 Web**：FastAPI + SQLite + `py-fsrs` 官方库；两张表（words 讲解缓存 + cards 调度状态）；DeepSeek API 逐词生成讲解并缓存（省钱关键：一词只生成一次）；Windows 摘词用 AutoHotkey 热键 + 浏览器右键扩展；本地 localhost 运行。投入几个晚上，复习界面完全自定义。
3. **Obsidian 方案**：Spaced Repetition 插件（FSRS）+ 生词卡片笔记 + Web Clipper 剪藏；与现有知识库打通，复习体验稍弱。

决策：先用 Anki 跑一周，不满意再自建。
