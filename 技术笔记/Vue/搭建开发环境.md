# Docker环境
## 生成Docker
```Dockerfile
FROM node

RUN npm config set registry http://mirrors.cloud.tencent.com/npm/
#COPY src/package.json .
#RUN npm install
WORKDIR /app  

EXPOSE 5173  
```
这个配置文件的意思是使用最新的node，且设置腾讯的npm源，配置/app目录为代码目录，并对外暴露5173端口.
上面注释的两行可以让镜像文件创建的时候就包含了需要的依赖，免去每次启动docker之后还需要重新进行npm install安装依赖

## Makefile
```make
VERSION := v20240402

.PHONY: all docker_build docker_tag docker_push docker_start

all: docker_stop docker_start
run: docker_start
stop: docker_stop
build: docker_build docker_tag docker_push 

docker_build:
	@echo "开始构建Vue开发镜像..."
	@docker build --no-cache -t node-latest .

docker_tag:
	@echo "--no-cache"
	@docker tag node-latest:latest 192.0.2.90/library/node-latest:$(VERSION)

docker_push:
	@echo "docker push 192.0.2.90/library/node-latest:$(VERSION)"
	@docker push 192.0.2.90/library/node-latest:$(VERSION)

docker_start:
    @echo "start docker node-latest app"
    docker run -v `pwd`/src:/app -p 5173:5173 --name vue-dev-app -it -d 192.0.2.90/library/node-latest:$(VERSION)
    @echo "docker exec -it vue-dev-app bash"
    @docker exec -it vue-dev-app bash

docker_stop:
	@echo "stop docker node-latest app"
	docker stop vue-dev-app
	docker rm vue-dev-app
```
使用了上面的配置就可以用make build先编译环境，之后每次只要执行make命令就可以启动测试环境.

## 部署Vue-element-plus
https://github.com/element-plus/element-plus-vite-starter
下载上面的element-plus启动模板放到src目录之后重新make build生成镜像文件

使用下面的方式可以直接make docker_start直接启动调试环境
```make
docker_start:
    @echo "start docker node-latest app"
    docker run -v `pwd`/src:/app -p 5173:5173 --name vue-dev-app -it -d 192.0.2.90/library/node-latest:$(VERSION)
    @echo "docker exec -it vue-dev-app npm run dev -- --host 0.0.0.0"
    @docker exec -it vue-dev-app npm run dev -- --host 0.0.0.0
```
