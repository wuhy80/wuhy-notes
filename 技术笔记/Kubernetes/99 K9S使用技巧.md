# 按键使用
## 排序方式
| 快捷键     | 作用      |
| ------- | ------- |
| shift-n | 按pod名排序 |
| shift-c | 按cpu排序  |
| shift-m | 按内存排序   |
| shift-i | 按 ip 排序 |
