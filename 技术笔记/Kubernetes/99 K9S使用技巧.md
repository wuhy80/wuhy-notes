# K9S 使用技巧

> [!abstract] 概述
> K9S 是一个基于终端的 Kubernetes 集群管理工具，提供了直观的 UI 界面来查看和管理集群资源。

---

## 排序快捷键

| 快捷键 | 作用 |
|--------|------|
| `Shift + N` | 按 Pod 名排序 |
| `Shift + C` | 按 CPU 使用率排序 |
| `Shift + M` | 按内存使用率排序 |
| `Shift + I` | 按 IP 地址排序 |

---

## 常用操作快捷键

| 快捷键 | 作用 |
|--------|------|
| `:` | 进入命令模式 |
| `/` | 过滤/搜索 |
| `Enter` | 查看详情 |
| `d` | 描述资源（describe） |
| `l` | 查看日志（logs） |
| `s` | 进入 Shell |
| `e` | 编辑资源 |
| `Ctrl + D` | 删除资源 |
| `y` | 查看 YAML |
| `Esc` | 返回上一级 |

---

## 资源导航命令

在命令模式（按 `:`）下输入：

| 命令 | 说明 |
|------|------|
| `:pod` 或 `:po` | 查看 Pod |
| `:deploy` | 查看 Deployment |
| `:svc` | 查看 Service |
| `:ns` | 查看 Namespace |
| `:node` | 查看 Node |
| `:cm` | 查看 ConfigMap |
| `:secret` | 查看 Secret |
| `:pv` | 查看 PersistentVolume |
| `:pvc` | 查看 PersistentVolumeClaim |

## 实用技巧

> [!tip] 快速切换命名空间
> 按 `0` 可以查看所有命名空间的资源，或使用 `:ns` 进入命名空间列表后选择。

> [!tip] 查看容器日志
> 选中 Pod 后按 `l` 查看日志，按 `Shift + F` 可以跟踪日志（类似 `tail -f`）。

> [!tip] 获取 Container ID
> 在 K9S 中查看 Pod 详情可以获取 Container ID，用于后续的底层文件系统分析。
