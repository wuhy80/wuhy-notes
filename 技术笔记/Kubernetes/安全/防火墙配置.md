以 `root` 用户身份执行：

下面的脚步会打开防火墙的配置
```bash
#!/bin/bash

# 启用 ufw
ufw --force enable

# 允许基本的 Kubernetes 端口
ufw allow 6443/tcp
ufw allow 2379:2380/tcp
ufw allow 10250/tcp
ufw allow 10251/tcp
ufw allow 10252/tcp
ufw allow 53/tcp
ufw allow 53/udp
ufw allow 8472/udp

# 允许 NodePort 端口范围
ufw allow 30000:32767/tcp

# 允许本地和内部网络流量
ufw allow from 192.168.0.0/16
ufw allow from 10.0.0.0/8
ufw allow from 172.16.0.0/12

# 重启 ufw 使规则生效
ufw reload

# 显示防火墙状态和规则
ufw status verbose
```

### 安装和配置 Kubernetes

首先，确保你已经安装和配置了 Kubernetes 1.24。如果还没有，可以按照以下步骤安装 Kubernetes 1.24：

```sh
# 更新包列表
apt-get update

# 安装必要的工具
apt-get install -y apt-transport-https ca-certificates curl

# 添加 Kubernetes apt 仓库
curl -fsSLo /usr/share/keyrings/kubernetes-archive-keyring.gpg https://packages.cloud.google.com/apt/doc/apt-key.gpg
echo "deb [signed-by=/usr/share/keyrings/kubernetes-archive-keyring.gpg] https://apt.kubernetes.io/ kubernetes-xenial main" | tee /etc/apt/sources.list.d/kubernetes.list

# 更新包列表并安装 kubelet、kubeadm 和 kubectl
apt-get update
apt-get install -y kubelet=1.24.0-00 kubeadm=1.24.0-00 kubectl=1.24.0-00

# 锁定版本
apt-mark hold kubelet kubeadm kubectl

# 启动并启用 kubelet
systemctl enable kubelet && systemctl start kubelet
```

### 配置 `ufw` 防火墙

1. **安装和启用 `ufw`**：

   ```sh
   apt-get install -y ufw
   ufw enable
   ```

2. **允许基本的 Kubernetes 端口**：

   Kubernetes 需要以下基本端口：

   - API 服务器：6443 (TCP)
   - etcd 服务器：2379-2380 (TCP)
   - kube-scheduler 和 kube-controller-manager：10251-10252 (TCP)
   - kubelet：10250 (TCP)
   - 集群 DNS：53 (TCP/UDP)
   - 集群内部通信：8472 (UDP)

   ```sh
   ufw allow 6443/tcp
   ufw allow 2379:2380/tcp
   ufw allow 10250/tcp
   ufw allow 10251/tcp
   ufw allow 10252/tcp
   ufw allow 53/tcp
   ufw allow 53/udp
   ufw allow 8472/udp
   ```

3. **允许 NodePort 端口范围**：

   Kubernetes 的 NodePort 服务默认使用 30000-32767 范围的端口。你可以根据需要调整这些端口的访问权限：

   - 如果你希望允许所有流量访问 NodePort 端口：

     ```sh
     ufw allow 30000:32767/tcp
     ```

   - 如果你只希望特定 IP 地址访问 NodePort 端口：

     ```sh
     ufw allow from 192.168.1.0/24 to any port 30000:32767 proto tcp
     ```

4. **允许本地和内部网络流量**：

   确保本地和内部网络的通信不受限制：

   ```sh
   ufw allow from 192.168.0.0/16
   ufw allow from 10.0.0.0/8
   ufw allow from 172.16.0.0/12
   ```

5. **重启 `ufw` 使规则生效**：

   ```sh
   ufw reload
   ```

6. **查看防火墙状态和规则**：

   你可以使用以下命令查看 `ufw` 的状态和已添加的规则：

   ```sh
   ufw status verbose
   ```

通过这些步骤，你可以在 Ubuntu 上配置 `ufw` 防火墙以保护 Kubernetes 1.24 集群，确保只有授权的流量可以访问必要的端口。这将有助于提高集群的安全性并减少潜在的攻击面。
