
要在 Docker 中运行 `ubuntu:22.04` 镜像，并在其中执行安装命令，然后保存这个安装了软件包的镜像，您可以按照以下步骤操作：
1. **运行容器**：
   使用 `docker run` 命令运行一个基于 `ubuntu:22.04` 的容器，并在容器中执行安装命令。
2. **安装软件包**：
   在容器中，使用 `apt-get update` 和 `apt-get install` 命令来安装所需的软件包。
3. **保存镜像**：
   安装完成后，使用 `docker commit` 命令将当前容器的状态保存为一个新的镜像。
4. **查看镜像**：
   使用 `docker images` 命令来查看当前所有镜像，包括您刚刚创建的新镜像。

下面是一个具体的命令示例：
```sh
docker run -it ubuntu:22.04 /bin/bash
```

这个命令会启动一个交互式终端，您可以通过这个终端来执行命令。在容器中，执行以下命令来安装软件包：
```sh
apt update && apt -y install locales language-pack-ja apt-utils curl vim wget telnet && locale-gen en_US.UTF-8 && apt clean
```

安装完成后，退出容器（例如，使用 `exit` 命令），然后使用以下命令来保存镜像：
```sh
docker commit <container_id> <new_image_name>
```

将 `<container_id>` 替换为实际容器的 ID，`<new_image_name>` 替换为您想要为镜像指定的名称。例如：
```sh
docker commit $(docker ps -aq) my_custom_ubuntu_image
```
这个命令会保存当前正在运行的容器的状态为一个新的镜像，命名为 `my_custom_ubuntu_image`。

最后，使用 `docker images` 命令来确认镜像已经被保存：
```sh
docker images
```
您应该能够看到名为 `my_custom_ubuntu_image` 的新镜像。这个镜像现在可以作为其他镜像的基础来构建。


## 一个实际操作的例子
```bash
docker run -it ubuntu:22.04 /bin/bash
# 在启动的docker内执行安装命令
apt update && apt -y install locales language-pack-ja apt-utils curl vim wget telnet && locale-gen en_US.UTF-8 && apt clean
# 退出docker镜像后将通过apt安装东西后的镜像打包后打tag再发送出去
docker commit 3fa3333bd71d ubuntu_2204_for_gateway
docker tag ubuntu_2204_for_gateway 192.0.2.90/gatewaydev/ubuntu_2204_for_gateway:20240425
docker push 192.0.2.90/gatewaydev/ubuntu_2204_for_gateway:20240425
```
