## FTP 服务器

### 使用 Docker 部署 vsftpd

> [!tip] 快速部署
> 使用 `fauria/vsftpd` 镜像可以快速搭建 FTP 服务器。

#### 准备目录

```bash
mkdir -p /data/ftp/data /data/ftp/log
chmod -R 750 /data/ftp
```

#### 启动 FTP 服务

```bash
docker run -d \
  --name vsftpd \
  --restart=always \
  -v /data/ftp/data/:/home/vsftpd \
  -v /data/ftp/log/:/var/log/vsftpd/ \
  -p 20:20 -p 21:21 -p 20000-20009:20000-20009 \
  -e FTP_USER=admin \
  -e FTP_PASS='change-this-strong-password' \
  -e PASV_MIN_PORT=20000 \
  -e PASV_MAX_PORT=20009 \
  -e LOG_STDOUT=1 \
  fauria/vsftpd
```

#### 参数说明

| 参数 | 说明 |
|-----|------|
| `-v /data/ftp/data/:/home/vsftpd` | FTP 数据目录映射 |
| `-v /data/ftp/log/:/var/log/vsftpd/` | 日志目录映射 |
| `-p 20:20` | FTP 数据端口 |
| `-p 21:21` | FTP 控制端口 |
| `-p 20000-20009:20000-20009` | 被动模式端口范围（需与 `PASV_MIN_PORT`/`PASV_MAX_PORT` 一致） |
| `-e FTP_USER=admin` | FTP 用户名 |
| `-e FTP_PASS='change-this-strong-password'` | FTP 密码（示例占位值） |
| `-e LOG_STDOUT=1` | 日志输出到标准输出 |

> [!warning] 安全提示
> FTP 会明文传输账号和数据；生产环境应优先使用 SFTP/FTPS，并通过 Secret 或环境变量注入强密码。不要提交真实密码，也不要使用 `chmod 777`。
