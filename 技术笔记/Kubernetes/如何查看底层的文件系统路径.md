# Overlay 的说明
在 overlayfs 中，几个关键的概念是 lowerdir、upperdir 和 workdir：

1. **lowerdir**: 这是指向底层只读层的一个或多个目录的指针。在 overlayfs 中，可以有多个 lowerdir，它们按照冒号分隔的顺序进行堆叠，最左边的目录是最低层，最右边的目录是最高层。在您的例子中，`lowerdir` 包含了四个目录，分别对应于四个不同的快照（22040、22039、22038、22037）。这些快照是容器的早期层，通常是只读的。
    
2. **upperdir**: 这是一个可写层，挂载在 lowerdir 的顶部。对文件系统的所有写操作都会在这个目录中发生。在您的例子中，`upperdir` 指向了快照 ID 为 56817 的目录。这个目录包含了容器运行时对文件系统所做的任何更改。
    
3. **workdir**: 这是 overlayfs 用来进行内部操作的一个工作目录，例如用于实现 copy-on-write（写时复制）机制。当需要修改一个文件时，overlayfs 会在这个工作目录中创建一个临时文件，然后将其复制到 upperdir 中。这个目录对于用户通常是不可见的，是 overlayfs 内部使用的。
    

总结来说，overlayfs 使用这种多层结构来提供一个统一的文件系统视图。当读取文件时，如果 upperdir 中存在该文件，则从 upperdir 中读取；如果不存在，则从 lowerdir 中读取。当写入文件时，overlayfs 会使用 copy-on-write 机制，在 upperdir 中创建文件的副本，而 lowerdir 中的原始文件保持不变。这样，每个容器都可以有一个自己的 upperdir，而共享底层的 lowerdir，从而实现高效的存储和资源管理。
