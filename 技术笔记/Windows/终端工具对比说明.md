# Windows 终端工具对比说明

> [!note] 时效性
> 终端工具的安装方式、免费额度和产品名称会变化。以下问题应记录具体版本和日期，不能把单次故障直接视为产品长期特性。

## Tabby（原 Terminus）

基于 Electron，支持 SSH、串口和本地 Shell。历史使用中出现过安装位置不明确、启动全屏等问题；重新评估时应先记录 Tabby 版本、安装来源和窗口设置，再判断是否仍能复现。

## NextSSH

界面较简洁，但免费版本的并发连接限制可能影响多主机运维。许可证和套餐可能调整，使用前应以当前官方说明为准。

## 选择维度

| 维度 | 检查内容 |
|---|---|
| 连接能力 | SSH、SFTP、串口、跳板机、端口转发 |
| 密钥管理 | 是否使用系统 SSH Agent，是否支持硬件密钥 |
| 会话效率 | 标签页、分屏、批量操作和配置同步 |
| 安全性 | 主机密钥校验、凭据存储位置、日志是否包含敏感内容 |
| 维护成本 | 更新方式、配置导出、跨平台支持和许可证限制 |

不需要内置 SSH 管理功能时，可优先使用 Windows Terminal 配合系统 OpenSSH；它沿用标准 `~/.ssh/config`，迁移成本较低。
