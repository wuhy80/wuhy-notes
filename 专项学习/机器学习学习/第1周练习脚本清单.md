# 第1周练习脚本清单

> [!note] 使用方式
> 每完成一个脚本，就在下面打勾，并把代码放到你自己的 `scripts/` 或 `notebooks/` 目录中。

- [ ] `hello_numpy.py`
说明：打印数组、形状、求和、均值

- [ ] `matrix_basic_ops.py`
说明：矩阵加减乘、转置、切片

- [ ] `matrix_multiplication_demo.py`
说明：实现 2 个矩阵乘法案例

- [ ] `statistics_demo.py`
说明：均值、方差、标准差计算

- [ ] `conditional_probability_demo.py`
说明：写 2 个简单条件概率例子

- [ ] `gradient_descent_demo.py`
说明：用最简单的一元函数演示梯度下降

- [ ] `week1_summary_demo.py`
说明：把本周核心内容放到一个综合脚本里

## 建议命名规范

- 文件名用英文和下划线
- 一个脚本只解决一个问题
- 每个脚本都加 3 行以内说明
