# 第1周执行计划

> [!abstract] 本周目标
> 第 1 周的重点不是“学很多”，而是把数学和 Python 数据处理的基础打稳，并且把学习环境与练习节奏跑顺。

关联文档：
- [[3个月学习规划]]
- [[3个月机器学习规划-学习进度跟踪]]

---

## 本周目标

- [ ] 完成 Python 机器学习环境搭建
- [ ] 理解向量、矩阵和矩阵乘法
- [ ] 理解均值、方差、标准差、条件概率
- [ ] 用 `numpy` 完成基础矩阵计算
- [ ] 输出 1 篇本周复盘

---

## 学习环境准备

- [ ] 安装 Python 3
- [ ] 安装 Jupyter 或 VSCode Notebook
- [ ] 安装 `numpy`
- [ ] 安装 `pandas`
- [ ] 安装 `matplotlib`
- [ ] 安装 `scikit-learn`

建议安装命令：

```bash
pip install numpy pandas matplotlib scikit-learn jupyter
```
