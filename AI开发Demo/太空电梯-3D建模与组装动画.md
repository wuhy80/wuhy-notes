# 轨道之环 · 太空电梯 3D 建模与组装动画

> [!summary] 一句话
> 一个零依赖的单文件网页：把「赤道锚点 → 配重入轨 → 主缆延伸 → 攀爬舱 → 同步轨道站 → 能量上线」六段太空电梯组装过程做成可交互的科幻动画，**双击 HTML 就能跑**，不需要联网、不需要服务器。

> [!note] 2026-11-28 重制：环形轿厢 + 程序化材质 + 景深
> 参考《流浪地球2》太空电梯壁纸：**环形轿厢抱索**夹住 7 股缆索束，两侧桁架导轨；轿厢上密度约 550 件细节（340 设备块 + 120 管线 + 90 天线/支架，全部 InstancedMesh）。
> 三层云：近处软雾团、远处大云团、低空云海平面；后期做**景深**（基于深度纹理的 3×3 CoC 模糊）、泛光、暗角、颗粒。
> 全部程序生成、无外部资产：金属底色/法线/粗糙度贴图与等距柱状环境贴图都由 Canvas 实时绘制，three.js 内联进单文件。

## 一、建模对象

| 部件 | 视觉表达 | 说明 |
| --- | --- | --- |
| 地球 | 全息线框球 + 大气辉光 + 夜面城市灯 + 赤道环 | 用程序化网格与粒子表现，不依赖贴图 |
| 赤道锚点 | 倒梯形基座 + 平台灯 | 缆索的地面起点 |
| 主缆 | 三层叠加辉光线 + 64 组分段锁扣 + 能量脉冲 | 分段出现，逐段建立张力 |
| 攀爬舱 | 胶囊形舱体 + 品红引擎辉光 | 4 台，挂载后低速往返 |
| 同步轨道站 | 环形桁架 + 12 个模块 + 太阳能板 | 模块沿环向依次对接 |
| 配重 | 琥珀色六边形舱体 | 缆索顶端，维持张力 |
| 运载器 | 三角箭体 + 尾焰 + 上升轨迹 | 第一阶段向轨道投送载荷 |

## 二、六阶段组装动画

| 阶段 | 时间轴 | 画面 | 遥测 |
| --- | --- | --- | --- |
| 01 地基锚点与载荷发射 | 0–14% | 三枚运载器从锚点升空，尾焰拖尾 | 高度 0 km |
| 02 配重入轨 · 初始缆索 | 14–30% | 配重出现在高位，始发缆索自上而下展开 | 分段 0→11 |
| 03 主缆延伸 · 分段锁扣 | 30–55% | 缆索逐段点亮，锁扣环闪光闭合 | 分段 → 64，张力上升 |
| 04 攀爬舱装配与试运行 | 55–74% | 4 台攀爬舱依次挂载，引擎点亮 | 攀爬舱 0→4 |
| 05 同步轨道站合拢 | 74–90% | 12 个模块沿环向对接 | 模块 0→12 |
| 06 能量注入 · 系统上线 | 90–100% | 能量脉冲贯穿全索，状态转 ONLINE | 能量 0→100% |

完整播放约 **78 秒**，可暂停、重播、拖拽时间轴或按 `1–6` 直接跳到对应阶段。

## 四、工程实现

- **渲染**：单个 `<canvas>` + Canvas 2D；自写透视投影（相机基向量 + 焦距），所有部件用 3D 坐标投影后绘制。
- **辉光**：`globalCompositeOperation = 'lighter'` 叠加多层描边/径向渐变，模拟 bloom，不引入 WebGL 后处理。
- **地球**：经纬线球面网格 + 大气径向渐变 + 夜面城市灯粒子（按太阳方向计算明暗）+ 移轴赤道环。
- **时间轴**：单一 `timeline ∈ [0,1]` 驱动全部状态（建造进度、分段数、模块数、攀爬舱、能量），HUD 与画面完全同源。
- **定帧参数**：`?t=0.62&pause=1` 直接渲染某个时间点的静态画面，方便截图与文档配图。
- **零依赖**：无外部字体/图片/JS，单文件约 40 KB（不含截图），`file://` 直接打开。

## 六、可扩展方向

1. **真实比例**：地球半径 6371 km、同步轨道 35786 km、缆索总长约 10 万 km，可按真实比例做“缩放镜头”转场。
2. **导入 glTF 模型**：攀爬舱/轨道站换成精细模型（会牺牲单文件约束）。
3. **多视角**：地面视角、攀爬舱第一人称、轨道俯视。
4. **数据驱动**：把阶段时长、部件参数抽成 JSON，便于换主题（例如月球电梯、火星电梯）。
5. **音效与字幕**：引擎低频、锁扣“咔哒”、阶段旁白。

## 七、取舍说明

- 用 Canvas 2D 而非 Three.js：为了**单文件零依赖、双击即开**，同时用 `lighter` 叠加做出了接近 bloom 的辉光；代价是没有真实光照和深度缓冲。
- 比例经过压缩：真实缆索长度是地球半径的十几倍，直接按比例会让画面只剩一根线，所以对“可视长度”做了压缩，遥测数字仍按真实量级给出。
- 这是**示意级建模**，不是工程仿真；张力、速度、能量都是叙事化数值。
