# 伺服轴智能运维 · 叙事页与演示脚本

## 一、demo-3d.html：产线级的「全景图」

一份滚动推进的叙事页，把六个阶段串成一条线：

1. **订单接入**——需求从哪来
2. **APS 排程**——怎么排、按什么约束排
3. **加工执行**——设备、工序、节拍
4. **质量追溯**——出了问题怎么倒查
5. **能耗与碳**——单耗、峰谷、碳足迹
6. **复盘改善**——数据怎么回到下一轮

适合开场 3 分钟用，让观众先有「整条线」的概念，再进到设备级细节。

## 二、演示脚本：讲的人手里的那张纸

七幕场景说明，每一幕给出画面要点、讲解口径和串场句。

> [!warning] 打开时机
> 它本身不是给观众看的，是给讲的人看的——**建议最后才打开**，或者干脆打印出来放在手边，否则会把注意力从画面上带走。

## 三、三份材料的关系

```text
叙事（demo-3d）                    ：为什么要做这件事
镜像（[[伺服轴数字孪生-CNC012实时镜像]]）：这件事在设备上长什么样
脚本（演示脚本）                    ：讲的时候怎么串
```

## 四、可复用的做法

1. **分层讲**：先产线（叙事页）再设备（孪生镜像）最后流程（脚本），比一上来就讲单机细节更容易建立信任。
2. **叙事页用滚动而非点击**：开场阶段观众还没进入交互状态，滚动推进的阻力最小。
3. **脚本要写「串场句」**：两屏之间的那句过渡话，往往比每屏的内容更决定演示是否连贯。
