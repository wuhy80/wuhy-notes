## 视频导读

- 主线问题：**如何描述一个向量场在每一点上「往外冒」还是「往里收」、「打转」还是「不打转」？**——散度衡量一点的「源/汇强度」，旋度衡量一点的「微观自旋倾向」。

## 核心概念中英对照

| 英文术语 | 中文 | 一句话说明 |
|---|---|---|
| vector field | 向量场 | 空间每一点都配一个向量的函数，如流速场、电场 |
| divergence | 散度 | 向量场在某点「向外发散/向内汇聚」的强度，正为源、负为汇 |
| curl | 旋度 | 向量场在某点附近的「微观旋转倾向」，流体里对应涡旋 |
| fluid flow | 流体流动 | 散度/旋度最直观的物理载体：膨胀、压缩与打转 |
| Maxwell's equations | 麦克斯韦方程组 | 用散度与旋度写成的电磁学四大方程 |
| source / sink | 源 / 汇 | 散度为正的点向外「冒」出场的量，为负则向内吸收 |
| flux | 通量 | 场穿过某个面的总量，散度是通量的体密度 |
| scalar / vector | 标量 / 向量 | 二维旋度是标量，三维旋度是向量（轴由右手定则定） |
