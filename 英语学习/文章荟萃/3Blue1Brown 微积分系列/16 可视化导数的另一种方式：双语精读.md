## 变换的视角（The transformation view）

| 原文 | 译文 |
|---|---|
| First off, let's just make sure we're all on the same page about what the standard visual is. If you graph a function which simply takes real numbers as inputs and outputs, one of the first things you learn in a calculus course is that the derivative gives you the slope of this graph. | 首先，确保我们对「标准的视觉化」有同一幅图景。把一个输入输出都是实数的函数画成图，你在微积分课上学到的头几件事之一就是：导数给出这条图像的斜率。 |
| What we mean by that is that the derivative of the function is a new function which for every input x, returns this slope. | 这么说的意思是：函数的导数是一个新函数，对每个输入 x，它返回这个斜率。 |
| **Quick sanity check! What's the derivative of $\sin (x) x^2$?** | （译注：原文此处是一道互动选择题，选项为 $2\sin(x)^2$；$\cos(x) + 2x$；$x^2 \sin(x) + 2x \sin(x)$；$x^2 \cos(x) + 2x \sin(x)$，正确答案为第四个，解析即下式。）**快速自查一下！$\sin (x) x^2$ 的导数是什么？** |

$$
(\sin(x) x^2)^{\prime} = (x^2)^{\prime} \sin(x) + (\sin(x))^{\prime} x^2 = x^2 \cos(x) + 2x \sin(x)
$$

| 原文 | 译文 |
|---|---|
| I'd encourage you not think of this derivative-as-slope idea as being the definition of the derivative; instead think of the derivative as asking how sensitive is the function to tiny nudges around a given input. The slope of the graph is just one way to think about that sensitivity, relevant only to this particular way of viewing functions. | 我鼓励你别把「导数即斜率」这个想法当作导数的定义；不如把导数想成在问：函数对给定输入周围的微小轻推有多敏感？图像的斜率只是思考这种敏感性（sensitivity）的方式之一，且只与「把函数看成图像」这一种特定视角相关。（译注：原文 not think 系 not to think 之笔误，照录。） |
| The basic idea behind the alternate visual for the derivative is to think of the function as mapping all possible inputs on a number line to their corresponding outputs on a different number line. | 导数的另一种视觉化，其基本想法是把函数想成：把一条数轴上所有可能的输入，映射到另一条数轴上对应的输出。 |
| In this case the derivative gives a measure of how much this input space gets stretched or squished in various regions. That is, if you zoom in around some specific input, and look at some evenly spaced points around it, the derivative of the function at that input will tell you how spread out or contracted those points become. | 在这种图景下，导数度量的是输入空间在各处被拉伸或压缩了多少。也就是说，如果你围绕某个输入放大，看看它周围一些等距的点，函数在该输入处的导数会告诉你：这些点会铺开成什么样、或收缩成什么样。 |
| A specific example helps. The function $f(x) = x^2$ maps the point at $1$ to $1$, the point at $2$ to $4$, the point at $3$ to $9$, and so on. | 一个具体例子会有帮助。函数 $f(x) = x^2$ 把 1 上的点映到 1，把 2 上的点映到 4，把 3 上的点映到 9，依此类推。 |
| If you were to zoom in on a little cluster of points around $1$, and see where they land around the relevant output, which for this function happens to also be $1$, you'd notice they get stretched out. | 如果你放大 1 附近的一小簇点，看看它们落在相应输出（对这个函数来说恰好也是 1）周围何处，你会注意到它们被拉开了。 |
| In fact, it roughly looks like stretching out by a factor of $2$. And the closer you zoom in, the more this local behavior just looks like multiplying by a factor of $2$. This is what it means for the derivative of $x^2$ at $x=1$ to be $2$; it's what that fact looks like in the context of transformations. | 实际上，它大致看起来就像被拉伸了 2 倍。而且放大得越近，这种局部行为就越像「乘以 2」。这就是「$x^2$ 在 $x=1$ 处的导数是 2」的含义；在变换的语境下，这个事实长这个样子。 |
| If you looked at a neighborhood of points around the input $3$, they would roughly get stretched out by a factor of $6$, which is what it means for the derivative of this function at the input $3$ to be $6$. | 如果你看输入 3 附近的一小片点，它们大致会被拉伸 6 倍——这就是「这个函数在输入 3 处的导数是 6」的含义。 |
| **Around the point $x=\frac{1}{4}$, what factor would the surrounding points stretch out by?** | （译注：互动选择题，选项为 $\frac{1}{2}$；$\frac{1}{4}$；$\frac{1}{8}$；$\frac{1}{16}$，正确答案为第一个，解析见下。）**在点 $x=\frac{1}{4}$ 附近，周围的点会被拉伸多少倍？** |
| The derivative of $x^2$ at $x=\frac{1}{4}$ is $\frac{1}{2}$, so the surrounding points would stretch out by a factor of $\frac{1}{2}$. | （译注：上题答案解析。）$x^2$ 在 $x=\frac{1}{4}$ 处的导数是 $\frac{1}{2}$，所以周围的点会被拉伸 $\frac{1}{2}$ 倍。 |
| The input zero is interesting: Zooming in by a factor of $10$, it doesn't exactly look like a constant stretching or squishing. | 输入 0 处很有意思：放大 10 倍之后，它看起来并不完全像一个恒定的拉伸或压缩。 |
| For one thing, all the outputs end up on the right positive side of things. As we zoom in closer, by $100$x, or $1,000$x, it looks more and more like the small neighborhood around zero gets collapsed to a point. | 一方面，所有输出都跑到右边正的那一侧去了。随着我们放得越来越近——100 倍、1000 倍——0 附近的小邻域看起来越来越像被坍缩成了一个点。 |
| This is what it looks like for a derivative to be $0$, the local behavior looks more and more like multiplying a number line by $0$. It doesn't have to completely collapse things to a point at any particular zoom level; instead it's a matter of what the limiting behavior is here. | 这就是「导数为 0」的样子：局部行为越来越像把一条数轴乘以 0。它不必在哪个特定的放大倍数下把东西完全坍缩成一个点；关键在于这里的极限行为是什么。 |
| If you also considered negative inputs, things start to feel a little cramped, since these collide with all those positive input values. This is one downside of thinking of functions transformations. But for derivatives, we only care about local behavior anyway; that is, what happens in a small range around a given input. | 如果你也考虑负的输入，画面就开始有点挤了，因为它们会和那些正的输入值撞在一起。这是把函数想成变换的一个缺点。但对导数来说，反正我们只关心局部行为，也就是给定输入周围小范围内的情形。（译注：原文 thinking of functions transformations 系 thinking of functions as transformations 之漏字，照录。） |
| We really only care about local behavior here. | （译注：此句在官网原文中是 Pi 生物对话气泡里的话。）我们在这里真正只关心局部行为。 |
| Notice that the inputs in a little neighborhood around, say, $-2$, don't just get stretch out, they also get flipped around. | 注意，比如 $-2$ 附近小邻域里的输入，不只是被拉开，还会被翻转。（译注：原文 get stretch out 系 get stretched out 之笔误，照录。） |
| Specifically, the action on such a neighborhood looks more and more like multiplying by $-4$ the closer you zoom in. This is what it looks like for a function to have a negative derivative. | 具体来说，放大得越近，这种邻域上的作用就越像「乘以 $-4$」。这就是「函数有负导数」的样子。 |
| **Given this interpretation of the derivative, can you come up with a formula for it using expressions you're already familiar with?** | （译注：互动选择题，选项为 $f'(x) = dx \cdot dy$；$dy = f'(x) \cdot dx$；$f'(x) = dy$；$f'(x) = dx$，正确答案为第二个，解析见下。）**有了对导数的这种解读，你能用已经熟悉的表达式给它想出一个公式吗？** |
| The interpretation is saying that the points around $x$ are stretched out by a factor of $f'(x)$. In other words, if we were to take a small step $dx$, the resulting step $dy$ is equal to the derivative times the small step $dx$. This is called a differential. | （译注：上题答案解析。）这种解读说的是：$x$ 周围的点被拉伸了 $f'(x)$ 倍。换句话说，如果我们迈出一小步 $dx$，由此产生的一步 $dy$ 就等于导数乘以小步 $dx$。这就叫作微分（differential）。 |

## 这种导数视角的一个应用（An application of this derivative view）

| 原文 | 译文 |
|---|---|
| This is all well and good, but let's see how it's useful in solving a problem. | 这些都很好，但让我们看看它在解题时怎么派上用场。 |
| A friend of mine recently asked me a pretty fun question about this infinite fraction: | 最近一位朋友问了我一个关于这个无穷连分式的相当有趣的问题： |

$$
1 + \frac{1}{1+\frac{1}{1+\frac{1}{1+...}}}
$$

| 原文 | 译文 |
|---|---|
| Maybe you've seen this before, but my friend's questions cuts to something you may not have thought about before, relevant to the view of the derivative we're looking at here. | 也许你见过它，但我朋友的这个问题切中了一个你之前可能没想过的事情，与我们这里看的导数视角有关。（译注：原文 questions cuts 系笔误，照录。） |
| A typical way you might evaluate an expression like this is to first set it equal to $x$. | 求这种表达式的一个典型做法，是先把它设为等于 $x$。 |

$$
x = 1 + \frac{1}{1+\frac{1}{1+\frac{1}{1+...}}}
$$

| 原文 | 译文 |
|---|---|
| Then, notice that there is a copy of the full fraction inside itself, giving us this: | 然后，注意到整个分式在它自己内部有一份拷贝，于是得到： |

$$
x = 1 + \frac{1}{x}
$$

| 原文 | 译文 |
|---|---|
| You can also think of this as finding a fixed point of the function $f(x) = 1 + \frac{1}{x}$. But here's the thing, there are actually two solutions for $x$; two special number where $1$ plus $1$ over that number gives you back the same number. | 你也可以把这想成求函数 $f(x) = 1 + \frac{1}{x}$ 的不动点（fixed point）。但关键在这里：$x$ 其实有两个解——两个特殊的数（译注：原文 two special number 系 numbers 之笔误，照录），1 加上它的倒数还等于它自己。 |
| One is the golden ratio $\varphi$, around $1.618...$, and the other is at $-0.618...$, which is $\frac{-1}{\varphi}$. I like to call this other number $\varphi$'s "little brother", since just about any property $\varphi$ has, this number also has. So would it be valid to say that this infinite fraction also equals $\varphi$'s little brother, $-0.618...$? | 一个是黄金比例（golden ratio）$\varphi$，约 $1.618...$；另一个在 $-0.618...$，也就是 $\frac{-1}{\varphi}$。我喜欢把这个数叫作 $\varphi$ 的「弟弟」，因为 $\varphi$ 有的性质，这个数几乎也都有。那么，说这个无穷连分式也等于 $\varphi$ 的弟弟 $-0.618...$，站得住脚吗？ |
| Which one is the answer? | （译注：此句在官网原文中是 Pi 生物对话气泡里的话。）到底哪个才是答案？ |
| Maybe you initially say "obviously not!". Everything on the left-hand side is positive, so how could it equal a negative number? Well, first let's be clear about what we mean by an expression like this. | 也许你第一反应是「显然不等于！」。左边全都是正数，怎么可能等于一个负数？嗯，我们先把「这样的表达式是什么意思」说清楚。 |
| One way to think of it, though it's not the only way, is to imagine starting with some constant, like $1$, then repeatedly applying the function $1 + \frac{1}{x}$, and asking about what this approaches as you keep going. | 一种理解方式（虽然不是唯一方式）是：想象从某个常数（比如 1）出发，反复施加函数 $1 + \frac{1}{x}$，然后问：一直做下去，它会趋近什么？ |
| So in that view, maybe if you start with a negative number, it's not so crazy for the whole expression to end up negative. | 在那种看法下，如果你从一个负数出发，最终整个表达式落在负数上，倒也不是什么疯狂的事。 |
| After all, if you start with $\frac{-1}{\varphi}$, then apply the function $1 + \frac{1}{x}$, you get back $\frac{-1}{\varphi}$. So no matter how many times you apply it, you'll stay fixed at that value. | 毕竟，如果你从 $\frac{-1}{\varphi}$ 出发，施加函数 $1 + \frac{1}{x}$，得到的还是 $\frac{-1}{\varphi}$。所以不管施加多少次，你都会停在那个值上不动。 |
| Well, even then, there is one reason you view $\varphi$ as the favorite brother in this pair. Try this, pull up a calculator of some kind, start with any random number, then plug it into this function $1 + \frac{1}{x}$. Then do it again. And again. And again and again and again. | 话虽如此，把 $\varphi$ 看成这对兄弟中受宠的那一个，倒是有一个理由。试试看：打开随便什么计算器，从任意一个随机数开始，把它代入函数 $1 + \frac{1}{x}$。然后再来一次。又一次。一次又一次再来再来再来。 |
| No matter what constant you start with, you will eventually end up at $1.618$. Even if you start with a negative number, even one really really close $\varphi$'s little brother, eventually it will shy away from that value and jump back to phi. | 无论你从什么常数出发，最终都会落到 $1.618$。哪怕你从一个负数开始——哪怕这个数离 $\varphi$ 的弟弟近得不能再近——它终究会躲开那个值，跳回到 phi（即 $\varphi$）。（译注：原文 really really close 后漏 to，照录。） |
| So what's going on here? Why is one of these fixed points favored over the other? | 这是怎么回事？为什么这两个不动点里，一个受青睐，另一个不吃香？ |
| Maybe you can already see how the transformational understanding of derivatives will help us to understand this setup, but for the sake of having a point of contrast, let me show how a problem like this is often taught using graphs. | 也许你已经能看出，导数的变换式理解会怎样帮我们弄清这个局面；但为了有一个对照组，让我先展示这类问题通常是怎么用图像来讲的。 |
| If you plug in some random input to this function, the $y$-value tells you the corresponding output. | 如果你给这个函数代入某个随机的输入，$y$ 值会告诉你相应的输出。 |
| To think about plugging that output back into the function, you might first move horizontally until you hit the line $y=x$, which will get you to a position where the $x$-value corresponds to your previous output. | 想把这个输出再代回函数，你可以先水平移动，直到碰到直线 $y=x$，这会把你带到「$x$ 值恰好等于刚才那个输出」的位置。 |
| Then, you can move vertically to see what the output at this new $x$-value is. | 然后，你可以竖直移动，看看这个新 $x$ 值处的输出是多少。 |
| Then repeat: Move horizontally to the line $y=x$ to find a point whose $x$-value is the same as the output you just got, then move vertically to apply the function. | 然后重复：水平移到直线 $y=x$，找到一个 $x$ 值等于你刚得到的输出的点，再竖直移动来施加函数。 |
| Personally, I think this is kind of an awkward way to think about repeatedly applying a function, don't you? I mean, it makes sense, but you kind of have to pause to think about it to remember which way to draw the lines. You can, if you want, think through what conditions make this spider-web process narrow in on a fixed point, vs. propagating away from it. | 就我个人而言，我觉得这种思考「反复施加函数」的方式有点别扭，你觉得呢？我是说，它讲得通，但你多少得停下来想一想，才记得该往哪个方向画线。如果你愿意，可以想想什么条件会让这个蜘蛛网式的过程收拢到不动点上，而不是从它向外发散。 |
| **Try thinking about it. In what cases would the result propagate away from the initial starting value, and in what cases would it narrow down?** | **试着想一想：什么情况下结果会从初始值向外发散，什么情况下会收拢？** |
| When the slope of the graph at the point where it intersects the line $x=y$ is relatively shallow, specifically with an absolute value less than 1, then the lines from this cobweb diagram will spiral in closer and closer to that point. But when this slope has an absolute value greater than 1, each new line drawn tends to go away from that intersection point. | （译注：上题参考答案。）当图像与直线 $x=y$ 交点处的斜率比较平缓——确切说绝对值小于 1——这张蛛网图（cobweb diagram）上的线就会盘旋着越来越近地围向那个点；而当这个斜率的绝对值大于 1 时，每画一条新线都趋于远离那个交点。 |
| But let's turn to how this function acts as a transformation. | 现在来看这个函数作为变换是怎么行动的。 |
| What does it look like to repeatedly apply the $1 + \frac{1}{x}$ in this context? Well, after letting it map all input points to outputs, you consider those as the new inputs and apply that same process again and again. | 在这个图景下反复施加 $1 + \frac{1}{x}$ 是什么样子？让它把所有输入点映成输出之后，你把这些输出当作新的输入，再把同样的过程一遍遍施加下去。（译注：原文 apply the $1 + \frac{1}{x}$ 后漏 function，照录。） |
| Notice how in animating this with these dots representing some sample points, it doesn't take many iterations at all for most dots to clump in around $1.618$. | 注意，用这些点代表一些样本点做动画时，用不了几次迭代，大多数点就聚到了 $1.618$ 周围。 |
| Now, we know that $1.618$ and its little brother $-0.618$ stay fixed in place during each iteration of this process, but zoom in on the neighborhood around $1.618$. | 现在，我们知道 $1.618$ 和它的弟弟 $-0.618$ 在这个过程的每次迭代里都原地不动；但请放大 $1.618$ 周围的邻域。 |
| During the map, points in that region get contracted around $\varphi$, meaning the function $1 + \frac{1}{x}$ has a derivative with magnitude less than 1 at the input $\varphi$. In fact, this derivative works out to be around $-0.38$ at the input $\varphi$. So each repeated application scrunches that neighborhood smaller, like a gravitational pull towards $\varphi$. | 在映射过程中，那一带的点向着 $\varphi$ 收缩，这意味着函数 $1 + \frac{1}{x}$ 在输入 $\varphi$ 处的导数绝对值小于 1。实际上，这个导数在输入 $\varphi$ 处算出来约为 $-0.38$。于是每重复施加一次，那个邻域就被挤得更小，像一股朝向 $\varphi$ 的引力。 |
| So now tell me what you think happens in a neighborhood of $\varphi$'s little brother. | 那么，你猜猜在 $\varphi$ 的弟弟的邻域里会发生什么？ |
| There, the derivative has a magnitude larger than $1$, so points near this fixed point are repelled away from it, by more than a factor of $2$ each iteration. Mathematicians would call this right value a "stable" fixed point, while the left one is an "unstable fixed point". Something is considered stable if when you perturb it a little, it tends to come back towards where it started, rather than going away. | 在那里，导数的绝对值大于 1，所以靠近这个不动点的点会被推离它，每次迭代都被推开不止 2 倍。数学家会把右边这个值叫作「稳定」（stable）不动点，而左边那个是「不稳定不动点」（unstable fixed point）。一个东西算稳定，是说当你稍微扰动它一下，它倾向于回到出发点，而不是跑开。 |
| So the stability of a fixed point is determined by whether the magnitude of its derivative is bigger or smaller than $1$, and this explains why $\varphi$ always shows up in the numerical play, and $\varphi$'s little brother does not. As to whether or not you want to consider $\varphi$'s little brother a valid value of our infinite fraction? Well, that's really up to you. Everything we just showed suggests that if you think of this expression as representing a limiting process, only phi makes sense. But maybe you think of it not as a limit, but as a static, purely algebraic object. | 所以，不动点稳不稳定，取决于它导数的绝对值比 1 大还是小；这也解释了为什么数值实验里 $\varphi$ 总是现身，而 $\varphi$ 的弟弟从不露面。至于你要不要把 $\varphi$ 的弟弟算作这个无穷连分式的合法取值？嗯，这真的由你决定。我们刚才展示的一切都表明：如果你把这个表达式理解成一个极限过程，那只有 phi（即 $\varphi$）说得通；但也许你不把它看成极限，而看成静态的、纯代数的对象。 |
| Either way, math is cool! | （译注：此句在官网原文中是 Pi 生物对话气泡里的话。）不管怎样，数学真酷！ |
| My point here not that understanding derivatives as measuring changes in density like this is somehow better than the graphical view on the whole. In fact, picturing an entire function this way, as opposed to a small window, can be clunky and impractical as compared to graphs. My point is that it deserves more of a mention in most introductory calculus courses, and can help make a student's understanding of the derivative a little more flexible. | 我在这里的要点并不是说，把导数理解成这样度量密度变化，就整体上比图像视角更高明。事实上，用这种方式去看一整个函数（而不是一个小窗口），跟图像比起来可能又笨重又不实用。我的要点是：它值得在大多数微积分入门课里多提一嘴，能让学生对导数的理解更灵活一点。（译注：原文 My point here not that 系 is not that 之漏字，照录。） |
| But as I mentioned, the real reason I'd recommend you carry this perspective with you as you learn new topics is not so much for how it will strengthen your understanding of single-variable calculus, but for what comes after. There are many topics typically taught in a college math department, which don't exactly have a reputation of being incredibly accessible. | 但正如我所说，我建议你在学习新话题时随身带着这个视角，真正的理由与其说是它会加深你对单变量微积分的理解，不如说是为了之后的东西。大学数学系里教的许多话题，可从来算不上以「平易近人」闻名。 |
| Understanding the transformation view of derivatives provides a great pathway into topics such as multivariable calculus, complex analysis and differential geometry. | 理解导数的变换视角，为通往多元微积分、复分析和微分几何这类话题提供了一条绝佳的路径。 |
