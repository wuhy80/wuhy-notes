## 不同的指数函数（Different Exponentials）

| 原文 | 译文 |
|---|---|
| There's not much special to the number $2$ here. If instead had we dealt with the function $3^t$, the exponential property would also have led us to the conclusion that the derivative of $3^t$ is proportional to itself, but this time with a proportionality constant of about $1.0986$. | 这里的数字 $2$ 其实没什么特别的。假如我们当初处理的是函数 $3^t$，指数性质同样会引导我们得出结论：$3^t$ 的导数与它自己成正比，只是这次比例常数约为 $1.0986$。 |
| For any other base to your exponent you can have fun seeing what the various proportionality constants are, maybe trying to find a pattern. | 换成任何其他底数，你都可以乐呵呵地看看各个比例常数是多少，没准还能找出一个模式。 |
| Notice how the proportionality constant for the derivative changes from less than $1$ for a base of $2$ to greater than $1$ for a base of $3$. | （图注）注意导数的比例常数如何从底数为 $2$ 时小于 $1$，变到底数为 $3$ 时大于 $1$。 |
| For example, if you plug in $8$ as the base of the exponential function, you can see the relevant proportionality constant is around $2.079$. And maybe, just maybe, you would notice that this number happens to be exactly $3$ times the constant associated with the base of $2$. So these numbers aren't random, there is some pattern. But what is the pattern? What does $2$ have to do with $0.6931$ and what does $8$ have to do with $2.079$. | 比如，如果你把 $8$ 代入作为指数函数的底数，你会看到相应的比例常数约为 $2.079$。而且，说不定，仅仅是说不定，你会注意到这个数恰好是底数 $2$ 所对应常数的 $3$ 倍。所以这些数并非随机，其中存在某种模式。可模式是什么呢？$2$ 和 $0.6931$ 有什么关系？$8$ 又和 $2.079$ 有什么关系？ |

## 欧拉数（Euler's Number）

| 原文 | 译文 |
|---|---|
| As it turns out, there is a number. It's the special constant $e$, around $2.71828$, called Euler's number. In fact, it's not just that $e$ happens to show up here, this is, in a sense, what defines the number $e$. This special exponential function with Euler's Number as the base is called _the exponential function_. | 结果证明，确实有这么一个数。它就是特殊的常数 $e$，约为 $2.71828$，叫作欧拉数（Euler's number）。事实上，并不只是 $e$ 碰巧在这里现身；从某种意义上说，这正是定义数 $e$ 的东西。这个以欧拉数为底的特殊指数函数，就叫作_指数函数_（the exponential function）。 |
| If you ask, why does $e$ of all numbers have this property? It's a little like asking why does $\pi$ of all numbers happen to be the ratio of the circumference of a circle to its diameter. This is, at its heart, what defines this value. | （译注：原文脚注。）如果你要问：为什么偏偏是 $e$ 这个数有这条性质？这有点像在问：为什么偏偏是 $\pi$ 碰巧成了圆的周长与直径之比。从根子上说，这正是定义这个值的东西。 |
| All exponential functions are proportional to their own derivative, but the _exponential function_ base $e$ alone is the special number so that the proportionality constant is $1$, meaning $e^t$ actually equals its own derivative. | 所有指数函数都与自己的导数成正比，但唯有以 $e$ 为底的_指数函数_，其底数是个特殊的数，使比例常数为 $1$——也就是说，$e^t$ 真的等于它自己的导数。 |

$$
\frac{d}{dt} \left ( e^{t} \right ) = e^{t}
$$

|---|---|
| If you look at the graph of $e^t$, it has the peculiar property that the slope of a tangent line to any point on the graph equals the height of that point above the horizontal axis. | 如果你去看 $e^t$ 的图像，它有一条奇特的性质：图像上任一点处切线的斜率，等于该点高出横轴的高度。 |
| Examples of the slope of the tangent line for the exponential function. | （图注）指数函数切线斜率的几个例子。 |
| So how does the exponential function help us find the derivatives of other exponential functions? Well, maybe you noticed that different exponentials look like horizontally scaled versions of each other. This is true for all exponential functions, but best seen with exponential functions with related bases. | 那么，指数函数怎样帮我们求其他指数函数的导数呢？嗯，也许你已经注意到，不同的指数函数看起来像是彼此横向缩放的版本。这对所有指数函数都成立，但在底数相关的指数函数之间最一目了然。 |
| This means that you can re-write one exponential in terms of another's base. For example, if we have an exponential function of base $2$ and want to re-write the function in terms of base $4$, it can be written like this. | 这意味着你可以用另一个函数的底数来重写一个指数函数。比如，如果我们有一个以 $2$ 为底的指数函数，想用以 $4$ 为底来重写它，可以这样写： |

$$
2^{x} = 4^{\frac{1}{2} \cdot x}
$$

| 原文 | 译文 |
|---|---|
| One way to see how to convert between two bases is to zoom in on the graph between $0$ and $1$ to see how fast the first base grows to to the value of the second base. In this case, base $4$ grows twice as fast as base $2$ and reaches the output of $2$ in half the time. So to convert base $4$ to base $2$ we can multiply the input $t$ of the base $4$ function by the constant $\frac{1}{2}$, which is the same as scaling $4^x$ by a factor of $2$ in the horizontal direction. | （译注：原文 grows to to 中第二个 to 系笔误，照录。）想看怎么在两个底数之间换算，一个办法是放大 $0$ 到 $1$ 之间的图像，看第一个底数以多快的速度长到第二个底数的值。在这个例子里，底数 $4$ 的增长速度是底数 $2$ 的两倍，用一半的时间就到达输出 $2$。所以要把底数 $4$ 换成底数 $2$，我们可以给底数 $4$ 函数的输入 $t$ 乘上常数 $\frac{1}{2}$——这等价于把 $4^x$ 在水平方向缩放 $2$ 倍。 |
| So we've found a function, _the exponential function_ of base $e$, with a really nice derivative property. Can we take any old exponential function and re-write it in terms of the exponential function? Or in other words, what constant do we multiply the input variable by to make the exponential function have the same output as another exponential function? | 于是我们找到了一个函数——以 $e$ 为底的_指数函数_——它有一条非常漂亮的导数性质。我们能不能随便拿一个旧的指数函数，把它用以指数函数来重写？换句话说，要给输入变量乘上一个什么常数，才能让指数函数的输出与另一个指数函数相同？ |
| For example, let's try to re-write $2^t$ in terms of the exponential function. | 比如，我们试着用指数函数来重写 $2^t$： |

$$
e^{c \cdot t} = 2^{t}
$$

| 原文 | 译文 |
|---|---|
| As before, we can zoom in on a plot of the two functions, and compare their behavior. Specifically, how long does it take the exponential function to grow to $2$? | 和前面一样，我们可以放大这两个函数的图像，比较它们的行为。具体说：指数函数要长到 $2$，需要多长时间？ |
| Well, looking at the graph, it takes about $t=0.693...$ units which is exactly equal to the same proportionality constant we found before! If we multiply the input variable $t$ in the exponential function by this constant, the exponential function has the same output as $2^t$. | 看图像，大约需要 $t=0.693...$ 个单位——这恰好等于我们之前找到的那个比例常数！如果给指数函数的输入变量 $t$ 乘上这个常数，指数函数的输出就与 $2^t$ 相同了。 |

## 自然对数（Natural logarithm）

| 原文 | 译文 |
|---|---|
| The existence of a function like this can answer the question of the mystery constants, and it's because it gives a different way to think about functions that are proportional to their own derivative. There's nothing fancy here, this is simply the definition of the natural log, which asks the question "$e$ to the what equals $2$". | 这样一个函数的存在，能解开神秘常数之谜，因为它给了我们一条不同的思路，来思考「与自己的导数成正比」的函数。这里没有什么花哨的东西：这就是自然对数的定义，它问的问题是「$e$ 的多少次方等于 $2$」。 |

$$
e^{??} = 2
$$

| 原文 | 译文 |
|---|---|
| And indeed, go plug in the natural log of $2$ to a calculator, and you'll find that it's $0.6931...$, the mystery constant we ran into earlier. And same goes for all the other bases, the mystery proportionality constant that pops up when taking derivatives and when re-writing exponential functions using $e$ is the natural log of the base; the answer to the question "$e$ to the what equals that base". | 确实如此：去计算器里按一下 $2$ 的自然对数，你会发现它是 $0.6931...$——我们早先撞见的那个神秘常数。其他所有底数也一样：无论在求导时，还是在用 $e$ 重写指数函数时，冒出来的那个神秘比例常数，就是底数的自然对数——也就是「$e$ 的多少次方等于那个底数」的答案。 |
| Importantly, the natural logarithm function gives us the missing tool we need to find the derivative of _any_ exponential function. The key is to re-write the function and then use the chain rule. For example, what is the derivative of the function $3^t$? Well, let's re-write this function in terms of the _exponential function_ using the natural logarithm to calculate the horizontally-scaling proportionality constant. | 重要的是，自然对数函数给了我们那件缺失的工具，用来求_任何_指数函数的导数。关键在于先重写函数，然后用链式法则。比如，函数 $3^t$ 的导数是什么？嗯，我们用自然对数算出横向缩放的比例常数，把这个函数用以_指数函数_重写： |

$$
3^{t} = e^{\ln(3)t}
$$

| 原文 | 译文 |
|---|---|
| Then, we can calculate the derivative of $e^{\ln(3)t}$ using the chain rule by. First, take the derivative of the outermost function, which due to the special nature of the exponential function is itself. Then, second, multiply this by the derivative of the inner function $\ln(3)t$, which is the constant $\ln(3)$. | （译注：原文 using the chain rule by 之 by 系衍字，照录。）然后，我们就可以用链式法则计算 $e^{\ln(3)t}$ 的导数。第一步，取最外层函数的导数——由于指数函数的特殊性质，它就是它自己。第二步，把它乘以内层函数 $\ln(3)t$ 的导数，也就是常数 $\ln(3)$。 |

$$
\frac{d}{dt} \left( e^{\ln(3)t} \right) = e^{\ln(3)t} \cdot \ln(3)
$$

| 原文 | 译文 |
|---|---|
| This is the same derivative we found using algebra above, since $\ln(3) = 1.09861228867...$ | 这与上面用代数找到的导数是同一个，因为 $\ln(3) = 1.09861228867...$ |

$$
\frac{d}{dt} \left( 3^t \right) = 3^t \cdot \ln(3)
$$

| 原文 | 译文 |
|---|---|
| The same technique can be used to find the derivative of any exponential function. | 同样的技巧可以用来求任何指数函数的导数。 |

$$
\frac{d\left(a^{t}\right)}{d t}=a^{t} \ln (a)
$$

| 原文 | 译文 |
|---|---|
| In fact, throughout applications of calculus, you rarely see exponentials written as some base to a power $t$. Instead you almost always write exponentials as $e$ raised to some constant multiplied by $t$. It's all equivalent; any function like $2^t$ or $3^t$ can be written as $e^{c \cdot t}$. The difference is that framing things in terms of the exponential function plays much more smoothly with the process of derivatives. | 实际上，纵观微积分的各种应用，你很少见到指数函数写成「某个底数的 $t$ 次幂」，你几乎总是把它们写成 $e$ 的「某个常数乘以 $t$」次幂。它们完全等价：像 $2^t$ 或 $3^t$ 这样的函数都可以写成 $e^{c \cdot t}$。区别在于，用指数函数来框定事物，与求导的过程配合起来顺畅得多。 |

## 为什么我们在乎（Why we care）

| 原文 | 译文 |
|---|---|
| I know this is all pretty symbol heavy, but the reason we care is that all sorts of natural phenomena involve a certain rate of change being proportional to the thing changing. | 我知道这一切符号都相当重，但我们关心它的原因是：形形色色的自然现象里，都有某种变化率与正在变化的那个量成正比。 |
| For example, the rate of growth of a population actually does tend to be proportional to the size of the population itself, assuming there isn't some limited resource slowing that growth down. If you put a cup of hot water in a cool room, the rate at which the water cools is proportional to the difference in temperature between the room and the water. Or said differently, the rate at which that difference changes is proportional to itself. If you invest your money, the rate at which it grows is proportional to the amount of money there at any time. | 比如，只要没有某种有限资源拖慢增长，种群的增长率确实往往与种群自身的规模成正比。如果你把一杯热水放进凉爽的房间，水冷却的速率正比于房间与水之间的温差；换句话说，那个差值自身的变化率正比于它自己。如果你投资你的钱，钱增长的速度正比于任一时刻钱的总量。 |
| In all these cases, where some variable's rate of change is proportional to itself, the function describing that variable over time will be some exponential. And even though there are lots of ways to write any exponential function, it's very natural to choose to express these functions as $e^{ct}$, since that constant $c$ in the exponent carries a very natural meaning: It's the same as the proportionality constant between the size of the changing variable and the rate of change. | 在所有这些情形里——某个变量的变化率与它自己成正比——描述该变量随时间变化的函数都会是某个指数函数。尽管任何一个指数函数都有很多种写法，选择把这些函数表达成 $e^{ct}$ 是非常自然的，因为指数里那个常数 $c$ 有着非常自然的含义：它就等于「变化中的变量的大小」与「变化率」之间的比例常数。 |
