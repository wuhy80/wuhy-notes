## 开场：一部被撕掉结尾的剧本

| 原文 | 译文 |
|---|---|
| Imagine you happen across a short movie script that describes a scene between a person and their AI assistant. The script has what the person asks the AI, but the AI's response has been torn off. | 想象你偶然间碰到一部短片剧本，写的是一个人和他的 AI 助手之间的一场戏。剧本上留着人对 AI 说了什么，可 AI 的回答却被撕掉了。 |
| Suppose you also have this powerful machine that can take in any text and provide a sensible prediction of what word comes next. You could then finish the script by feeding in what you have to the machine, seeing what it would predict to start the AI's answer, and then repeating this over and over with a growing script completing the dialogue. | 再假设你还有这么一台强大的机器：喂给它任何文本，它都能对「下一个词是什么」给出合情合理的预测。这样你就能把剧本补完——把手头的内容喂给机器，看它预测 AI 的回答会以哪个词开头，然后一遍又一遍重复这个过程，剧本越滚越长，对话也就补完了。 |
| The machine, after being fed **Can you explain...a semiconductor device...**, predicts the word _used_. | 机器被喂入 **Can you explain...a semiconductor device...** 之后，预测出的词是 _used_。 |
| The machine, after being fed **Can you explain...semiconductor device used...**, predicts the word _to_. | 机器被喂入 **Can you explain...semiconductor device used...** 之后，预测出的词是 _to_。 |
| When you interact with a chatbot, this is exactly what's happening. | 当你和聊天机器人（chatbot）互动时，正在发生的正是这件事。 |

> [!note]- 词汇注释 · 开场
> - **script** /skrɪpt/ —— 剧本；在编程语境里是「脚本」。
> - **sensible** /ˈsensəbl/ —— 合情合理的、讲得通的。a sensible prediction。
> - **prediction** /prɪˈdɪkʃn/ —— 预测。动词 predict。
> - **chatbot** /ˈtʃætbɒt/ —— 聊天机器人。chat + bot。
> - *happen across* —— 偶然碰到、撞见。= come across。
> - *tear off* —— 撕下来。the response has been torn off（被动语态）。
> - *over and over* —— 一遍又一遍地。

## 什么是大语言模型？（What is an LLM?）

| 原文 | 译文 |
|---|---|
| A large language model(LLM) is a **sophisticated mathematical function that predicts what word comes next for any piece of text**. | 大语言模型（Large Language Model，LLM）是**一个精密复杂的数学函数：对任何一段文本，它都能预测出下一个词是什么**。 |
| Instead of predicting one word with certainty, though, what it does is assign a probability to all possible next words. | 不过，它并不是笃定地预测某一个词，而是给所有可能的下一个词各分配一个概率。 |
| To build a chatbot, you first lay out some text that describes an interaction between a user and a hypothetical AI assistant. | 要搭一个聊天机器人，你得先铺好一段文本，描述用户与一个假想 AI 助手之间的互动。 |
| Then, you add on whatever the user types in as the first part of the interaction. | 然后，把用户键入的内容接在后面，作为这段互动的第一部分。 |
| Finally, you have the model repeatedly predict the next word that this hypothetical AI assistant would say in response, and that is what's presented to the user. | 最后，让模型反复预测这个假想 AI 助手接下来会说什么来回应——而呈现给用户的，正是这些内容。 |
| Feeding the model the green text and user input, as well as what the model has already generated, produces a probability distribution where the model selects the word _option_. | 把绿色文本、用户输入以及模型已经生成的内容一起喂给模型，会产出一个概率分布（probability distribution），模型从中选中了 _option_ 这个词。 |
| You might notice that, in the image, the model didn't select the most likely word. This isn't always the case, but is done by the model because the output tends to look a lot more natural if you allow it to select less likely words along the way at random. | 你可能注意到了，图中的模型并没有选中概率最高的那个词。情况并不总是如此；模型这么做，是因为如果允许它沿途随机挑一些不那么可能的词，输出往往会显得自然得多。 |
| What this means is even though the model itself is deterministic, a given prompt typically gives a different answer each time it's run. | 这意味着：尽管模型本身是确定性的（deterministic），但同一个提示词（prompt）每次运行，得到的回答通常各不相同。 |

> [!note]- 词汇注释 · 什么是 LLM
> - **sophisticated** /səˈfɪstɪkeɪtɪd/ —— 精密复杂的。形容系统、函数的精巧程度。
> - **assign** /əˈsaɪn/ —— 分配、指派。assign a probability to each word。
> - **hypothetical** /ˌhaɪpəˈθetɪkl/ —— 假想的、假设的。
> - **deterministic** /dɪˌtɜːmɪˈnɪstɪk/ —— 确定性的：同样输入必得同样输出。
> - **probability distribution** —— 概率分布。
> - *lay out* —— 铺好、摆好。
> - *with certainty* —— 确定无疑地。反义对照：at random 随机地。

## 大语言模型怎么预测下一个词？（How does an LLM predict the next word?）

| 原文 | 译文 |
|---|---|
| Models learn how to make these predictions by processing an enormous amount of text, typically pulled from the internet. | 模型靠处理海量的文本来学会做这类预测，这些文本通常取自互联网。 |
| Fun fact: For a standard human to read the amount of text that was used to train GPT-3, they would need to read non-stop, 24-7, for over 2,600 years. Larger models since then, such as GPT-4, train on much, much more data. | 冷知识：一个普通人要想读完训练 GPT-3 所用的文本量，得不吃不睡、全天候 24/7 连轴转地读上 2600 多年。而此后更大的模型，比如 GPT-4，训练数据还要多得多、多得多。 |
| Training a model can be thought of as tuning the dials on a really big machine. The way that a language model behaves is entirely determined by these many different continuous values, usually called _parameters_ or _weights_. | 训练模型，可以想成在一台巨大的机器上拧旋钮。语言模型的行为方式，完全由这许多不同的连续数值决定，它们通常被叫作*参数*（parameters）或*权重*（weights）。 |
| Changing these parameters is like changing the probabilities that the model gives for the next word on a given input. | 改动这些参数，就相当于改变模型对给定输入所给出的「下一个词」概率。 |
| What puts the _large_ in large language model is how they can have hundreds of billions of these parameters. | 让 large language model 里的 _large_ 名副其实的，是它们的参数可以多达几千亿个。 |
| No human ever deliberately sets those parameters, though. Instead, they begin at random, meaning the model just outputs gibberish. Then, they're repeatedly refined based on many example pieces of text. | 不过，从来没有人刻意去设定这些参数。它们一开始是随机的——也就是说模型只会输出胡言乱语（gibberish）——然后基于大量示例文本被反复打磨。 |
| These training examples could be just a handful of words, or they could be thousands of words. In either case, the way this training works is you pass in all but the last word from that example into the model and compare the prediction that it makes with the true last word from the example. | 这些训练样本可能只有寥寥几个词，也可能有成千上万个词。不管是哪种，训练的方式都是：把样本里除最后一个词之外的全部内容喂给模型，再拿它的预测和样本里真正的最后一个词做比较。 |
| An algorithm called backpropagation is then used to tweak all of the parameters in such a way that it makes the model a little _more_ likely to choose the true last word and a little _less_ likely to choose all the other words. | 接着用一个叫反向传播（backpropagation）的算法去微调（tweak）所有参数，让模型选中那个真正末词的可能性稍微*变大*一点，选中其他所有词的可能性稍微*变小*一点。 |
| When this process is done for many, many trillions of examples, not only does the model start to give more accurate predictions on the training data, but it also starts to make more reasonable predictions on text that it's never seen before. | 当这个过程在数以万亿计的样本上反复做完，模型不仅对训练数据的预测变得更准，对从没见过的文本也开始做出更合理的预测。 |
| Given the huge number of parameters and the enormous amount of training data a model has to go through, the scale of computation involved in training a large language model is, to say the least, mind-boggling. | 考虑到参数之多、模型要过一遍的训练数据之巨，训练一个大语言模型所涉及的计算量，往轻了说也令人脑子嗡掉（mind-boggling）。 |
| To put it into perspective, let's imagine that you could perform 1,000,000,000 additions and multiplications **every single second**. | 给你个参照系：假设你每一**秒**都能完成 10 亿次加法和乘法。 |
| How long do you think it would take for you to do all of the operations involved in training the largest language models? A year? 10,000 years? | 你猜，算完训练那些最大语言模型所需的全部运算要花多久？一年？一万年？ |
| It will actually take you well over **100,000,000** years. | 实际上，你要花掉远超 **1 亿**年。 |
| This process we just talked about is called **pre-training**, and is only part of training a chatbot goes through. | 我们刚才讲的这个过程叫**预训练**（pre-training），它只是聊天机器人所受训练的一部分。 |
| The goal of auto-completing a random passage of text from the internet is very different from the goal of being a good AI assistant. To address this, chatbots undergo another type of training, one just as important, called **reinforcement learning with human feedback(RLHF)**. | 「补全一段来自互联网的随机文本」这个目标，和「当一个好的 AI 助手」的目标非常不同。为了解决这个问题，聊天机器人还要经历另一种同样重要的训练，叫**基于人类反馈的强化学习**（reinforcement learning with human feedback，RLHF）。 |
| Here, workers flag unhelpful or problematic predictions. Their corrections further change the model's parameters, making them more likely to give predictions that users prefer. | 在这一步，工作人员会把没帮助或有问题的预测标记（flag）出来；他们的纠正进一步改动模型参数，让模型更有可能给出用户偏好的回答。 |
| Looking back at the pre-training, though, this staggering amount of computations is only made possible by using special computer chips that are optimized for running many operations in parallel, known as GPUs. | 回头再看预训练：这样惊人的计算量之所以可能，靠的是一种专门的计算机芯片——为并行跑大量运算而优化的 GPU（图形处理器）。 |
| But not all language models can be easily parallelized. Prior to 2017, most language models would process text _one word at a time_. Then a team of researchers at Google introduced a new model known as the **transformer**. | 但并非所有语言模型都能轻松并行化。2017 年以前，大多数语言模型都是*一次一个词*地处理文本。后来，Google 的一支研究团队推出了一种叫 **transformer** 的新模型。 |
| Transformers don't read text from the start to the finish, they soak it all in at once, in parallel. | Transformer 读文本不是从头读到尾，而是一口气把全文并行地吸收进来。 |

> [!note]- 词汇注释 · 预测下一词
> - **parameter** /pəˈræmɪtə/ —— 参数。模型里可调的连续数值，与 weights 同义。
> - **gibberish** /ˈdʒɪbərɪʃ/ —— 胡言乱语。参数随机时模型的输出。
> - **refine** /rɪˈfaɪn/ —— 打磨、精炼。be refined based on...。
> - **tweak** /twiːk/ —— 微调。比 adjust 更轻的调整。
> - **trillion** /ˈtrɪljən/ —— 万亿（10 的 12 次方）。trillions of examples。
> - **mind-boggling** /ˈmaɪndˌbɒɡlɪŋ/ —— 令人难以想象的。boggle the mind = 让脑子卡壳。
> - *to put it into perspective* —— 给个参照系，让你对数量级有概念。
> - *soak it all in* —— 一口气全部吸收进去。

## Transformer 架构（Transformers）

| 原文 | 译文 |
|---|---|
| The very first step inside a transformer, and most other language models for that matter, is to associate each word with a long list of numbers. This is due to the fact that the training process only works with continuous values, so you have to somehow encode language using numbers. | Transformer 内部（顺带一提，大多数其他语言模型也一样）的第一步，是把每个词关联到一长串数字上。这是因为训练过程只认连续数值，所以你必须设法用数字来给语言编码（encode）。 |
| Each one of these long lists of numbers must somehow encode the meaning of the corresponding word. | 这些长串数字中的每一串，都得设法编码出对应词的含义。 |
| What makes transformers unique is their reliance on a special operation known as attention. This operation gives all of these lists of numbers a chance to communicate with one another and refine the meanings they encode based on the _context_ around, all done in parallel. | Transformer 的独门绝活，是一种叫注意力（attention）的特殊运算。这个运算让所有这些数字串有机会互相通信，并根据周围的*上下文*（context）精炼各自编码的含义——全程并行完成。 |
| For example, in the image above, the numbers encoding the word _bank_ might be changed based on the context surrounding it, like _river_ and _jumped into_, to somehow encode the more specific notion of a _riverbank_. | 比如，在上图中，编码 _bank_ 一词的数字，会根据它周围的语境（比如 _river_ 和 _jumped into_）发生改变，从而编码出更具体的「河岸」（riverbank）概念。 |
| Transformers typically also include a second type of operation known as a feed forward neural network/Multi-layer Perceptron. This operation gives the model an extra capacity to store more patterns about language that it learned during training. | Transformer 通常还包含第二类运算，叫前馈神经网络（feed forward neural network），也叫多层感知机（Multi-layer Perceptron，MLP）。这个运算给模型额外的容量，用来存储训练中学到的更多语言模式。 |
| All of this data then repeatedly flows through many different iterations of these two fundamental operations. As it does so, the hope is that each list of numbers is enriched to encode whatever information might be needed to make an accurate prediction of the next word in the passage. | 然后，所有这些数据会反复流经这两个基本运算的许多轮迭代。在这个过程中，期望的结果是：每一串数字都被充实起来，编码上准确预测文中下一个词可能需要的任何信息。 |
| At the end, one final function is performed on the last vector in this sequence, which now has been updated by all of the context from the input text as well as everything the model learned during training, to produce a prediction of the next word. | 到了最后，会对序列中的最后一个向量执行一个最终函数——此时这个向量已经被输入文本的全部上下文、以及模型训练中学到的一切更新过——从而产出对下一个词的预测。 |
| The model's prediction looks like a probability for every possible next word. | 模型的预测，看起来就是给每个可能的下一个词一个概率。 |
| While researchers do design the framework for how each of these steps work, it's important to understand that the specific behavior is an emergent phenomenon based on how those hundreds of billions of parameters are tuned during training. This makes it incredibly challenging to understand _why_ the model makes the exact predictions that it does. | 研究者确实设计了每一步如何运作的框架，但很重要的一点是：模型的具体行为是一种涌现现象（emergent phenomenon），取决于那几千亿个参数在训练中被调成了什么样。这也让我们极难搞清，模型*为什么*恰好做出它所做的那些预测。 |

> [!note]- 词汇注释 · Transformer
> - **associate ... with ...** —— 把……与……关联起来。
> - **encode** /ɪnˈkəʊd/ —— 编码。反义 decode 解码。
> - **reliance** /rɪˈlaɪəns/ —— 依赖、倚重。reliance on...。
> - **context** /ˈkɒntekst/ —— 上下文、语境。
> - **perceptron** /pəˈseptrɒn/ —— 感知机。Multi-layer Perceptron 多层感知机。
> - **iteration** /ˌɪtəˈreɪʃn/ —— 迭代、一轮。
> - **emergent** /ɪˈmɜːdʒənt/ —— 涌现的。emergent phenomenon 涌现现象。
> - *for that matter* —— 顺带一提，就此而言（把话扩展到同类对象）。
