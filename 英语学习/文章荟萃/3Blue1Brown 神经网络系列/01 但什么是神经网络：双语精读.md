## 神经网络的结构（The Structure of a Neural Network）

| 原文 | 译文 |
|---|---|
| This lesson is all about motivating and understanding the structure and mathematical description of a neural network, while the next lesson will focus on how to train it with labeled examples. | 这一课的全部目标，就是让你明白神经网络为什么长这样，并理解它的结构与数学描述；下一课则聚焦如何用带标签的样本来训练它。 |
| There are many variants of neural networks, such as convolutional neural networks (CNN), recurrent neural networks (RNN), transformers, and countless others. In recent years there's been a boom in research of these variants. But the first step to understanding any of them is to build up the simplest, plain vanilla form with no added frills. | 神经网络有很多变体，比如卷积神经网络（CNN）、循环神经网络（RNN）、Transformer 等等，不胜枚举。近年来，这些变体的研究热火朝天。但要理解其中任何一个，第一步都是先搭出最简单、最「原味」的形式——不加任何花哨点缀。 |
| The simple network we're using to identify digits is just a few layers of neurons linked together. | 我们用来识别数字的这个简单网络，不过是几层连在一起的神经元。 |
| **Neurons** | **神经元** |
| Right now, when I say neuron, all I want you to think is "a thing that holds a number." Specifically, a number between 0.0 and 1.0. Neural networks are really just a bunch of neurons connected together. | 现在，当我说神经元（neuron）时，你只需要想到「一个装着数字的东西」。具体来说，是 0.0 到 1.0 之间的一个数。神经网络说白了，就是一堆连在一起的神经元。 |
| This number inside the neuron is called the "activation" of that neuron, and the image you might have in your mind is that each neuron is lit up when its activation is a high number. | 神经元里的这个数，叫作该神经元的「激活值」（activation）。你脑海里可以浮现这样一幅图景：激活值一高，神经元就被点亮。 |
| Every neuron has an activation between 0.0 and 1.0, sort of analogous to how neurons in the brain can be active or inactive. | 每个神经元都有一个 0.0 到 1.0 之间的激活值，有点类似于大脑中的神经元可以被激活或不激活。 |
| All the information passing through our neural network is stored in these neurons. So we need to represent the inputs and outputs of our network (the images and digit predictions) in terms of these neuron values between 0.0 and 1.0. | 流经神经网络的所有信息，都储存在这些神经元里。所以我们需要把网络的输入和输出（图像与数字预测），统统用这些 0.0 到 1.0 之间的神经元数值来表示。 |
| Each pixel in the original image has a value between 0.0 (black) and 1.0 (white). | 原始图像里的每个像素，取值都在 0.0（黑）到 1.0（白）之间。 |
| All of our digit images have $28 \times 28 = 784$ pixels, each with a brightness value between 0.0 (black) and 1.0 (white). To represent this in the network, we'll create a layer of 784 neurons, where each neuron corresponds to a particular pixel. | 我们的数字图像都有 $28 \times 28 = 784$ 个像素，每个像素的亮度值介于 0.0（黑）与 1.0（白）之间。为了在网络中表示它，我们会建一层共 784 个神经元，每个神经元对应一个特定的像素。 |
| The input layer contains 784 neurons, each of which corresponds to a single pixel in the original image. | 输入层（input layer）包含 784 个神经元，每个对应原图中的一个像素。 |
| When we want to feed the network an image, we'll set each input neuron's activation to the brightness of its corresponding pixel. | 想给网络喂一张图像时，我们就把每个输入神经元的激活值设为它所对应像素的亮度。 |
| The last layer of our network will have 10 neurons, each representing one of the possible digits. The activation in these neurons, again some number between 0.0 and 1.0, will represent how much the system thinks an image corresponds to a given digit. | 网络的最后一层将有 10 个神经元，每个代表一个可能的数字。这些神经元的激活值——同样是一个 0.0 到 1.0 之间的数——代表系统认为这张图像在多大程度上对应某个给定数字。 |
| The output layer of our network has 10 neurons. Each neuron corresponds to a particular digit that the image could contain. | 网络的输出层（output layer）有 10 个神经元，每个对应图像可能包含的一个特定数字。 |
| Take a look at the following image: | 看看下面这张图： |
| Based on the output layer of the network shown above, what kind of digit does this network think it's looking at? How certain does it feel? | 根据上图的输出层，这个网络觉得自己看到的是什么数字？它的把握有多大？ |
| It's having trouble deciding whether the input image is a 4 or a 9. | 它正拿不定主意：输入的图像到底是 4 还是 9。 |
| **The Hidden Layers** | **隐藏层** |
| There will also be some layers in between, called "hidden layers", which for the time being should just be a giant question mark for how on earth this process of recognizing digits will be handled. | 中间还会有一些层，叫「隐藏层」（hidden layers）。至于「识别数字这个过程究竟是怎么处理的」，眼下它们对你来说就该是个巨大的问号。 |
| In this network I have 2 hidden layers, each with 16 neurons, which is admittedly kind of an arbitrary choice. To be honest, I chose 2 layers based on how I want to motivate the structure in just a moment, and 16 was simply a nice number to fit on the screen. In practice, there's a lot of room to experiment with the specific structure. | 这个网络里我放了 2 个隐藏层，每层 16 个神经元——无可否认，这是个挺随便的选择。老实讲，我选 2 层，是因为这样安排待会儿讲结构动机时最顺；16 则纯粹是个「正好能塞进屏幕」的好数字。实践中，具体结构大可以拿来做实验。 |

> - *plain vanilla* —— 最朴素、不加料的「原味」版本。vanilla 本义「香草」，引申为默认款。

> - **arbitrary** /ˈɑːbɪtrəri/ —— 随意的、拍脑袋定的。an arbitrary choice 无甚道理可言的选择。

## 为什么要分层？（Why Use Layers?）

| 原文 | 译文 |
|---|---|
| You'll notice how in these drawings each neuron from one layer is connected to each neuron of the next with a little line. This is meant to indicate how the activation of each neuron in one layer, the little number inside it, has some influence on the activation of each neuron in the next layer. | 你会注意到，这些示意图里上一层的每个神经元，都用一条小线连到下一层的每个神经元。这是想表示：某一层里每个神经元的激活值——它内部那个小数字——会对下一层每个神经元的激活值产生一定影响。 |
| Watching the activations in each layer propagate through to determine the activations in the next can be quite mesmerizing. | 看着各层的激活值一层层传播过去、决定下一层的激活值，可以相当令人着迷。 |
| However, not all these connections are equal. Some will be stronger than others, and as you'll see shortly, determining how strong these connections are is really the heart of how a neural network operates, as an information processing mechanism. | 不过，这些连接并非人人平等。有的强，有的弱；很快你会看到，决定这些连接有多强，恰恰是神经网络作为一种信息处理机制如何运转的核心。 |
| But before jumping into the math for how one layer influences the next, or how training works, let's talk about why it's even reasonable to expect a layered structure like this to behave intelligently. What are we expecting here? What's the best hope for what those middle layers are doing? Why not just directly connect all the pixels to the final output we want? | 但在一头扎进「一层如何影响下一层」「训练如何进行」的数学之前，先聊聊：凭什么认为这样一个分层结构能表现得智能？我们在这儿期待的是什么？对中间层在干的事，最好的指望是什么？为什么不干脆把所有像素直接连到我们想要的最终输出？ |
| Well, when you or I recognize digits, we piece together various components like loops and lines. | 是这样：不管你还是我，识别数字时都是把各种部件拼起来看的，比如圈圈和线条。 |
| Each digit can be broken into smaller, recognizable subcomponents. | 每个数字都可以拆成更小的、可识别的子部件。 |
| In a perfect world, we might hope that each neuron in the second-to-last layer corresponds to one of these subcomponents. That anytime you feed in an image with, say, a loop up top, there is some specific neuron whose activation will be close to 1.0. | 在最理想的世界里，我们或许可以指望：倒数第二层的每个神经元恰好对应其中一个子部件。也就是说，只要你喂进一张图像——比如说顶部有个圈——就有某个特定神经元，它的激活值会接近 1.0。 |
| And I don't mean just this _exact_ loop of pixels. The hope would be that any generally loopy pattern toward the top of the image sets off this neuron. That way, going from this third layer to the last one would only require learning which combinations of subcomponents correspond to which digits. | 而且我不只是指这一圈像素_分毫不差_的圈。希望在于：图像顶部任何大致呈圈状的图案，都能点亮这个神经元。这样，从第三层走到最后一层，就只需要学习「哪些子部件组合对应哪些数字」。 |
| Of course, this just kicks the problem down the road, because how would you recognize these subcomponents, or even learn what the right subcomponents should be? And I still haven't talked about how exactly one layer influences the next! But run with me on this for a moment. | 当然，这不过是把问题往后踢了一脚：你又打算怎么识别这些子部件？甚至，怎么学出「正确的子部件应该是什么」？况且我还没讲一层到底怎么影响下一层呢！不过，请先容我这么推演一会儿。 |
| Recognizing a loop can also break down into subproblems. One reasonable way to do that would be to first recognize the various edges that make it up. | 识别一个圈，本身也能拆成子问题。一个合理的做法，是先识别构成它的各条边。 |
| A loop can be broken down into several small edges. | 一个圈可以拆成若干条小边。 |
| Similarly, a long line, as you might see in the digits 1, 4 or 7, is really just a long edge. Or maybe you think of it as a certain pattern of several smaller edges. | 类似地，你在数字 1、4、7 里看到的那种长线，其实就是一条长边。或者你也可以把它看作若干更小的边构成的某种图案。 |
| A long line is also just a bunch of edges. | 一条长线，也不过是一堆边。 |
| So our hope might be that each neuron in the second layer of the network corresponds to some little edge. Maybe when an image comes in, it lights up neurons associated with all the specific little edges inside that image. This, in turn, would light up the neurons in the third layer associated with larger scale patterns like loops and long lines, which would then cause some neuron from the final layer to fire which corresponds to the appropriate digit. | 于是我们的希望就可能是：网络第二层的每个神经元对应某条小边。也许一张图像进来时，会点亮与图中所有特定小边相关联的神经元；这又会点亮第三层中与圈、长线这类更大尺度图案相关联的神经元；而这最终会让末层中对应正确数字的某个神经元放电。 |
| Whether or not this is how our final network actually works is another question. (One that we'll revisit after seeing how to train this network.) But this is a hope that we might have. | 我们最终的网络是否真会这样运转，是另一个问题（看完如何训练这个网络之后，我们会回头讨论）。但这是我们不妨怀抱的一个希望。 |
| **Layers Break Problems Into Bite-Sized Pieces** | **分层把问题拆成一小口一小块** |
| You can imagine how being able to detect edges and patterns would also be useful for other image-recognition tasks. | 可以想象，能够检测边和图案，对其他图像识别任务也同样有用。 |
| Edge detection isn't just for digits! It's a useful step for all kinds of image-recognition problems. [Original lion image](https://en.wikipedia.org/wiki/File:Lion_waiting_in_Namibia.jpg) by Kevin Pluck, licensed under CC BY 2.0 | 边缘检测可不是只给数字用的！对各种各样的图像识别问题，它都是有用的一步。[狮子原图](https://en.wikipedia.org/wiki/File:Lion_waiting_in_Namibia.jpg)由 Kevin Pluck 提供，以 CC BY 2.0 授权。 |
| And beyond image recognition, there are all sorts of intelligent tasks that you can break down into layers of abstraction. | 而在图像识别之外，还有各式各样的智能任务，都可以拆解成一层层的抽象。 |
| Parsing speech, for example, involves parsing raw audio into distinct sounds, which combine to make certain syllables, which combine to form words, which combine to make up phrases and more abstract thoughts, etc. | 举个例子，解析语音，就是把原始音频拆成一个个不同的音；这些音组合成特定音节，音节组合成单词，单词再构成短语和更抽象的思想，等等。 |
| The layered structure of the neural network is great because it allows you to break down difficult problems into bite-size steps, so that moving from one layer to the next is relatively straightforward. | 神经网络的分层结构妙就妙在这里：它让你能把难题拆成一小口一小口的步骤，使得从一层走到下一层都相对简单直接。 |

> [!note]- 词汇注释 · 为什么要分层？
> - *piece together* —— 拼合、拼凑出。we piece together various components 把各种部件拼起来。
> - **subcomponent** /ˈsʌbkəmpəʊnənt/ —— 子部件。sub- 前缀 = 下位的组成部分。
> - *kick the problem down the road* —— 把问题往后踢（往后推，并未真正解决）。
> - *run with me on this* —— 先跟我这么推演下去。run with an idea = 顺着思路走。
> - *set off* —— 触发。any loopy pattern sets off this neuron。
> - **mesmerizing** /ˈmezməraɪzɪŋ/ —— 令人着迷的。mesmerize 使入迷。
> - *the heart of ...* —— ……的核心、要害。the heart of how a neural network operates。
> - **bite-size** /ˈbaɪtsaɪz/ —— 一小口大小的、化整为零的。bite-size steps 把难题拆小。

## 信息如何在层与层之间传递（How Information Passes Between Layers）

| 原文 | 译文 |

| With this as a general idea, how do you actually implement it? The goal is to have some mechanism that could conceivably combine pixels into edges, or edges into patterns, or patterns into digits. ReLU spits out 0 for any negative input, and doesn't change the positive inputs at all. | 所以如今，人们更常用一个叫 ReLU（Rectified Linear Unit，修正线性单元）的函数。对一个极简单的函数来说，这名字浮夸得离谱。ReLU 对任何负输入都吐出 0，对正输入则原样放行。 |
| Unlike sigmoid, the output of ReLU never flattens out, no matter how large the weighted sum becomes. So wiggling the weights always gives useful feedback about how the network should change. This makes the training process much faster and more efficient, especially as there are more layers involved, which is where the "deep" in "deep learning" comes from. | 与 sigmoid 不同，无论加权和变得多大，ReLU 的输出都永远不会变平。所以扭动权重总能给出有用的反馈，告诉你网络该怎么变。这让训练过程快得多、高效得多——层数越多越是如此，而「深度学习」（deep learning）里的那个「深」字就是打这儿来的。 |
| Earlier, I motivated the inclusion of the sigmoid by saying we want each neuron to hold a value between 0 and 1. While this is nice for the biological analogy of a neuron being either active or inactive, it's not a necessary restriction; the relevant result at the output layer comes down to whether some neurons are more active than others, regardless of the scale. | 前面我论证为什么要引入 sigmoid 时，说的是我们想让每个神经元的值落在 0 到 1 之间。这对「神经元要么激活、要么不激活」的生物学类比固然贴切，但它并不是必要的限制；输出层上真正要紧的，只是某些神经元比另一些更活跃，与数值尺度无关。 |
| You might wonder, then, why we need _any_ function wrapped around the matrix product. Forget sigmoid and ReLU, what about nothing at all? If the only thing we were doing was rescaling by weights and adding biases at each layer, then the result of propagating the information from the input layer to the output layer would be nothing more than a sequence of matrix multiplications (with some offsets along the way), which means the full function is _linear_. We won't go into the details here, but this would make the network dramatically less expressive. If you want to see a lovely visual explanation of what it means for data to be "linearly separable", and why having some non-linear step in a neural network is important, you may enjoy [this post](https://colah.github.io/posts/2014-03-NN-Manifolds-Topology/) by Chris Olah. | 那你可能会问：凭什么非要在矩阵乘积外面套_任何_函数？把 sigmoid 和 ReLU 都忘掉，什么都不套行不行？如果我们做的只是在每层按权重缩放、再加偏置，那么信息从输入层传到输出层的结果，就不过是一连串矩阵乘法（沿途加些偏移），这意味着整个函数是_线性_的。细节这里不展开，但这会让网络的表达能力大打折扣。想看「数据线性可分」是什么意思、以及神经网络里为什么需要某个非线性步骤的精彩可视化讲解，你可能会喜欢 Chris Olah 的[这篇文章](https://colah.github.io/posts/2014-03-NN-Manifolds-Topology/)。 |
| But of course, we shouldn't get ahead of ourselves. We still need to discuss how the network learns from new data, which you can learn about in the following chapters. | 当然，我们不该操之过急。我们还得讨论网络如何从新数据中学习——这你可以在接下来的几章里读到。 |
