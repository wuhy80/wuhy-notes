## 视频导读

- 官方给出的主题一句话：**扩散模型、CLIP，以及「把文字变成图像」的数学**（Diffusion models, CLIP, and the math of turning text into images）。
- 主线思路：文生图模型先学会「从纯噪声里一步步去噪」还原出图像（扩散/去噪过程），再借助 CLIP 这类图文对齐模型，把「文字提示词」变成引导去噪方向的向量——两条技术拼在一起，就是 Stable Diffusion 一类模型的骨架。
- 看视频时建议带着三个问题：为什么「加噪声再学着去噪」是个好训练任务？CLIP 是怎么把图和文拉进同一个向量空间的？生成视频相比生成图像，额外的难点在哪（时间维度一致性）？

## 核心概念中英对照

| 英文术语 | 中文 | 一句话说明 |
|---|---|---|
| diffusion model | 扩散模型 | 通过「逐步加噪 → 学习逐步去噪」来生成图像/视频的生成模型 |
| noise / denoise | 噪声 / 去噪 | 训练时人为加入的随机干扰；模型学的就是把噪声一步步剥掉 |
| CLIP | 图文对齐模型 | OpenAI 提出的把图像和文字映射进同一向量空间的模型，是「听懂提示词」的关键 |
| prompt | 提示词 | 用户输入的文字描述，用来引导生成内容 |
| embedding | 嵌入向量 | 把图像或文字表示成高维空间中的一个点/方向 |
| vector space | 向量空间 | 语义相似的输入对应的向量彼此靠近的空间 |
| sampling | 采样 | 从模型学到的分布里「抽」出一张具体图像的生成步骤 |
| text-to-image | 文生图 | 由文字提示直接生成图像的任务 |
