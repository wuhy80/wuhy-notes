## 反向传播是什么？（What is Backpropagation?）

| 原文 | 译文 |
|---|---|
| Remember, the negative gradient of the cost function is a 13,002-dimensional vector that tells us how to nudge all the weights and biases to decrease the cost most efficiently. **Backpropagation, the topic of this lesson, is an algorithm for computing that negative gradient.** | 记住，代价函数的负梯度是一个 13,002 维的向量，它告诉我们该怎样微调所有权重和偏置，才能最有效地降低代价。**反向传播——本课的主角——就是计算这个负梯度的算法。** |
| Thinking about the gradient vector as a direction in a 13,002-dimensional space is, to put it lightly, beyond the scope of our imaginations. | 把梯度向量想成 13,002 维空间里的一个方向——说得委婉点——这超出了我们想象力的射程。 |
| Direction in 13,002 dimensions?!? | 13,002 维空间里的方向？！ |
| So as we talked about in the previous lesson, it's helpful to consider it this way: The magnitude of each component of the gradient tells you how _sensitive_ the cost function is to each corresponding weight and bias. | 所以，正如上一课谈到的，换个方式来理解会很有帮助：梯度每个分量的大小，告诉你代价函数对每个对应的权重和偏置有多_敏感_。 |
| For example, let's say you compute the negative gradient, using the process I'm about to describe, and the component associated with the weight on one edge comes out to be 3.2, while the component associated with some other edge is 0.1: | 举个例子：假设你用我马上要讲的方法算出了负梯度，某条边上那个权重对应的分量算出来是 3.2，而另一条边对应的分量是 0.1： |
| Suppose the entry of the gradient vector associated with one weight is 32x as large as the entry associated with some other weight. | 假设梯度向量里与某个权重对应的项，是与另一个权重对应的项的 32 倍大。 |
| The way to read this is that the cost function is 32 times more sensitive to changes to that first weight. So if you were to wiggle the value of that weight a bit, it'll cause a change to the cost function 32 times greater than what the same wiggle to the second weight would cause. | 这该怎么读？读法是：代价函数对第一个权重的变动的敏感度，是对第二个权重的 32 倍。所以，如果你把第一个权重的值轻轻扭动一点，引起的代价函数变化，将是同样扭动第二个权重所引起变化的 32 倍。 |
| Changing a weight that has a larger magnitude in the negative gradient vector has a bigger effect on the cost. | 改动一个在负梯度向量中量级更大的权重，对代价的影响也更大。 |

> [!note]- 词汇注释 · 反向传播是什么
> - **sensitive** /ˈsensətɪv/ —— 敏感的。how sensitive the cost function is 对……有多敏感。
> - **entry** /ˈentri/ —— （向量、表格里的）一项。the entry of the gradient vector。
> - **wiggle** /ˈwɪɡl/ —— 轻轻扭动。wiggle the value a bit 把值轻轻扭一点。
> - **dimension** /daɪˈmenʃn/ —— 维、维度。13,002-dimensional 13,002 维的。
> - *beyond the scope of ...* —— 超出……的范围。beyond the scope of our imaginations。
> - *let's say ...* —— 比方说、假设（口语引入假想情形）。

## 反向传播的直觉（The Intuition for Backpropagation）

| 原文 | 译文 |
|---|---|
| When I first learned backpropagation, the most confusing aspect was just the notation and index chasing of it all. | 我当初学反向传播时，最让人犯晕的，就是那一堆记号，以及满篇追着下标跑的晕眩感。 |
| There's a lot of notation here. What does it all mean!? | 这里的记号可真不少。这一切到底是什么意思！？ |
| For this article, let's begin with a complete disregard for notation and instead step through the effect that each training example has on the weights and biases. Hopefully, these effects will feel intuitive so that by the time we return to the notation, it acts to articulate something you already know, rather than acting as a code to be decrypted. | 在这篇文章里，我们先彻底无视记号，改为一步步过一遍每个训练样本对权重和偏置产生的影响。希望这些影响会让你觉得很直观，这样等回头再看记号时，它就是在替你说出你已经懂的东西，而不是一段等着被破译的密码。 |
| Because the full cost function involves averaging a certain cost-per-example for all the tens of thousands of training examples, the way we adjust all the weights and biases for a single gradient descent step also depends on _every single example_. Or, rather, in principle it should, but for computational efficiency, we'll do a little trick later to keep you from needing to hit every single example for every single step. | 因为完整的代价函数要对全部几万个训练样本的「单样本代价」取平均，所以单次梯度下降中对所有权重的调整方式，也依赖_每一个样本_。或者说，原则上理应如此；但为了计算效率，稍后我们会用一个小技巧，让你不必每一步都遍历每一个样本。 |
| Right now, though, focus your attention on a single example, this image of a 2: | 不过现在，请把注意力集中在一个样本上——这张数字 2 的图像： |
| How can we adjust the weights and biases to improve the network's performance on this image? | 我们要怎么调整权重和偏置，才能提升网络在这张图上的表现？ |
| What effect does this one training example have on how the weights and biases should be adjusted? | 这一个训练样本，对「权重和偏置该如何调整」有什么影响？ |
| Because the network is not yet well trained, the activations in that output layer are effectively random. That's no good; we want to change these activations so that they properly identify the digit 2. | 由于网络还没训练好，输出层的激活值实际上就是随机的。这可不行；我们想改变这些激活值，让它们正确地认出数字 2。 |
| But remember, we only have control over the weights and biases of the network. So we will have to nudge those weights and biases in a way that improves the output. | 但记住，我们能直接控制的只有网络的权重和偏置。所以我们只能通过微调这些权重和偏置来改善输出。 |
| The activations in the output layer are trash, and we need to fix them by adjusting the weights and biases. | 输出层的激活值一塌糊涂，我们得靠调整权重和偏置来收拾它们。 |
| Although we can't _directly_ change the activations, it's helpful to keep track of what adjustments we _wish_ to take place in this output layer. | 虽然我们_无法直接_改变激活值，但把「我们_希望_输出层发生哪些调整」记在心里，很有帮助。 |
| Since we want the network to classify this as a 2, we want the digit 2 neuron's value to be nudged up while all the others get nudged down: | 既然我们想让网络把它分类成 2，那我们希望数字 2 那个神经元的值被往上推，而其他所有神经元都被往下压： |
| Moreover, the sizes of these nudges should be proportional to how far off each output value is from the target. Neurons that are way off require big nudges, but neurons that are pretty close to correct only require little nudges. | 而且，这些推力的大小应当与每个输出值偏离目标的程度成正比。偏得远的神经元需要大力推，接近正确的神经元只需轻轻推。 |
| Zooming in further, let's focus on the one neuron whose activation we wish to increase: | 再放大些，聚焦到那个我们想提高激活值的神经元： |
| Remember that its activation value (in this case 0.2) is defined as a weighted sum of all activations from the previous layer, plus a bias, which is then plugged into something like the sigmoid squishification or a ReLU: | 记住，它的激活值（这里是 0.2）定义为前一层的全部激活值的加权和、再加一个偏置，然后塞进类似 sigmoid 压扁函数或 ReLU 的东西里： |
| So there are three avenues that can team up together to increase this activation: | 所以，有三条途径可以联手来提高这个激活值： |
| 1. Increase the **bias** | 1. 增大**偏置** |
| 2. Increase the **weights** | 2. 增大**权重** |
| 3. Change the **activations** from the previous layer | 3. 改变上一层的**激活值** |

> [!note]- 词汇注释 · 反向传播的直觉
> - **notation** /nəʊˈteɪʃn/ —— 记号、符号体系。数学教材的高频痛点词。
> - *index chasing* —— 追着下标跑。index 此处指公式里的下标，形容 i、j、k 满天飞的晕眩感。
> - **disregard** /ˌdɪsrɪˈɡɑːd/ —— 无视、不顾。complete disregard for notation 彻底无视记号。
> - **articulate** /ɑːˈtɪkjuleɪt/ —— 清楚地表达。articulate something you already know。
> - **decrypt** /diːˈkrɪpt/ —— 破译、解密。a code to be decrypted 一段待破译的密码。
> - **avenue** /ˈævənuː/ —— 途径、路径。three avenues 三条途径。
> - *proportional to ...* —— 与……成正比。sizes proportional to how far off。
> - **squishification** /ˈskwɪʃɪfɪˈkeɪʃn/ —— 「压扁化」（3Blue1Brown 的自造词：squish 压扁 + -ification 化）。指 sigmoid 之类的压缩函数。

## 调整偏置（Changing the Bias）

| 原文 | 译文 |
|---|---|
| Changing the bias associated with a neuron is the simplest way to change its activation. Unlike changing the weights or the activations from the previous layer, the effect of a change to the bias on the weighted sum is constant and predictable. | 改变与神经元关联的偏置，是改变其激活值最简单的办法。与改变权重或上一层激活值不同，偏置的变化对加权和的影响是恒定且可预测的。 |
| Since we want to increase the activation of the digit-2 output neuron we've been discussing, how should its associated bias be adjusted? What about the biases associated with all the other output neurons for this training example? | （译注：原文此处是一道互动测验，需到官网原页体验。）既然我们想提高一直在讨论的数字 2 输出神经元的激活值，它的偏置该怎么调？对这个训练样本，其他所有输出神经元的偏置又该怎么调？ |
| The bias associated with the digit-2 neuron should be increased, because that will cause the activation of the digit-2 neuron to increase. All the other output activations should be decreased, which requires decreasing their associated biases. | 与数字 2 神经元关联的偏置应该增大，因为那样会让数字 2 神经元的激活值上升。其余所有输出激活值都应该被压低，这就要求减小它们各自的偏置。 |
| These changes will give a more accurate prediction with a lower cost for this particular training example. | 对这一个特定训练样本而言，这些改动会带来更准确的预测和更低的代价。 |

> [!note]- 词汇注释 · 调整偏置
> - *associated with ...* —— 与……相关联的。the bias associated with a neuron。
> - **constant** /ˈkɒnstənt/ —— 恒定的、不变的。constant and predictable。
> - **predictable** /prɪˈdɪktəbl/ —— 可预测的。predict 预测 + -able。
> - **accurate** /ˈækjərət/ —— 准确的。a more accurate prediction 更准确的预测。
> - **adjust** /əˈdʒʌst/ —— 调整。how should its bias be adjusted。

## 调整权重（Changing the Weights）

| 原文 | 译文 |
|---|---|
| How should the weights be adjusted? Notice, because they are being multiplied by the activations, the weights have differing levels of influence: | 权重该怎么调？注意，由于权重要与激活值相乘，不同权重的影响力也分三六九等： |
| Changing the weights associated with large activation values will have a stronger effect than changing the weights associated with small activation values. | 改动与大激活值关联的权重，比改动与小激活值关联的权重效果更强。 |
| The connections with the brightest neurons from the preceding layer have the biggest effect since those weights are multiplied by larger activation values. So increasing one of those weights has a bigger influence on the cost function than increasing the weight of a connection with a dimmer neuron. (Again, this is all only insofar as this one training example is concerned.) | 与上一层最亮的神经元相连的连接影响最大，因为这些权重乘的是更大的激活值。所以，增大这类权重，对代价函数的影响就比增大与较暗神经元相连的权重更大。（再次强调，这一切只就这一个训练样本而言。） |
| Remember, when we talk about gradient descent, we don't just care about whether each component should be nudged up or down. We care about which ones give you the most bang for your buck. | 记住，谈梯度下降时，我们不只关心每个分量该往上推还是往下压，更关心哪些改动最划算。 |
| To get the most bang for your buck, adjust the weights in proportion to their associated activations. | 为了最划算，就按各权重所关联的激活值成比例地调整它们。 |
| This, by the way, is at least somewhat reminiscent of a theory in neuroscience for how biological networks of neurons learn, Hebbian theory, often summed up in the phrase "neurons that fire together wire together." | 顺带一提，这多少有点让人想起神经科学里解释生物神经元网络如何学习的理论——赫布理论（Hebbian theory），它常被概括成一句话：「一起放电的神经元连在一起。」 |
| Here, the biggest increases in weights—the biggest strengthening of connections—happens between neurons that are the most active and the ones which we wish to become more active. | 在这里，权重增幅最大的地方——也就是连接增强得最厉害的地方——发生在最活跃的神经元与我们希望变得更活跃的神经元之间。 |
| In some sense, the neurons that fire while seeing a 2 get more strongly linked to those firing while thinking about a 2. | 从某种意义上说，看到 2 时放电的神经元，与「想着 2」时放电的神经元，被更紧密地连在了一起。 |
| Connections are strengthened between neurons that should be activated at the same time. | 应当同时激活的神经元之间，连接得到加强。 |
| The analogy is not perfect since the untrained network is not really "thinking" about a 2 when it sees this example; it's more that the label on the training data is hardcoding what the network _should_ be thinking about. Still, it's satisfying to know that buried beneath all the calculus and linear algebra typically used to describe backpropagation, the actual changes happening to the weights with each training example mirror the ideas of Hebbian theory. | 这个类比并不完美，因为未训练的网络看到这个样本时并不是真的在「想」2；更准确地说，是训练数据上的标签把网络_应该_想什么硬编码了进去。尽管如此，知道这一点仍令人欣慰：在通常用来描述反向传播的微积分和线性代数外表之下，每个训练样本实际给权重带来的改变，与赫布理论的想法遥相呼应。 |

> [!note]- 词汇注释 · 调整权重
> - **influence** /ˈɪnfluəns/ —— 影响（力）。differing levels of influence 影响力分高低。
> - **preceding** /prɪˈsiːdɪŋ/ —— 在前的。the preceding layer 前一层。
> - *insofar as ...* —— 到……的程度、就……而言。only insofar as this one example is concerned。
> - *reminiscent of ...* —— 让人想起……的。somewhat reminiscent of a theory。
> - *neurons that fire together wire together* —— 「一起放电的神经元连在一起」。fire 放电，wire 连线；赫布理论的经典概括。
> - **hardcode** /ˈhɑːdkəʊd/ —— 硬编码、写死。the label is hardcoding what the network should think。
> - **mirror** /ˈmɪrə/ —— 与……呼应、映照。mirror the ideas of Hebbian theory。
> - **analogy** /əˈnælədʒi/ —— 类比。The analogy is not perfect 这个类比不完美。

## 调整激活值（Changing the Activations）

| 原文 | 译文 |
|---|---|
| The third way we can help increase this neuron's activation is by changing all the activations in the previous layer. Namely, if everything connected to that digit-2 neuron with a positive weight was brighter, and if everything connected with a negative weight was dimmer, that digit-2 neuron would be more active. | 帮这个神经元提高激活值的第三种办法，是改变上一层的全部激活值。也就是说，如果所有以正权重连到数字 2 神经元的东西都更亮一点，而所有以负权重相连的都更暗一点，那这个数字 2 神经元就会更活跃。 |
| Similar to the weight changes, you'll get the most bang for your buck by seeking changes proportional to the size of the corresponding weights: | 与改权重类似，要想最划算，就要寻求与相应权重大小成比例的改动： |
| Just like changing weights in proportion to activations, you get the most bang for your buck by increasing activations in proportion to their associated weights. | 正如按激活值成比例地改权重一样，按各激活值所关联的权重成比例地增大它们，你就最划算。 |
| Of course, we cannot directly influence these activations. We only have control over the weights and biases. But just as with the last layer, it's helpful to keep note of the desired changes. | 当然，我们无法直接影响这些激活值——能控制的只有权重和偏置。但和上一层一样，把这些期望中的改动记录下来很有用。 |
| We can't influence the activations in the previous layer directly. But we can change the weights and biases that determine their values! | 我们无法直接影响上一层的激活值，但我们可以改变决定这些取值的权重和偏置！ |
| Remember, this is only what that one digit-2 output neuron wants. We also want all the other neurons in the last layer to become less active, and each of those other output neurons has its own influence on what should happen to the second-to-last layer. | 记住，这只是数字 2 那一个输出神经元的愿望。我们还希望最后一层的其他神经元都变得不那么活跃，而那些输出神经元中的每一个，对倒数第二层该发生什么，也都有各自的影响力。 |
| We want to adjust all these other output neurons too, which means we will have many competing requests for changes to activations in the previous layer. | 我们还想调整所有其他输出神经元，这意味着对上一层激活值的改动，会有许多互相竞争的要求。 |
| So the desire of this digit-2 neuron is added together with the desires of all the other nine neurons. Each has its own suggested nudge for that second-to-last layer, again in proportion to the corresponding weights and in proportion to how much each neuron needs to change. | 于是，数字 2 神经元的愿望就与其他九个神经元的愿望加在了一起。每一个都对倒数第二层提出了自己建议的微调，同样按相应权重成比例、也按每个神经元需要改变的程度成比例。 |
| It's impossible to perfectly satisfy all these competing desires for activations in the second layer. The best we can do is add up all the desired nudges to find the overall desired change. | 想让倒数第二层的激活值完美满足这互相竞争的所有愿望，是不可能的。我们能做到的最好程度，就是把所有期望的微调加总，得出总体期望的改动。 |
| Here is where the idea of propagating backward comes in. By adding all these desired effects, you can get a list of the nudges you want to happen to this second-to-last layer. From there, you can recursively apply the same process to the relevant weights and biases determining those values, repeating this process as you move backward through the network. | 「反向传播」的点子就在这里登场了。把所有这些期望的效果加起来，你就得到一份清单：你希望倒数第二层发生哪些微调。从这里出发，你可以对决定这些取值的相关权重和偏置递归地套用同一流程，在网络中一路向后，重复这个过程。 |

> [!note]- 词汇注释 · 调整激活值
> - **namely** /ˈneɪmli/ —— 也就是说、即。引出对上句的具体展开。
> - **dim** /dɪm/ —— 暗的、变暗。dimmer 更暗的；与 bright 相对。
> - **competing** /kəmˈpiːtɪŋ/ —— 互相竞争的、打架的。competing requests 互相竞争的要求。
> - **recursively** /rɪˈkɜːsɪvli/ —— 递归地。recursively apply the same process。
> - *second-to-last* —— 倒数第二的。the second-to-last layer 倒数第二层。
> - *keep note of ...* —— 记下、留意。keep note of the desired changes。
> - *come in* —— 登场、派上用场。Here is where the idea ... comes in。

## 对所有训练样本重复这一过程（Repeating for All Training Examples）

| 原文 | 译文 |
|---|---|
| Everything we just stepped through only records how a _single_ training example wishes to nudge each of the many, many weights and biases. | 我们刚才一步步过的这一切，记录的只是_单个_训练样本希望怎样去微调那许许多多权重和偏置中的每一个。 |
| So far we've only identified the nudges to the weights and biases that would improve our results for this digit 2. But we also need to account for all the other digits! | 到目前为止，我们找出的只是能让这张数字 2 的结果变好的微调。但其他所有数字也得一并考虑！ |
| If we only listened to what that image of a 2 wanted, the network would ultimately be incentivized to just classify all images as a 2. | 如果我们只听这张 2 的图像的一面之词，网络最终就会有动机把所有图像统统分类成 2。 |
| To zoom out a bit, you also go through this same backpropagation routine for every other training example, recording how each of them would like to change the weights and biases. Then you average together all those desired changes. | 把镜头拉远一点：你还要对其他每个训练样本都跑一遍同样的反向传播流程，记录下它们各自想怎么改权重和偏置。然后，把这些期望中的改动全部取平均。 |
| Each training example has its own desire for how the weights and biases should be adjusted, and with what relative strengths. | 每个训练样本对「权重和偏置该怎么调、各自用多大力气」都有自己的愿望。 |
| By averaging together the desires of all training examples, we get the final result for how a given weight or bias should be changed in a single gradient descent step. | 把所有训练样本的愿望平均起来，就得到最终结果：单次梯度下降中，某个给定的权重或偏置该怎么改。 |
| The collection of these averaged nudges to each weight and bias is, loosely speaking, the negative gradient of the cost function! Or at least something proportional to it. | 这份对每个权重和偏置的平均微调的总集，说得宽松些，就是代价函数的负梯度！至少是与它成正比的东西。 |
| The result of all this backpropagation is that we've found (something proportional to) the negative gradient! | 这一整趟反向传播的结果就是：我们找到了（与）负梯度（成正比的东西）！ |
| I say "loosely speaking" only because I have yet to get quantitatively precise about these nudges. But if you understood each change I referenced above, why some are proportionally bigger than others, and how they all need to be added together, then you understand the mechanics for what backpropagation is actually doing. | 我说「说得宽松些」，只是因为我还没把这些微调在数量上讲得严格精确。但如果你理解了上面提到的每一处改动——为什么有些按比例来说更大、它们又为何必须加在一起——那你就已经明白了反向传播真正在干的活儿的机制。 |

> [!note]- 词汇注释 · 对所有训练样本重复这一过程
> - **incentivize** /ɪnˈsentɪvaɪz/ —— 激励、给……以动机。be incentivized to do 有动机去做。
> - *zoom out* —— 拉远镜头、扩大视野。与 zoom in 相对。
> - **routine** /ruːˈtiːn/ —— 例行流程。backpropagation routine。
> - *loosely speaking* —— 宽松地说、大体上讲。与 strictly speaking 相对。
> - **proportional** /prəˈpɔːʃənl/ —— 成正比的。something proportional to it。
> - **quantitatively** /ˈkwɒntɪtətɪvli/ —— 定量地、数量上地。quantitatively precise。
> - **mechanics** /məˈkænɪks/ —— 机制、运作原理。the mechanics of what backprop is doing。

## 随机梯度下降（Stochastic Gradient Descent）

| 原文 | 译文 |
|---|---|
| In practice, it takes computers an extremely long time to add up the influences of every single training example for every single gradient descent step. Instead, there's a clever trick for speeding up the process in a way that involves more total gradient descent steps but much less time for each one. | 实践中，让计算机为每一次梯度下降都把每个训练样本的影响加总一遍，耗时极长。于是有个聪明的加速技巧：总的梯度下降步数变多了，但每一步花的时间少得多。 |
| Randomly shuffle your training data and divide it into a bunch of mini-batches, having, say, 100 training examples each. | 把训练数据随机打乱，再切成一堆小批次（mini-batch），比如每批 100 个训练样本。 |
| Then you compute a gradient descent step according to each minibatch rather than the entire set of training examples. It won't give you the _actual_ gradient of the cost function, which depends on all the training data, so it's not the most efficient step downhill. | 然后你按每个小批次（而不是整个训练集）来计算一步梯度下降。它给不出代价函数_真正_的梯度——那需要依赖全部训练数据——所以这一步并不是最高效的下坡步。 |
| But each mini-batch gives a pretty good approximation, and if there are 100 minibatches, each step takes 1/100th of the total time. And after 100 steps, each piece of training data will have had its chance to influence the final result. | 但每个小批次都给出相当不错的近似；如果有 100 个小批次，每步只花总时间的百分之一。而走完 100 步之后，每份训练数据都有机会影响最终结果。 |
| With these mini-batches, which only _approximate_ the gradient, the process of gradient descent looks more like a drunk man stumbling aimlessly down a hill but taking quick steps rather than a carefully calculating man who takes slow, deliberate steps downhill. | 用这些只_近似_梯度的小批次，梯度下降的过程看上去就不像一个深思熟虑、步子又慢又稳地下山的人，而更像一个醉汉，跌跌撞撞、方向飘忽，但步子迈得飞快。 |
| Using mini-batches means our steps downhill aren't quite as accurate, but they're much faster. | 使用小批次意味着我们下山的步子没那么精准，但快得多。 |
| This is referred to as _Stochastic gradient descent_. | 这就是所谓的_随机梯度下降_（Stochastic gradient descent）。 |

> [!note]- 词汇注释 · 随机梯度下降
> - **stochastic** /stəˈkæstɪk/ —— 随机的。stochastic gradient descent 随机梯度下降（SGD）。
> - **shuffle** /ˈʃʌfl/ —— 打乱（顺序）。randomly shuffle your training data。
> - **approximation** /əˌprɒksɪˈmeɪʃn/ —— 近似。a pretty good approximation 相当不错的近似。
> - **stumble** /ˈstʌmbl/ —— 跌跌撞撞地走。stumbling aimlessly down a hill。
> - **deliberate** /dɪˈlɪbərət/ —— 从容而审慎的（形容词）。slow, deliberate steps；作动词读 /dɪˈlɪbəreɪt/，指深思熟虑。
