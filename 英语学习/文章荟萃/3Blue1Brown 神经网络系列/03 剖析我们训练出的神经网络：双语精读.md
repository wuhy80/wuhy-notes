## 开篇：先动手玩一把

| 原文 | 译文 |
|---|---|
| In the last post, we learned about how training a neural network involves minimizing a cost function with gradient descent. In the next post, we'll dig into how the relevant gradient is computed. But before that, as a brief interlude, I want to skip ahead and have you look at what the result of this whole process is. | 上一篇里，我们了解了训练神经网络是怎么回事：用梯度下降（gradient descent）去最小化一个成本函数（cost function）。下一篇，我们会深挖相关梯度是怎么算出来的。但在那之前，作为一段简短的插曲，我想先跳到前面，让你看看这一整套过程的成果是什么样子。 |
| This entire mini lesson will be all about analyzing the trained neural network to see exactly what it does and why. But before you do any reading, it's good to get your hands messy and try to discover for yourself exactly what this network is up to. | 这一整堂迷你小课，都要用来剖析这个训练好的神经网络，看清它究竟在做什么、为什么这么做。但在你阅读之前，最好先把手弄脏——亲自试着发现这个网络到底在干什么。 |
| That's why we're bringing back the digit drawing demo from the very first lesson. But this time, to aid in your experimentation, all the neurons update live as you're drawing, so you can get an immediate sense of how the input pixels affect the hidden layers and eventually the output. | 所以我们把第一课那个画数字的 demo 请了回来。但这一次，为了帮你做实验，所有神经元都会在你作画的同时实时更新，让你能立刻感受到输入像素如何影响隐藏层、并最终影响输出。 |
| Spend a bit of time experimenting, now with a bit more knowledge of how this whole system actually works, and then we'll discuss what's going on. | 花点时间做做实验吧——这一次，你对整套系统究竟怎么运作已经多懂了一些——然后我们再来讨论到底发生了什么。 |

> [!note]- 词汇注释 · 开篇
> - **interlude** /ˈɪntəluːd/ —— 插曲、幕间。as a brief interlude 简短的插曲。
> - *skip ahead* —— 先跳到前面（预告后面的内容）。
> - *get your hands messy* —— 把手弄脏、亲自动手（同 get your hands dirty）。
> - *bring back* —— 请回来、重新搬出。bringing back the digit drawing demo。
> - **live** /laɪv/ —— 实时地（副词，重音在前）。all the neurons update live。
> - *be up to* —— 正在干（什么事）。what this network is up to 这个网络在干什么。

## 剖析这个网络（Analyzing the Network）

| 原文 | 译文 |
|---|---|
| The network we've developed, with two hidden layers of 16 neurons each, chosen mostly for aesthetic reasons, is… not bad. It classifies about 96% of new images it sees correctly. And honestly, if you look at some of the examples it messes up on, you feel compelled to cut it a little slack. | 我们一路搭起来的这个网络——两个隐藏层、每层 16 个神经元，当初这么选主要是图个好看——表现得……不赖。它对新见到的图像，大约 96% 能正确分类。而且说实在的，看看它搞错的那些例子，你会觉得不忍心太苛责它。 |
| These are some tricky digits! It's not surprising the network struggled here. | 这些数字可真刁钻！网络在这里犯难，一点也不奇怪。 |
| If you play around with the hidden layer structure and make some tweaks, you can get this up to about 98%. That's pretty good! Although it's not the best. Modern neural networks, which add in more sophisticated ideas than our plain vanilla variant, can have testing accuracy as high as 99.75%. And frankly, looking through the [MNIST database](http://yann.lecun.com/exdb/mnist/), I'm not even sure if most humans could do better than that. | 如果把隐藏层结构拿来摆弄摆弄、做些调整，你能把这个成绩提到 98% 左右。相当不错了！虽然还算不上最好。现代神经网络加入了比我们这个「原味」版本更精巧的想法，测试准确率最高可达 99.75%。而且说句实话，翻翻 [MNIST 数据库](http://yann.lecun.com/exdb/mnist/)，我都不确定大多数人类能不能做得比这更好。 |
| Given how daunting the initial task is, there's something incredible about any network doing this well on images it's never seen, given that we never specifically told it what patterns to look for. | 考虑到最初的任务有多令人生畏，一个网络能在从未见过的图像上做到这么好——何况我们从没明确告诉过它该找什么模式——这本身就有点不可思议。 |

> [!note]- 词汇注释 · 剖析这个网络
> - **aesthetic** /iːsˈθetɪk/ —— 美学上的、图好看的。chosen mostly for aesthetic reasons。
> - *cut it a little slack* —— 对它宽容一点。cut sb (some) slack 别太苛责某人。
> - *mess up* —— 搞砸、出错。the examples it messes up on 它搞错的那些例子。
> - **daunting** /ˈdɔːntɪŋ/ —— 令人生畏的。how daunting the initial task is。
> - *given that ...* —— 鉴于、考虑到。
> - **accuracy** /ˈækjərəsi/ —— 准确率。testing accuracy as high as 99.75%。

## 这些层到底在干什么？（What Are These Layers Doing?）

| 原文 | 译文 |
|---|---|
| This was our prediction for the behavior of the layers. Is this what they actually do? | 这是我们对各层行为的预测。它们实际干的是这个吗？ |
| Well, for this one at least, not at all! Remember how in the first lesson, I said the weights leading to a given neuron in the second layer can be visualized as a pixel pattern that the second layer neuron is picking up on? | 呃，至少对这个网络来说，完全不是！还记得第一课里我说过的话吗：通向第二层某个神经元的那些权重，可以可视化为这个神经元正在探测的一种像素图案。 |
| When we look at the weights associated with the transition from the first layer to the next, instead of picking up on isolated little edges here and there, they look, well, almost random. There are some loose patterns, but hardly the ones we might expect. | 当我们查看从第一层到下一层这一步的权重时，它们并没有在探测这儿一条、那儿一条的小边，而是看上去……呃，几乎是随机的。有一些松散的模式，但很难说是我们预期的那种。 |
| The neurons in the second layer are looking for very loose patterns, but not necessarily the little edges we predicted. | 第二层的神经元在找非常松散的模式，但不一定是我们预测的那些小边。 |
| It seems that in the unfathomably large 13,002-dimensional space of possible weights and biases, the network found itself a happy little local minimum that, despite successfully classifying most images, doesn't exactly pick up on more generalizable patterns. | 看来，在那 13,002 维、大得无可测度的可能权重与偏置空间里，网络给自己找了一个自得其乐的小小局部最小值（local minimum）：它虽然成功分类了大多数图像，却并没有真正捕捉到更具泛化力的模式。 |
| To really drive this point home, watch what happens when you input a random image: | 为了把这一点狠狠敲进脑子，看看输入一张随机图像时会发生什么： |
| The neural network confidently predicts that this random noise is a 5. | 神经网络信心满满地预测：这团随机噪声是 5。 |
| If the system was intelligent, you might expect it to feel really uncertain, either not really activating any of those ten output neurons or activating them all evenly. Instead, it confidently gives some nonsense answer, as if it feels as sure that this random noise is a 5 as it does that an actual image of a 5 is a 5. | 如果这个系统真有智能，你大概会指望它感到非常不确定——要么那十个输出神经元基本不激活，要么全部均匀地激活。可它偏偏自信满满地给出一个胡说八道的答案，仿佛它对「这团随机噪声是 5」的确信程度，跟对「一张真正的 5 的图像是 5」一模一样。 |
| This suggests that even if this network can recognize digits, it has no idea how to draw them. | 这说明：即便这个网络能认数字，它对「怎么画出数字」一无所知。 |
| Much of this is because it's such a tightly constrained training setup. From the network's point of view, the entire universe consists of nothing but clearly defined unmoving digits centered on a tiny grid, and its cost function never gave it an incentive to be anything but utterly confident in its decisions. | 这很大程度上是因为训练场景管得太死。在这个网络的眼里，整个宇宙就是一些清晰、静止、居中摆在小小网格上的数字，别无其他；而它的成本函数，也从未给过它任何激励，让它学着对自己的判断保留一点犹豫。 |
| You might wonder why I'd introduce this network with the motivation of picking up on edges and patterns when that's not at all what it ends up doing. Well, this is not meant to be an end goal, but instead a starting point. | 你可能会奇怪：既然它最终干的事根本不是探测边和图案，我为什么还要用那套动机来引入这个网络？嗯，因为这本来就不是终点，而是一个起点。 |
| Frankly, this is old technology, the kind researched in the ‘80s and ‘90s. You need to understand this before getting to more detailed modern variants, and it clearly is capable of solving some interesting problems! But the more you dig into what's going on in these hidden layers, the less intelligent it seems. | 坦白讲，这是老技术了——上世纪八九十年代研究的那一类。你得先弄懂它，才能进而理解更细致的现代变体；而且它显然也确实能解决一些有趣的问题！可你越是深挖这些隐藏层里发生的事，它就显得越不智能。 |
| Let's return to the drawing demo. These 2nd layer weight grids, which aren't really picking up on the edges we hoped for, but instead on some strange blobby shapes, are visible within the demo if you click on any neuron in the 2nd layer. | 我们回到画数字的 demo。第二层这些权重网格——探测的并不是我们期望的边，而是一些奇怪的团团块块——只要点击第二层的任意一个神经元，就能在 demo 里看到它们。 |
| What's even cooler is that if you're looking at the weight grid for a particular neuron while drawing a digit, you can watch the weights be "revealed", which changes the value of the neuron. | 更酷的是：如果你一边画数字、一边盯着某个神经元的权重网格，你可以亲眼看到权重被「揭示」出来的过程，而这会改变该神经元的值。 |
| One fun challenge is to try drawing a 3, and then slowly extending it so it becomes an 8. At some point the network's prediction will change, and as that's happening, watch for which neuron(s) in the 2nd layer are changing, and then to figure out _why_ they change as the 3 becomes an 8. | 一个好玩的挑战：试着画一个 3，然后慢慢把它延长，让它变成 8。在某个时刻，网络的预测会改变；趁着这个过程发生，留意第二层哪些神经元在变，再想想当 3 变成 8 时，它们_为什么_会变。 |
| As you spend time playing with the network, you'll start to find all kinds of edge cases where it gets confused or gives the wrong answer or just behaves in a way that isn't as intelligent as we might hope. This technology is cool, but it isn't perfect. | 在你花时间跟这个网络玩的过程里，你会开始发现各种各样的边缘情况：它犯迷糊、给错答案，或者表现得不如我们希望的那样聪明。这项技术很酷，但并不完美。 |
| Again, think about what a constrained training environment this network had. Every digit that it saw was of a particular size, centered in the frame. So if you give it something that is too big or too small or not quite in the center, it is bound to get confused. | 再强调一次：想想这个网络的训练环境有多受限。它见过的每个数字，都是特定大小、居中摆在画框里的。所以你若给它太大、太小、或不太居中的东西，它必然会犯迷糊。 |
| The network was only trained on centered, properly-sized images. So when it sees anything different, it gets confused. | 这个网络只在居中、尺寸合适的图像上训练过。所以一旦看到不一样的东西，它就懵了。 |
| Our current learning algorithm does nothing to let the network transfer knowledge of patterns picked up on one region of the grid to another, or to make inferences about scaling. In fact, nothing about our training algorithm even uses the fact that some pixels are adjacent to others. | 我们目前的学习算法，丝毫没有让网络把「在网格某个区域学到的模式知识」迁移到另一个区域，也没有让它对缩放做任何推断。事实上，我们的训练算法甚至连「有些像素彼此相邻」这个事实都没用上。 |
| If you start thinking hard about how to change structure of this network to allow for more flexible learning, e.g. how learning a pattern in one part of the image could naturally transfer to any other part of the image, you'll be well situated to learn about some of the more modern variations on this theme, most notably convolutional neural networks. | 如果你开始认真思考如何改变这个网络的结构、让学习更灵活——比如，在图像某一处学到的模式如何自然地迁移到图像的任何其他部分——那你就正好为学习这一主题下更现代的变体做好了准备，其中最著名的当属卷积神经网络（convolutional neural networks）。 |
| But we're getting ahead of ourselves. Before that, it's time to learn about backpropagation, the workhorse behind neural network training. | 不过我们又跑太快了。在那之前，该学学反向传播（backpropagation）了——神经网络训练背后的那匹驮马。 |

> [!note]- 词汇注释 · 这些层到底在干什么？
> - **visualize** /ˈvɪʒuəlaɪz/ —— 可视化。weights can be visualized as a pixel pattern。
> - **unfathomable** /ʌnˈfæðəməbl/ —— 深不可测的、大得没边的。the unfathomably large space。
> - *drive this point home* —— 把这个观点讲透、敲进脑子。drive sth home 使人彻底领会。
> - **blobby** /ˈblɒbi/ —— 一团团的、成块的。blob 团块 + -y。
> - *edge case* —— 边缘情况、极端个案。程序员高频用语。
> - *be bound to* —— 必然会。it is bound to get confused。
> - **workhorse** /ˈwɜːkhɔːs/ —— 役马、主力干将。the workhorse behind neural network training。
> - **adjacent** /əˈdʒeɪsnt/ —— 相邻的。some pixels are adjacent to others。
