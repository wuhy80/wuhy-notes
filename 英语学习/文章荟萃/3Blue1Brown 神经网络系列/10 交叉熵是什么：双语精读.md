## 视频导读

- 官方给出的主题一句话：**当你的概率模型出错时，压缩数据的代价是什么？**（What does it cost to compress data when your model of the probabilities is wrong?）
- 承接第 1 部分的「压缩即智能」视角：语言模型预测下一个词，本质上就是在给文本做压缩编码——模型预测得越准，需要的编码越短。
- 本部分把直觉推进到定量：**交叉熵 = 按模型 P 给数据分配的码长，而数据实际服从分布 Q**。模型越自信地猜错，付出的码长代价越大——这正是训练 LLM 时最小化的那个 loss 的含义。
- 看视频时建议带着三个问题：为什么用负对数（negative log likelihood）而不是别的函数？「熵」和「交叉熵」差在哪里（KL 散度的影子）？为什么说「压得好 = 预测得准」？

## 核心概念中英对照

| 英文术语 | 中文 | 一句话说明 |
|---|---|---|
| cross-entropy | 交叉熵 | 用概率模型 P 给实际服从 Q 的数据编码时的平均码长，也是 LLM 训练最常用的损失函数 |
| entropy | 熵 | 数据在「最优模型」下的最短平均码长，是交叉熵的下界 |
| probability model | 概率模型 | 给每个可能结果分配概率的模型，语言模型给的就是「下一个词」的分布 |
| code length | 码长 | 按某套编码方案表示一条数据所需的比特数 |
| compression | 压缩 | 用更少的比特表示信息；预测越准，压缩越狠 |
| negative log likelihood | 负对数似然 | 「猜对概率的负对数」，交叉熵在单个样本上的取值形式 |
| ground truth | 真实答案 | 数据里实际出现的那个词/结果 |
