## 开篇：把直觉对接上微积分

| 原文 | 译文 |
|---|---|
| The hard assumption here is that you've read [the previous part](https://www.3blue1brown.com/lessons/backpropagation), giving an intuitive walkthrough of the backpropagation algorithm. Here, we get a bit more formal and dive into the relevant calculus. It's normal for this to be a little confusing, so be sure to pause and ponder throughout. | 这里有个很强硬的前提假设：你已经读过[上一课](https://www.3blue1brown.com/lessons/backpropagation)，也就是对反向传播（backpropagation）算法的直观走读。这一篇我们要更正式一点，扎进相关的微积分里。读起来有点犯迷糊很正常，所以请务必勤暂停、多琢磨。 |
| As a quick reminder, backpropagation is an algorithm for calculating the gradient of the cost function of a network. | 简单回顾一下：反向传播是一个计算网络代价函数（cost function）梯度（gradient）的算法。 |

$$
\textcolor{red}{\nabla C} =
\left[\begin{array}{c}
\frac{\textcolor{red}{\partial C}}{\textcolor{blue}{\partial w^{(1)}}} \\[0.8em]
\frac{\textcolor{red}{\partial C}}{\textcolor{pink}{\partial b^{(1)}}} \\[0.5em]
\vdots \\[0.5em]
\frac{\textcolor{red}{\partial C}}{\textcolor{blue}{\partial w^{(L)}}} \\[0.8em]
\frac{\textcolor{red}{\partial C}}{\textcolor{pink}{\partial b^{(L)}}}
\end{array}\right]
$$

| 原文 | 译文 |
|---|---|
| The entries of the gradient vector are the partial derivatives of the cost function with respect to all the different weights and biases of the network, so it's really those derivatives that backpropagation helps us find. | 梯度向量的各个分量，就是代价函数对网络里所有不同权重和偏置的偏导数；所以说到底，反向传播帮我们求的就是这些导数。 |
| In the last lesson we talked about the intuitive feeling you might have for how backpropagation works, so now our focus will be on connecting that intuition with the appropriate calculus. | 上一课我们聊了你对反向传播如何工作可能抱有的直观感受；现在我们的重点，是把这份直觉和相应的微积分对接起来。 |
| (For those uncomfortable with the relevant calculus, I do have [a whole series on the topic](https://www.3blue1brown.com/topics/calculus).) | （如果你对相关微积分还没把握，我确实有一整套讲微积分的系列。） |
| The main goal here is to show how people in machine learning commonly think about the [chain rule](https://www.3blue1brown.com/lessons/chain-rule-and-product-rule) in the context of networks, which can feel a bit different than how most introductory calculus courses approach the subject. | 这一篇的主要目标，是展示机器学习圈的人在网络的语境下通常怎么思考[链式法则](https://www.3blue1brown.com/lessons/chain-rule-and-product-rule)（chain rule）——那感觉和大多数微积分入门课讲它的方式会有点不一样。 |

> [!note]- 词汇注释 · 开篇
> - **backpropagation** /ˌbækprɒpəˈɡeɪʃn/ —— 反向传播。神经网络学习的核心算法，口语常简称 backprop。
> - **gradient** /ˈɡreɪdiənt/ —— 梯度。代价函数对所有权重与偏置的偏导数排成的向量。
> - **cost function** —— 代价函数。衡量网络输出离目标答案有多远的函数，深度学习里也叫损失函数（loss function）。
> - **partial derivative** —— 偏导数。多元函数只对一个变量求导，其余变量按住不动。
> - **calculus** /ˈkælkjələs/ —— 微积分。the relevant calculus 指相关的微积分知识。
> - *intuitive walkthrough* —— 直观走读。walkthrough 指一步一步带你过一遍的讲解。
> - *dive into* —— 纵身扎进、深入钻研。

## 用反向传播计算梯度（Calculating the Gradient with Backpropagation）

| 原文 | 译文 |
|---|---|
| Let's start with an extremely simple network, where each layer has just one neuron. | 我们从一个极简单的网络开始：每层只有一个神经元（neuron）。 |
| We'll start with a very simple neural network. | 我们就从一个非常简单的神经网络开始。 |
| This network is determined by 3 weights (one for each connection) and 3 biases (one for each neuron, except the first), and our goal is to understand how changing each of them will affect the cost function. That way we know which adjustments will cause the most efficient decrease to the cost. | 这个网络由 3 个权重（weight，每条连接一个）和 3 个偏置（bias，每个神经元一个、第一层除外）完全确定；我们的目标是搞清楚，改变它们中的每一个会如何影响代价函数。这样我们才知道，哪些调整能让代价下降得最有效率。 |
| How strongly do these six weights and biases affect the value of the cost function? | 这六个权重和偏置，对代价函数的值影响有多大？ |
| For now, let's just focus on the connection between the last two neurons. I'll label the activation of that last neuron with a superscript $L$, indicating which layer it's in, so the activation of the previous neuron is $a^{(L-1)}$: | 眼下，我们先只盯住最后两个神经元之间的那条连接。我用上标（superscript）$L$ 来标记最后一个神经元的激活值（activation），指明它处在哪一层；于是前一个神经元的激活值就是 $a^{(L-1)}$： |
| We label the activations of the neurons based on which layer they're in, where $L$ is the last layer of the network. | 我们按神经元所在层来标记各激活值，其中 $L$ 是网络的最后一层。 |
| To be clear, these are _not_ exponents. They are just ways of indexing what layer we're talking about, since we want to save subscripts for different indices later on. | 说清楚：这些*不是*指数，只是标记「我们在说哪一层」的办法——因为我们想把下标（subscript）省下来，留给后面要用的其他编号。 |
| Let's say that for a certain training example, the desired output is $y$. That means that the cost for this one training example is $C_0 = (a^{(L)} - y)^2$. | 假设对某个训练样本，期望输出是 $y$。那么这一个训练样本的代价就是 $C_0 = (a^{(L)} - y)^2$。 |
| The cost to the network for this one training example is just the difference between the actual output and the desired output squared. | 对网络来说，这一个训练样本的代价，就是「实际输出与期望输出之差」的平方。 |
| As a reminder, this last activation $a^{(L)}$ is determined by a weight, a bias, and the previous neuron's activation, all pumped through some special nonlinear function like a sigmoid or a ReLU. | 回顾一下：最后这个激活值 $a^{(L)}$，由一个权重、一个偏置和前一个神经元的激活值共同决定，全部一起灌进某个特殊的非线性函数（nonlinear function），比如 sigmoid 或 ReLU。 |

$$
a^{(L)} = \sigma\left(\textcolor{blue}{w^{(L)}} a^{(L-1)} + \textcolor{pink}{b^{(L)}}\right)
$$

| 原文 | 译文 |
|---|---|
| It'll make things easier for us to give a special name to this weighted sum, like $z$, with the same superscript as the activation: | 为了省事，我们给这个加权和（weighted sum）起个专门的名字，比如 $z$，上标与激活值保持一致： |

$$
\begin{align*}
\textcolor{green}{z^{(L)}} &= \textcolor{blue}{w^{(L)}} a^{(L-1)} + \textcolor{pink}{b^{(L)}} \\
a^{(L)} &= \sigma\left(\textcolor{green}{z^{(L)}}\right)
\end{align*}
$$

| 原文 | 译文 |
|---|---|
| A way you might conceptualize this is that the weight, the previous activation, and the bias together let us compute $z^{(L)}$, which in turn lets us compute $a^{(L)}$, which in turn, along with the constant $y$, lets us compute the cost. | 你可以在脑子里这样组织它：权重、前一个激活值和偏置合起来，让我们算出 $z^{(L)}$；有了 $z^{(L)}$ 就能算出 $a^{(L)}$；有了 $a^{(L)}$，再配上常数 $y$，就能算出代价。 |
| This tree shows which values depend on which other values in our network. | 这棵树展示了：网络里哪些值依赖哪些值。 |
| And of course, $a^{(L-1)}$ is influenced by its own weight and bias, which means our tree actually extends up higher... | 当然，$a^{(L-1)}$ 又受它自己的权重和偏置影响，也就是说这棵树其实还能往上伸得更高…… |
| ...but we won't focus on that right now. | ……不过眼下我们先不管它。 |
| All of these are just numbers, so it can be nice to think of each variable as having its own little number line. | 这些统统只是数字，所以不妨把每个变量都想成有属于自己的一根小数轴。 |
| Each of these variables has a value that we can place on its own little number line. | 每个变量都有一个值，可以摆到它专属的小数轴上。 |

> [!note]- 词汇注释 · 计算梯度
> - **weight** /weɪt/ —— 权重。连接上的可调参数，乘在前层激活值上。
> - **bias** /ˈbaɪəs/ —— 偏置。直接加进加权和里的可调常数，让神经元更容易或更难被激活。
> - **activation** /ˌæktɪˈveɪʃn/ —— 激活值。一个神经元的输出数值。
> - **superscript** /ˈsuːpəskrɪpt/ —— 上标。本篇用 $L$ 这类上标标记层号，并非指数。
> - **subscript** /ˈsʌbskrɪpt/ —— 下标。作者特意把下标留给后面区分神经元用。
> - **sigmoid / ReLU** —— 两种常用非线性激活函数；ReLU = rectified linear unit（修正线性单元）。
> - *save ... for ...* —— 把……省下来留给……用。save subscripts for different indices。

## 计算第一个导数（Computing The First Derivative）

| 原文 | 译文 |
|---|---|
| Our first goal is to understand how sensitive the cost $C_0$ is to small changes in the weight $w^{(L)}$. That is, we want to know the derivative $\frac{\partial C_0}{\partial w^{(L)}}$. | 我们的第一个目标，是弄清代价 $C_0$ 对权重 $w^{(L)}$ 的微小变化有多敏感。也就是说，我们想知道导数 $\frac{\partial C_0}{\partial w^{(L)}}$。 |
| When you see this $\partial w^{(L)}$ term, think of it as meaning "some tiny nudge to $w^{(L)}$", like a change by 0.01. And think of this $\partial C_0$ term as meaning "whatever the resulting nudge to the cost is." We want their ratio. | 看到 $\partial w^{(L)}$ 这一项，就把它想成「对 $w^{(L)}$ 的轻轻一拨」，比如变动 0.01；再把 $\partial C_0$ 这一项想成「代价因此被拨动了多少」。我们想要的，就是两者的比值。 |
| Conceptually, this tiny nudge to $w^{(L)}$ causes some nudge to $z^{(L)}$, which in turn causes some change to $a^{(L)}$, which directly influences the cost, $C_0$. | 从概念上讲：对 $w^{(L)}$ 的一下微扰，会让 $z^{(L)}$ 晃一下；这又会让 $a^{(L)}$ 变一点；而 $a^{(L)}$ 直接影响代价 $C_0$。 |
| The nudge to $w^{(L)}$ has a chain of effects which eventually causes a nudge to $C_0$. | 对 $w^{(L)}$ 的这一拨，会引发一串连锁效应，最终拨动 $C_0$。 |
| So we break this up by first taking the ratio of a tiny change to $z^{(L)}$ to the tiny change in $w^{(L)}$. That is, the derivative of $z^{(L)}$ with respect to $w^{(L)}$. Likewise, consider the ratio of a tiny change to $a^{(L)}$ to the tiny change in $z^{(L)}$ that caused it, as well as the ratio between the final nudge to $C_0$ and this intermediate nudge to $a^{(L)}$. | 所以我们把它拆开：先取「$z^{(L)}$ 的微小变化」对「$w^{(L)}$ 的微小变化」之比，也就是 $z^{(L)}$ 对 $w^{(L)}$ 的导数；同样地，再取「$a^{(L)}$ 的微小变化」对「引起它的 $z^{(L)}$ 的微小变化」之比；以及「$C_0$ 最终那一拨」对「中间这一下 $a^{(L)}$ 的拨动」之比。 |
| This is the [chain rule](https://www.3blue1brown.com/lessons/chain-rule-and-product-rule), where multiplying these three ratios gives us the sensitivity of $C_0$ to small changes in $w^{(L)}$. | 这就是[链式法则](https://www.3blue1brown.com/lessons/chain-rule-and-product-rule)（chain rule）：把这三个比值乘在一起，就得到 $C_0$ 对 $w^{(L)}$ 微小变化的敏感度。 |

> [!note]- 词汇注释 · 第一个导数
> - **sensitive** /ˈsensətɪv/ —— 敏感的。how sensitive A is to B = A 对 B 的变化有多敏感，本篇高频句式。
> - **nudge** /nʌdʒ/ —— 轻推、轻轻一拨。微积分语境里指极小的改变量。
> - **ratio** /ˈreɪʃiəʊ/ —— 比值。the ratio of A to B = A 与 B 之比。
> - **conceptually** /kənˈseptʃuəli/ —— 从概念上讲。
> - *with respect to* —— 「对……（求导）」。the derivative of C with respect to w 的固定说法，缩写 w.r.t.。
> - *a chain of effects* —— 一串连锁效应。

## 构成它的三个分导数（The Constituent Derivatives）

| 原文 | 译文 |
|---|---|
| We've broken down the derivative we actually want, $\frac{\partial C_0}{\partial w^{(L)}}$, into its constituent parts. Now we just need to compute the values of the three individual derivatives that make it up. | 我们已经把真正想要的导数 $\frac{\partial C_0}{\partial w^{(L)}}$ 拆成了组成部分；现在只需求出构成它的那三个导数各自的值。 |
| To compute each derivative, we'll use some relevant formula from the way we've defined our neural network. | 要算每个导数，我们就从神经网络自己的定义式中挑一条相关公式。 |

$$
\begin{align*}

\textcolor{green}{z^{(L)}} &= \textcolor{blue}{w^{(L)}} a^{(L-1)} + \textcolor{pink}{b^{(L)}}
\quad &\longrightarrow \quad
\frac{\textcolor{green}{\partial z^{(L)}}}{\textcolor{blue}{\partial w^{(L)}}} &= a^{(L-1)} \\ \\

a^{(L)} &= \sigma\left(\textcolor{green}{z^{(L)}}\right)
\quad &\longrightarrow \quad
\frac{\partial a^{(L)}}{\textcolor{green}{\partial z^{(L)}}} &= \sigma^{\prime}\left(\textcolor{green}{z^{(L)}}\right) \\ \\

\textcolor{red}{C_0} &= \left(a^{(L)} - \textcolor{orange}{y}\right)^{2}
\quad &\longrightarrow \quad
\frac{\textcolor{red}{\partial C_0}}{\partial a^{(L)}} &= 2\left(a^{(L)} - \textcolor{orange}{y}\right)

\end{align*}
$$

| 原文 | 译文 |
|---|---|
| As you can see, each derivative is pretty straightforward once you know which equation to start from. | 可以看到，只要知道从哪条方程下手，每个导数都相当直白。 |
| It's worth taking a moment to reflect on what these expressions actually mean. Notice the first derivative we computed, $\frac{\partial z^{(L)}}{\partial w^{(L)}}$. It's telling us that changing the weight has a stronger effect on $z^{(L)}$ (and therefore a stronger effect on the cost) when the previous neuron is more active. This is where that biological idea that "neurons that fire together, wire together" is mirrored in our math. | 值得停下来回味一下，这些表达式到底意味着什么。注意我们算出的第一个导数 $\frac{\partial z^{(L)}}{\partial w^{(L)}}$：它在告诉我们，前一个神经元越活跃，改变权重对 $z^{(L)}$ 的影响就越强（对代价的影响也就越强）。生物学里那句「一起激发的神经元连在一起」（neurons that fire together, wire together），正是在这里映进了我们的数学。 |
| Also pay attention to the final derivative, $\frac{\partial C_0}{\partial a^{(L)}}$. It's proportional to the difference between the actual output and the desired output. This means that when the actual output is way different than what we want it to be, even small nudges to the activation stand to make a big difference to the cost. | 也请留意最后一个导数 $\frac{\partial C_0}{\partial a^{(L)}}$：它与「实际输出和期望输出之差」成正比（proportional）。这意味着，当实际输出离我们要的差得很远时，哪怕对激活值轻轻一拨，也可能让代价变化巨大。 |

> [!note]- 词汇注释 · 分导数
> - **constituent** /kənˈstɪtʃuənt/ —— 构成的、组成部分。constituent parts。
> - **straightforward** /ˌstreɪtˈfɔːwəd/ —— 直截了当的、不难的。
> - **proportional** /prəˈpɔːʃənl/ —— 成正比的。be proportional to。
> - *reflect on* —— 细想、回味。
> - *fire together, wire together* —— 「一起激发的神经元连在一起」：神经科学里概括赫布学习规则的口号。
> - *stand to do* —— 很有可能（得到某结果）。stand to make a big difference。

## 全部拼起来（Putting It All Together）

| 原文 | 译文 |
|---|---|
| We originally broke down $\frac{\partial C_{0}}{\partial w^{(L)}}$ into three separate derivatives using the chain rule: | 一开始，我们用链式法则把 $\frac{\partial C_{0}}{\partial w^{(L)}}$ 拆成了三个独立的导数： |

$$
\frac{\textcolor{red}{\partial C_{0}}}{\textcolor{blue}{\partial w^{(L)}}} =
\frac{\textcolor{green}{\partial z^{(L)}}}{\textcolor{blue}{\partial w^{(L)}}}
\frac{\partial a^{(L)}}{\textcolor{green}{\partial z^{(L)}}}
\frac{\textcolor{red}{\partial C_0}}{\partial a^{(L)}}
$$

| 原文 | 译文 |
|---|---|
| Putting this together with our constituent derivatives, we get: | 把它和前面那几个分导数拼起来，就得到： |

$$
\frac{\textcolor{red}{\partial C_{0}}}{\textcolor{blue}{\partial w^{(L)}}} =
a^{(L-1)} \sigma^{\prime}\left(\textcolor{green}{z^{(L)}}\right) 2\left(a^{(L)} - \textcolor{orange}{y}\right)
$$

| 原文 | 译文 |
|---|---|
| This formula tells us how a nudge to that _one particular weight_ in the last layer will affect the cost for that _one particular training example_. This is just one very specific piece of information, and we'll need to calculate a lot more to get the entire gradient vector. | 这条公式告诉我们：拨动最后一层里*那一个特定权重*，会如何影响*那一个特定训练样本*的代价。这只是一条非常具体的信息；要拿到整个梯度向量，还得再算一大堆。 |
| But the good news is that we've already laid the foundations for the rest of the work that needs to be done. Now it's just a process of generalizing our results until we have an understanding (in the form of the gradient vector) of how all the weights and biases in the network affect the overall cost. | 但好消息是：剩下工作所需的地基，我们已经打好了。接下来只不过是把结果不断推广（generalize），直到我们能（以梯度向量的形式）理解：网络里所有权重和偏置是如何影响整体代价的。 |

> [!note]- 词汇注释 · 拼装
> - *put it all together* —— 把全部拼合起来。
> - *break down ... into ...* —— 把……分解成……。本篇的高频动词搭配。
> - **generalize** /ˈdʒenrəlaɪz/ —— 推广、泛化。
> - *lay the foundations* —— 打好地基。
> - **entry** /ˈentri/ —— （向量/矩阵的）分量、元素。the entries of the gradient vector。

## 全部训练数据的代价（The Cost for All Training Data）

| 原文 | 译文 |
|---|---|
| Notice the little subscript zero in the derivative we calculated, $\frac{\partial C_{0}}{\partial w^{(L)}}$. That's there because $C_0$ is just the cost of a single training example. | 注意我们刚算出的导数 $\frac{\partial C_{0}}{\partial w^{(L)}}$ 里那个小小的下标零：它在那儿，是因为 $C_0$ 只是单个训练样本的代价。 |
| The full cost function for the network ($\textcolor{red}{C}$) is the average all the individual costs for each training example: | 网络完整的代价函数（$C$），是所有训练样本各自代价的平均值： |

$$
\textcolor{red}{C} = \frac{1}{n} \sum_{k=0}^{n-1} \textcolor{red}{C_k}
$$

| 原文 | 译文 |
|---|---|
| So if we want the derivative of $C$ with respect to the weight (rather than the derivative of $C_0$ with respect to the weight), we need to take the average of all the individual derivatives: | 所以，如果我们想要 $C$ 对该权重的导数（而不是 $C_0$ 对该权重的导数），就需要对所有单个导数取平均： |

$$
\frac{\textcolor{red}{\partial C}}{\textcolor{blue}{\partial w^{(L)}}} =
\frac{1}{n} \sum_{k=0}^{n-1} \frac{\textcolor{red}{\partial C_k}}{\textcolor{blue}{\partial w^{(L)}}}
$$

| 原文 | 译文 |
|---|---|
| This expression tells us how the overall cost of the network will change when we wiggle the last weight. | 这个表达式告诉我们：轻轻拨动（wiggle）最后一个权重时，网络的整体代价会怎么变。 |
| Recall that the entries of the gradient vector are the partial derivatives of the cost function $C$ with respect to every weight and bias in the network. So this derivative, $\frac{\partial C}{\partial w^{(L)}}$, is one of its entries! | 回想一下：梯度向量的各个分量，就是代价函数 $C$ 对网络里每一个权重和偏置的偏导数。所以这个导数 $\frac{\partial C}{\partial w^{(L)}}$，正是其中一个分量！ |

> [!note]- 词汇注释 · 全部数据
> - **average** /ˈævərɪdʒ/ —— 平均（数）；作动词指取平均。

## 全部权重与偏置的导数（The Derivative for All Weights And Biases）

| 原文 | 译文 |
|---|---|
| But to compute the full gradient, we will also need all the other derivatives with respect to all the other weights and biases in the entire network. | 但要算出完整的梯度，我们还需要对整个网络里其余所有权重和偏置的导数。 |

$$
\textcolor{red}{\nabla C} =
\left[\begin{array}{c}
\frac{\textcolor{red}{\partial C}}{\textcolor{blue}{\partial w^{(1)}}} \\[0.8em]
\frac{\textcolor{red}{\partial C}}{\textcolor{pink}{\partial b^{(1)}}} \\[0.5em]
\vdots \\[0.5em]
\frac{\textcolor{red}{\partial C}}{\textcolor{blue}{\partial w^{(L)}}} \\[0.8em]
\frac{\textcolor{red}{\partial C}}{\textcolor{pink}{\partial b^{(L)}}}
\end{array}\right]
$$

| 原文 | 译文 |
|---|---|
| Let's work on computing the bias in the last layer next. | 接下来，我们来算最后一层的偏置。 |

> [!note]- 词汇注释 · 全部参数
> - **compute** /kəmˈpjuːt/ —— 计算。按流程求出结果，与 calculate 略同。
> - **entire** /ɪnˈtaɪə/ —— 整个的。the entire network 全网络。
> - *work on ...* —— 接下来做……、着手处理……。Let's work on computing...
> - *in the last layer* —— 在最后一层。层序说法：last / second-to-last / earlier layers。
> - 纯中文说明：本节公式即开篇那张梯度矩阵的完整版；颜色约定全文一致——蓝为权重、粉为偏置、绿为加权和 $z$、红为代价。

## 偏置（The Bias）

| 原文 | 译文 |
|---|---|
| The good news is that the sensitivity of the cost function to a change in the bias is almost identical to the equation for a change to the weight. | 好消息是：代价函数对偏置变化的敏感度，和权重那套方程几乎一模一样。 |
| As a reminder, here's the equation we found earlier for the derivative with respect to the weight in the last layer: | 回顾一下，这是我们此前得到的、对最后一层权重的导数： |

$$
\frac{\textcolor{red}{\partial C_{0}}}{\textcolor{blue}{\partial w^{(L)}}} =
\frac{\textcolor{green}{\partial z^{(L)}}}{\textcolor{blue}{\partial w^{(L)}}}
\frac{\partial a^{(L)}}{\textcolor{green}{\partial z^{(L)}}}
\frac{\textcolor{red}{\partial C_0}}{\partial a^{(L)}}
$$

| 原文 | 译文 |
|---|---|
| And here's the new equation for the derivative with respect to the bias in the last layer (instead of the weight): | 而这是新方程——对最后一层偏置（而非权重）的导数： |

$$
\frac{\textcolor{red}{\partial C_{0}}}{\textcolor{pink}{\partial b^{(L)}}} =
\frac{\textcolor{green}{\partial z^{(L)}}}{\textcolor{pink}{\partial b^{(L)}}}
\frac{\partial a^{(L)}}{\textcolor{green}{\partial z^{(L)}}}
\frac{\textcolor{red}{\partial C_0}}{\partial a^{(L)}}
$$

| 原文 | 译文 |
|---|---|
| All we've done is replaced the $\frac{\partial z^{(L)}}{\partial w^{(L)}}$ with a $\frac{\partial z^{(L)}}{\partial b^{(L)}}$. | 我们所做的，不过是把 $\frac{\partial z^{(L)}}{\partial w^{(L)}}$ 换成了 $\frac{\partial z^{(L)}}{\partial b^{(L)}}$。 |
| Luckily, this new derivative is simply $1$: | 幸运的是，这个新导数干脆就是 $1$： |

$$
\textcolor{green}{z^{(L)}} = \textcolor{blue}{w^{(L)}} a^{(L-1)} + \textcolor{pink}{b^{(L)}}
\quad \longrightarrow \quad
\frac{\textcolor{green}{\partial z^{(L)}}}{\textcolor{pink}{\partial b^{(L)}}} = 1
$$

| So the derivative for the bias turns out to be even simpler than the derivative for the weight. | 于是，偏置的导数算出来竟比权重的还要简单。 |
| That's two gradient entries taken care of. | 就这样，梯度向量里已经搞定两个分量了。 |

## 前面各层的权重与偏置（Previous Layers' Weights and Biases）

| 原文 | 译文 |
|---|---|
| We've now determined how changes to the last weight and last bias in our super-simple neural network will affect the overall cost, which means we already have two of the entries of our gradient vector. | 现在，我们已经弄清这个超简单网络里最后一个权重和最后一个偏置的变化会如何影响整体代价——也就是说，梯度向量的两个分量已经到手。 |
| All the other weights and biases lie in earlier layers of the network, meaning their influence on the cost is less direct. | We still need to figure out what to do with the activation of the neuron in the previous layer. | 我们还得弄清楚：该怎么处理前一层那个神经元的激活值。 |
| Unsurprisingly, the derivative of the cost with respect to that activation looks very similar to what we've seen already: | 不出所料，代价对该激活值的导数，长得和我们见过的非常像： |

$$
\frac{\textcolor{red}{\partial C_{0}}}{\partial a^{(L-1)}} =
\frac{\textcolor{green}{\partial z^{(L)}}}{\partial a^{(L-1)}}
\frac{\partial a^{(L)}}{\textcolor{green}{\partial z^{(L)}}}
\frac{\textcolor{red}{\partial C_0}}{\partial a^{(L)}}
$$

| 原文 | 译文 |
|---|---|
| To solve it, we just need to figure out the value of $\frac{\partial z^{(L)}}{\partial a^{(L-1)}}$, which we can do by reminding ourselves of the definition of $z^{(L)}$. | 要解出它，只需求出 $\frac{\partial z^{(L)}}{\partial a^{(L-1)}}$ 的值；办法是回想一下 $z^{(L)}$ 的定义。 |

$$
\textcolor{green}{z^{(L)}} = \textcolor{blue}{w^{(L)}} a^{(L-1)} + \textcolor{pink}{b^{(L)}}
\quad \longrightarrow \quad
\frac{\textcolor{green}{\partial z^{(L)}}}{\partial a^{(L-1)}} = \textcolor{blue}{w^{(L)}}
$$

| 原文 | 译文 |
|---|---|
| So when the activation in the second-to-last layer is changed, the effect on $z^{(L)}$ will be proportional to the weight. | 所以，当倒数第二层的激活值变化时，对 $z^{(L)}$ 的影响与该权重成正比。 |
| But we don't really care about what happens when we change the activation directly, because we don't have control over that. | The trick here is to remember that the activation in the previous layer is actually determined by its own set of weights and biases. In reality, our tree stretches back farther than we've shown so far: | 这里的诀窍是记住：前一层那个激活值，其实是由它自己的一组权重和偏置决定的。实际上，我们的树比目前画出来的要伸得更远： |
| The activation in the second-to-last layer is determined by its own weights and biases. The plot thickens. | 倒数第二层的激活值由它自己的权重和偏置决定。剧情愈发复杂了。 |
| This is where the propagation backwards comes in. Even though we won't be able to directly change that activation, it's helpful to keep track of, because we can just keep iterating this chain rule backwards to see how sensitive the cost function is to previous weights and biases. | 「反向传播」正是在这里登场。虽然我们无法直接改动那个激活值，但把它记在账上有用——因为只要把这条链式法则不断往回迭代，就能看出代价函数对更前面那些权重和偏置的敏感度。 |
| For example, there is a long chain of dependencies between the weight $w^{(L-1)}$ and the cost $C_0$. | 原文 | 译文 |

| So that's how you get the relevant derivatives for this super simple network. | 以上就是为这个超简单网络求出相关导数的方法。 |
| You might think that this is an overly simple example, because each layer has just one neuron, and that it's going to get dramatically more complicated for a real network. | Rather than the activation in a given layer simply being $a^{(L)}$, it will also have a subscript indicating which neuron of the layer it is. | 此时某一层的激活值就不再是光秃秃的 $a^{(L)}$，它还会带一个下标，表明它是这一层里的哪个神经元。 |
| The superscript on each neuron indicates which layer it's on, and the subscript indicates which neuron it is. | 每个神经元的上标表明它在哪一层，下标表明它是这一层里的第几个。 |

| Each weight now needs a few more indices to keep track of where it is, so let's call the weight of the edge connecting this $k$th neuron to this $j$th neuron $\textcolor{blue}{w^{(L)}_{jk}}$: | 现在每个权重都需要多几个编号来标明自己的位置；把连接第 $k$ 个神经元与第 $j$ 个神经元的那条边的权重记作 $w^{(L)}_{jk}$： |
| Those indices, $\textcolor{blue}{jk}$, might feel backwards at first, but it lines up with how you'd index the weight matrix I talked about in [part 1 of this series](https://www.3blue1brown.com/lessons/neural-networks). | $jk$ 这个顺序乍一看是反的，但它和[本系列第 1 课](https://www.3blue1brown.com/lessons/neural-networks)里讲过的权重矩阵的编号方式正好对齐。 |

$$
\textcolor{green}{z_j^{(L)}} =

\textcolor{blue}{w_{j0}^{(L)}} a_0^{(L-1)} +
\textcolor{blue}{w_{j1}^{(L)}} a_1^{(L-1)} +
\textcolor{blue}{w_{j2}^{(L)}} a_2^{(L-1)} +
\textcolor{pink}{b_j^{(L)}}
$$

| 原文 | 译文 |
|---|---|
| We still wrap this weighted sum with a special function like a sigmoid or a ReLU to get the final activation. | 我们仍然把这个加权和包进一个特殊函数（比如 sigmoid 或 ReLU），得到最终的激活值。 |

$$
\frac{\textcolor{red}{\partial C_0}}{\textcolor{blue}{\partial w_{jk}^{(L)}}} =

\frac{\textcolor{green}{\partial z_j^{(L)}}}{\textcolor{blue}{\partial w_{jk}^{(L)}}}
\frac{\partial a_j^{(L)}}{\textcolor{green}{\partial z_j^{(L)}}}
\frac{\textcolor{red}{\partial C_0}}{\partial a_j^{(L)}}
$$

| 原文 | 译文 |
|---|---|
| The only difference is that we're keeping track of more indices, $j$ and $k$, which tell us which weight specifically we're talking about. After all, there are now many weights connecting the second-to-last layer to the last. | 唯一的区别是，我们要多盯几个编号 $j$ 和 $k$，它们说明我们具体说的是哪个权重。毕竟如今连接倒数第二层和最后一层的权重有很多个。 |

| The activation in one layer affects all the activations in the next layer. | 一层的激活值，会影响下一层的所有激活值。 |

\sum_{j=0}^{n_L - 1}

\frac{\partial a_j^{(L)}}{\textcolor{green}{\partial z_j^{(L)}}}
\frac{\textcolor{red}{\partial C_0}}{\partial a_j^{(L)}}
}_{\text{Sum over layer L}}
$$
