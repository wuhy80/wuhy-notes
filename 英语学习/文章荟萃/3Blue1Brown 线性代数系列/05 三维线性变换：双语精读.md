## 三维（Three-dimensions）

| 原文 | 译文 |
|---|---|
| For example, consider a linear transformation with three-dimensional vectors as inputs and three-dimensional vectors as outputs. | 比如，考虑一个吃进三维向量、吐出三维向量的线性变换。 |
| Just like in two dimensions, we can visualize the transformation as the input vector _moving_ to the output vector. | 和二维一样，我们可以把这个变换可视化为输入向量*运动*到输出向量。 |
| To understand the transformation as a whole, we imagine every possible vector move to its corresponding output vector. | 要理解整个变换，我们就想象每一个可能的向量都移动到它对应的输出向量。 |
| It gets very crowded to think about all the vectors as arrows all at once. Instead, we can get a sense for the behavior of the function by transforming the grid in a way that keeps grid lines parallel and evenly spaced. | 把所有向量一次性全想一遍、每个都画成箭头，实在太挤了。换个办法：让网格以「保持网格线平行且等距」的方式变换，由此来感受这个函数的行为。 |
| Just as with two dimensions, one of these transformations is completely determined by where the basis vectors go. But now, there are three basis vectors: The unit vector in the $x$-direction, $\hat{\imath}$, the unit vector in the $y$-direction, $\hat{\jmath}$, and the unit vector in the $z$-direction, called $\hat{k}$. | 和二维一样，这类变换完全由基向量（basis vector）的去向决定。只不过现在有三个基向量了：$x$ 方向上的单位向量 $\hat{\imath}$，$y$ 方向上的单位向量 $\hat{\jmath}$，以及 $z$ 方向上的单位向量，记作 $\hat{k}$。 |
| In fact it's easier to think about these transformations by only following the basis vectors, since the full 3d grid representing all points can get messy. By leaving a copy of the original axes in the background, we can think about the coordinates where each of the three basis vectors lands. | 实际上，只跟着基向量走会更容易想清楚这些变换，因为表示所有点的完整三维网格会变得乱糟糟。在背景里留一份原始坐标轴的副本，我们就可以只思考三个基向量各自落在哪个坐标上。 |
| Record the coordinates of these three resulting vectors as the columns of a 3x3 matrix. This gives a matrix that completely describes your transformation using nine numbers. | 把这三个新向量的坐标记下来，作为 3×3 矩阵的列。这样得到的矩阵，用九个数就完整描述了你的变换。 |
| To see where a vector with coordinates $x$, $y$ and $z$ lands, the reasoning is almost identical to what it was for two dimensions: Each of those coordinates can be thought of as instructions for how to scale each basis vector, so that they add together to get your vector. | 要看坐标为 $x$、$y$ 和 $z$ 的向量落在哪儿，推理过程几乎和二维时一模一样：每个坐标都可以想成「该如何缩放对应基向量」的说明，缩放后的基向量加在一起，就得到你的向量。 |

## 变换的复合（Combining Transformations）

| 原文 | 译文 |
|---|---|
| Multiplying two matrices is also similar to what we did for two dimensions: Whenever you see two 3x3 matrices getting multiplied together, you should imagine first applying the transformation encoded by the right one, then applying the transformation encoded by the left one. | 两个矩阵相乘，也和我们二维时做的事情类似：每当你看到两个 3×3 矩阵相乘，就应该想象先应用右边那个矩阵编码（encode）的变换，再应用左边那个矩阵编码的变换。 |
| The resulting transformation is the combination of applying the two matrices one after the other. | 所得的变换，就是把两个矩阵先后应用一遍的组合效果。 |
| Three dimension matrix multiplication turns out to be very important for computer graphics and robotics, since things like rotations in three-dimensions can be very hard to describe, but are easier to wrap your mind around if you break them down as the composition of different transformations. | 事实证明，三维矩阵乘法对计算机图形学和机器人学非常重要：三维空间里的旋转之类的操作，直接描述会非常困难，但如果把它们拆解成不同变换的复合（composition），就容易想明白了。 |
| Performing this matrix multiplication numerically is, once again, very analogous to the two-dimensional case. | 原文 | 译文 |

| Here's another puzzle for you: It's also meaningful to talk about a linear transformation from two-dimensional space to three-dimensional space, or from three-dimensions down to two. When is it meaningful to talk about multiplying such matrices, and why? | 再给你一道谜题：谈「从二维空间到三维空间的线性变换」，或者「从三维降到二维的变换」，同样是有意义的。你能把这样的变换可视化出来吗？你能用矩阵表示它们吗？各自该有几行几列？什么时候谈论「这样的矩阵相乘」才有意义？为什么？ |
| A simple example from 3d to 2d would be the shadow cast by a 3d object onto a 2d plane. Although, in order for the transformation to be linear, the light rays should be considered parallel to each other to simplify the problem. If you consider the light source to be something really far away, like the sun, then this is a reasonable choice to make. | （译注：原文此处是一道自由问答题，下为官网给出的参考回答。）从三维到二维的一个简单例子，就是三维物体投到二维平面上的影子。不过，要让这个变换成为线性变换，得把光线视为彼此平行，以简化问题。如果你把光源想成非常非常远的东西——比如太阳——那么这就是一个合理的选择。 |
| You can represent these transformations with matrices. The number of columns corresponds to the dimension of the input and the number of rows corresponds to the dimension of the output. For example, a matrix that maps coordinates in 3d to 2d would have three columns and two rows. | 你可以用矩阵表示这些变换。列数对应输入的维数，行数对应输出的维数。比如，把三维坐标映射到二维的矩阵，就该有三列、两行。 |
