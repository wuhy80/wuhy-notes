## 从二维到三维（2d to 3d）

| 原文 | 译文 |
|---|---|
| It's perfectly reasonable to talk about transformations between dimensions, such as a transformation from 2d space to 3d space. Again, what makes one of these linear is that grid lines remain parallel and evenly spaced, and the origin maps to the origin. | 谈论维度之间的变换是完全合理的，比如从二维空间到三维空间的变换。重申一遍：让这类变换成为线性变换的，是网格线保持平行且等距，以及原点映到原点。 |
| What we have pictured here is the input space on the left, which is 2d space, and the output of the transformation shown on the right. The reason we're not showing the inputs move to their outputs like we usually do is not just visualization laziness, it's worth emphasizing that 2d vector inputs are a very different animal from the 3d vector outputs, living in a completely separate and unconnected space. | 这里画出的，是左边的输入空间（二维空间），以及右边展示的变换输出。我们不像往常那样把输入动画到输出，原因不只是可视化上偷懒：值得强调的是，二维的向量输入和三维的向量输出是完全不同的两种动物，它们活在完全独立、互不相连的空间里。 |
| Encoding such a transformation with a matrix is really just the same thing as what we've done before: Look at where each basis vector lands, and write the coordinates of its landing spot as the columns of a matrix. | 用矩阵给这样的变换编码（encode），其实和我们之前做的完全是同一件事：看每个基向量落在哪儿，把它落点的坐标写进矩阵的列。 |
| For example, look at the matrix that corresponds to the current transformation that takes $\hat{\imath}$ to the coordinates $\left[\begin{array}{c} 2 \\ -1 \\ -1 \end{array}\right]$, and $\hat{\jmath}$ to the coordinates $\left[\begin{array}{c} 0 \\ 1 \\ 1 \end{array}\right]$. The first column represents where $\hat{\imath}$ lands and the second column represents where $\hat{\jmath}$ lands. | 比如，看对应于当前变换的那个矩阵：它把 $\hat{\imath}$ 变到坐标 $\left[\begin{array}{c} 2 \\ -1 \\ -1 \end{array}\right]$，把 $\hat{\jmath}$ 变到坐标 $\left[\begin{array}{c} 0 \\ 1 \\ 1 \end{array}\right]$。第一列代表 $\hat{\imath}$ 的落点，第二列代表 $\hat{\jmath}$ 的落点。 |
| Notice, this means the matrix encoding our transformation has three rows and two columns, which, to use standard terminology, makes it a "3x2 matrix". | 注意，这意味着编码我们变换的矩阵有三行、两列——用标准术语（terminology）来说，它是一个「3×2 矩阵」（3x2 matrix）。 |
| To use the language of the last chapter, the column space of this matrix, the place where all vectors land, is a 2d plane slicing through the origin of 3d space. But the matrix is still full-rank, since the number of dimensions in this column space is the same as the number of dimensions in your input space. | 借用上一章的语言：这个矩阵的列空间——所有向量落向的地方——是一个切过三维空间原点的二维平面。但这个矩阵仍然是满秩的（full-rank），因为这个列空间的维数，与你的输入空间的维数相同。 |
| So if you see a 3x2 matrix out in the wild, you can know that it has the geometric interpretation of mapping 2 dimensions to 3, since the two columns indicate that the input space has 2 basis vectors, and the 3 rows indicate that the landing spot for each basis vector is described with 3 coordinates. | 所以，如果你在野外看见一个 3×2 矩阵，你就知道它可以作几何解读：把二维映射到三维。因为两列说明输入空间有 2 个基向量，三行说明每个基向量的落点要用 3 个坐标来描述。 |
| Likewise, if you see a 2x3 matrix, with 2 rows and 3 columns, what do you think that means? | 同理，如果你看到一个 2×3 矩阵——2 行 3 列——你觉得那意味着什么？ |
| Well, the 3 columns indicate that the starting space has 3 basis vectors, so we're starting in 3 dimensions. And the 2 rows indicate that the landing spot for each of those 3 basis vectors is described with only 2 coordinates, so they must be landing in 2 dimensions. | （译注：原文此处是一道自由问答题，下为官网给出的参考回答。）嗯，3 列说明起始空间有 3 个基向量，所以我们从三维出发；而 2 行说明那 3 个基向量的落点只用 2 个坐标描述，所以它们必然落在二维里。 |
| This means it's a transformation from three-dimensions down to two; a transformation that would feel deeply uncomfortable to experience. | 这意味着这是一个从三维降到二维的变换——一个要是亲身经历会让人深感不适的变换。 |

## 从二维到一维（2d to 1d）

| 原文 | 译文 |
|---|---|
| You could also have a transformation from two dimensions to one dimension. One-dimensional space is really just the number line, so a transformation like this takes in 2d vectors, and spits out numbers. | 你也可以有从二维到一维的变换。一维空间其实就是数轴（number line），所以这样的变换吃进二维向量，吐出的是数。 |
| Thinking about grid lines remaining parallel and evenly spaced is a bit messy due to all of the squishification, so in this case, the visual understanding for what makes a linear transformation distinct from non-linear transformations is that a line of evenly spaced dots would remain evenly spaced once they're mapped onto the number line. | 由于大量的压扁操作，「网格线保持平行且等距」想起来会有点乱。所以在这种情形下，线性变换区别于非线性变换的视觉理解是：一列等距分布的点，被映射到数轴上之后，依然等距分布。 |
| One of these transformations is encoded with a 1x2 matrix, each of whose 2 columns just has a single entry, indicating the number the $\hat{\imath}$ lands on and the number that $\hat{\jmath}$ lands on. | 这类变换用一个 1×2 矩阵编码：它的两列各自只有一个元素（entry），分别表示 $\hat{\imath}$ 落上的那个数，和 $\hat{\jmath}$ 落上的那个数。 |
| This is actually a surprisingly meaningful type of transformation, with close ties to the dot product that we'll talk about next chapter. Until then, we encourage you to play around with this idea on your own, contemplating the meaning of things like matrix multiplication and linear systems of equations in the context of transformations between dimensions. | 这其实是意义出奇重大的一类变换，它和我们下一章要讲的点积（dot product）关系密切。在那之前，我们鼓励你自己把这个想法把玩起来，在「维度之间的变换」这个语境里，琢磨矩阵乘法、线性方程组这些东西的含义。 |

> [!note]- 词汇注释 · 从二维到一维
> - **number line** —— 数轴。One-dimensional space is really just the number line。
> - **squishification** /ˌskwɪʃɪfɪˈkeɪʃn/ —— 压扁（3b1b 自造的口语名词，来自 squish）。
> - **dot product** —— 点积。下一章的主角。
> - **contemplate** /ˈkɒntəmpleɪt/ —— 沉思、琢磨。contemplating the meaning of things。
> - **encourage** /ɪnˈkʌrɪdʒ/ —— 鼓励。we encourage you to...。
> - **distinct** /dɪˈstɪŋkt/ —— 不同的、有区别的。distinct from non-linear transformations。
> - *play around with* —— 把玩、摆弄。play around with this idea。
> - *take in ... spit out ...* —— 吃进……吐出……。takes in 2d vectors, and spits out numbers。
