## 变换就是函数（Transformations Are Functions）

| 原文 | 译文 |
|---|---|
| To start, let's parse this term: "Linear transformation". _Transformation_ is essentially a fancy word for function; it's something that takes in inputs, and spits out some output for each one. Specifically, in the context of linear algebra, we think about transformations that take in some vector and spit out another vector. | 先来拆解这个术语：「线性变换」（linear transformation）。*变换*（transformation）说白了就是「函数」的花哨说法：它接收输入，并为每个输入吐出某个输出。具体到线性代数的语境，我们考虑的是「吃进一个向量、吐出另一个向量」的变换。 |
| So why use the word "transformation" instead of "function" if they mean the same thing? It's to be suggestive of a certain way to visualize this input-output relation. Rather than trying to use something like a graph, which really only works in the case of functions that take in one or two numbers and output a number, a great way to understand functions of vectors is to use _movement_. | 既然意思一样，为什么用「变换」而不用「函数」？这是为了暗示一种把这种输入-输出关系可视化的特定方式。与其去用图像之类的手段——那其实只对「吃进一两个数、吐出一个数」的函数行得通——理解向量函数的好办法是借用*运动*。 |
| Transformation" suggests movement! | （译注：官网原文此处是吉祥物皮皮在对话气泡里喊的一句话。）「变换」暗示着运动！ |
| If a transformation takes some input vector to some output vector, we imagine that input vector _moving_ to the output vector. | 如果一个变换把某个输入向量变成某个输出向量，我们就想象这个输入向量*运动*到了输出向量那里。 |
| To understand the transformation as a whole, we imagine every possible vector move to its corresponding output vector. | 要理解整个变换，我们就想象每一个可能的向量都移动到它对应的输出向量。 |
| It gets very crowded to think about all vectors all at once, each as an arrow. So let's think of each vector not as an arrow, but as a single point: the point where its tip sits. That way, to think about a transformation taking every possible input vector to its corresponding output vector, we watch every point in space move to some other point. | 把所有向量一次性全想一遍、每个都画成箭头，那实在太挤了。所以我们不再把每个向量想成箭头，而是想成一个单独的点：它的箭尖所在的那个点。这样一来，要思考「变换把每个可能的输入向量送到对应的输出向量」，我们只需看着空间里的每一个点移动到某个别的点。 |
| In the case of transformations in two dimensions, to get a better feel for the shape of a transformation, we can do this with all the points on an infinite grid. It can also be helpful to keep a static copy of the grid in the background, just to help keep track of where everything ends up relative to where it starts. | 对于二维变换，为了更好地感受变换的形状，我们可以对无穷网格上的所有点都这么做。在背景里保留一份静止的网格也会很有帮助，方便追踪每个点最终落在哪里、相对于它从哪儿出发。 |
| Visualizing functions with 2d inputs and 2d outputs like this can be beautiful, and it's often difficult to communicate the idea on a static medium like a blackboard. Here are a couple more particularly pretty examples of such functions. | 像这样把「二维输入、二维输出」的函数可视化出来，可以非常美；而在黑板这类静态媒介上，往往很难传达这层意思。下面再给几个格外漂亮的此类函数例子。 |

## 什么样的变换才是「线性」的？（What makes a transformation "linear"?）

| 原文 | 译文 |
|---|---|
| As you can imagine, though, arbitrary transformations can look pretty complicated, but luckily linear algebra limits itself to a special type of transformation that's easier to understand called _Linear_ transformations. Visually speaking, a transformation is "linear" if it has two properties: all lines must remain lines, without getting curved, and the origin must remain fixed in place. | 不过可以想象，任意的变换看上去可能相当复杂。幸运的是，线性代数只局限于一种更容易理解的特殊变换，叫作*线性*（Linear）变换。从视觉上说，一个变换是「线性」的，要满足两条性质：所有直线必须保持为直线、不能变弯；原点必须固定在原地。 |
| For example, this right here would not be a linear transform, since the lines get all curvy. | 比如眼前这个就不是线性变换，因为线都变得弯弯曲曲。 |
| And this one would not be a linear transformation because the origin moves. | 而这个也不是线性变换，因为原点动了。 |
| This one here fixes the origin, and it might look like it keeps lines straight, but that's just because we're only showing horizontal and vertical grid lines. | 这个呢，原点是固定的，看起来直线也保持得笔直——但那只是因为我们只展示了横平竖直的网格线。 |
| When you see what it does to a diagonal line, it becomes clear that it's not a linear transformation at all, since it turns that line all curvy. | 等你看到它把一条对角线变成什么样，就一目了然了：它压根不是线性变换，因为它把那条线扭得弯弯曲曲。 |
| In general, you should think of linear transformations as keeping grid lines parallel and evenly spaced, although they might change the angles between perpendicular grid lines. Some linear transformations are simple to think about, like rotations about the origin. | 总的来说，你应该把线性变换想成「保持网格线平行且等距」，尽管它们可能改变相互垂直的网格线之间的夹角。有些线性变换很好想，比如绕原点的旋转。 |
| Others, as we will see later, are a little trickier to describe with words. | 还有一些，正如我们后面会看到的，用语言描述起来要更绕一点。 |
| **Which of the transformations in the image below are linear?** | （译注：原文此处是一道互动测验的题干，配图见官网原页——A、B、C、D 四幅变换图选 linear 的。）**下图中的哪些变换是线性的？** |
| C is the only transformation where the lines are parallel and evenly spaced. | （译注：上题的答案解析。）C 是唯一一个线条保持平行且等距的变换。 |

> [!note]- 词汇注释 · 线性的定义
> - **arbitrary** /ˈɑːbɪtrəri/ —— 任意的。arbitrary transformations。
> - **property** /ˈprɒpəti/ —— 性质。two properties 两条性质。
> - **remain** /rɪˈmeɪn/ —— 保持。lines must remain lines。
> - **curvy** /ˈkɜːvi/ —— 弯曲的。get all curvy 变得弯弯曲曲。
> - **evenly spaced** —— 等距分布的。parallel and evenly spaced。
> - **perpendicular** /ˌpɜːpənˈdɪkjə/ —— 垂直的。
> - **tricky** /ˈtrɪki/ —— 棘手的、不好处理的。a little trickier to describe。
> - *fixed in place* —— 固定在原地。

## 矩阵（Matrices）

| 原文 | 译文 |
|---|---|
| How do you think you could do these transformations numerically? If you were, say, programming some animations to make a video teaching the topic, what formula do you give the computer so that if you give it the coordinates of a vector, it can tell you the coordinates of where that vector lands? | 你觉得怎么才能用数字来实现这些变换？比如说，假如你在编写一些动画、要做一期讲这个主题的视频，你会给计算机一条什么公式，使得输入一个向量的坐标，它就能告诉你这个向量落点的坐标？ |
| It turns out, you only need to record where the two basis vectors $\hat{\imath}$ and $\hat{\jmath}$ go, and everything else will follow. | 结果发现，你只需要记录两个基向量 $\hat{\imath}$ 和 $\hat{\jmath}$ 去了哪里，其余一切都随之确定。 |
| For example, consider the vector $\vec{\mathbf{v}}$ with coordinates $\begin{bmatrix}-1\\2\end{bmatrix}$, meaning it is equal to $-1\hat{\imath} + 2\hat{\jmath}$. | 举个例子，考虑坐标为 $\begin{bmatrix}-1\\2\end{bmatrix}$ 的向量 $\vec{\mathbf{v}}$，也就是说它等于 $-1\hat{\imath} + 2\hat{\jmath}$。 |
| If we play some transformation and follow where all three of these vectors go, the property that grid lines remain parallel and evenly spaced has a really important consequence: the place where $\vec{\mathbf{v}}$ lands will be $(-1)$ times the vector where $\hat{\imath}$ landed, plus $2$ times the vector where $\hat{\jmath}$ landed. | 如果我们播放某个变换、追踪这三个向量各自去了哪里，「网格线保持平行且等距」这条性质有一个非常重要的推论：$\vec{\mathbf{v}}$ 的落点，将是 $\hat{\imath}$ 落点向量的 $(-1)$ 倍，加上 $\hat{\jmath}$ 落点向量的 $2$ 倍。 |
| In other words, it started off as a certain linear combination of $\hat{\imath}$ and $\hat{\jmath}$, and it ended up at that same linear combination of where those two vectors landed. | 换句话说，它出发时是 $\hat{\imath}$ 和 $\hat{\jmath}$ 的某个线性组合，最终就落在「那两个向量落点」的同一线性组合上。 |
| Now, given that we're actually showing you the full transformation, you could have just looked to see that $\vec{\mathbf{v}}$ has coordinates $\left[\begin{array}{c} 5 \\ 2 \end{array}\right]$, but the cool part here is that this gives us a technique to deduce where the vector lands without needing to watch the transformation. | 既然我们实际上给你看了完整的变换，你本来可以直接看出 $\vec{\mathbf{v}}$ 的坐标是 $\left[\begin{array}{c} 5 \\ 2 \end{array}\right]$；但这里的妙处在于，这给了我们一个不必盯着变换看、就能推断向量落点的技巧。 |
| This is a good point to pause and ponder because it's pretty important. | 这里值得停下来好好琢磨一下，因为它相当重要。 |
| Using the technique from above, write the vector $\left[\begin{array}{c} -3 \\ -1 \end{array}\right]$ in terms of the standard basis as $(-3)\hat{\imath} + (-1)\hat{\jmath}$. Then, transform $\hat{\imath}$ and $\hat{\jmath}$ to their destinations and compute the new linear combination. | （译注：原文此处是一道互动测验的答案解析，题目在官网原页面上——给定 $\hat{\imath}\to\begin{bmatrix}-1\\1\end{bmatrix}$、$\hat{\jmath}\to\begin{bmatrix}-2\\-1\end{bmatrix}$ 的变换，求 $\begin{bmatrix}-3\\-1\end{bmatrix}$ 的落点。）用上面的技巧，把向量 $\left[\begin{array}{c} -3 \\ -1 \end{array}\right]$ 按标准基写成 $(-3)\hat{\imath} + (-1)\hat{\jmath}$，然后把 $\hat{\imath}$ 和 $\hat{\jmath}$ 变换到各自的目的地，再算出新的线性组合。 |
| So given the transformation described by $\hat{\imath}\to\begin{bmatrix}-1\\1\end{bmatrix}$ and $\hat{\jmath}\to\begin{bmatrix}-2\\-1\end{bmatrix}$, the vector $\left[\begin{array}{c} -3 \\ -1 \end{array}\right]$ is transformed to $\left[\begin{array}{c} 5 \\ -2 \end{array}\right]$. Of course, we can double check our work by visualizing where the standard basis vectors go. | 于是，给定由 $\hat{\imath}\to\begin{bmatrix}-1\\1\end{bmatrix}$ 与 $\hat{\jmath}\to\begin{bmatrix}-2\\-1\end{bmatrix}$ 所描述的变换，向量 $\left[\begin{array}{c} -3 \\ -1 \end{array}\right]$ 就被变换成了 $\left[\begin{array}{c} 5 \\ -2 \end{array}\right]$。当然，我们可以把标准基向量的去向可视化出来，复核一下答案。 |
| So long as we have a record of where $\hat{\imath}$ and $\hat{\jmath}$ land, this technique works for any vector that is passed to the transformation function. | 只要我们有 $\hat{\imath}$ 和 $\hat{\jmath}$ 落点的记录，这个技巧对任何传入变换函数的向量都管用。 |
| Writing the vector with more general coordinates, $x$ and $y$: It will land on $x$ times the vector where $\hat{\imath}$ lands, $\left[\begin{array}{c} 1  \\ -2 \end{array}\right]$, plus $y$ time the vector where $\hat{\jmath}$ lands, $\left[\begin{array}{c} 3 \\ 0 \end{array}\right]$. | 把向量写成更一般的坐标 $x$ 和 $y$：它会落在「$x$ 乘以 $\hat{\imath}$ 的落点 $\left[\begin{array}{c} 1  \\ -2 \end{array}\right]$，加上 $y$ 乘以 $\hat{\jmath}$ 的落点 $\left[\begin{array}{c} 3 \\ 0 \end{array}\right]$」上。 |

$$
L(\vec{\mathbf{v}}) = x\left[\begin{array}{c}1 \\-2\end{array}\right]+y\begin{bmatrix}\:3\:\\0\end{bmatrix}
$$

| 原文 | 译文 |
|---|---|
| Carrying out that sum, we see that it lands on $\left[\begin{array}{c} 1 x+3 y \\ -2 x+0 y \end{array}\right]$. Given any vector you can tell where it lands using this formula. | 把这个和算出来，我们看到它落在 $\left[\begin{array}{c} 1 x+3 y \\ -2 x+0 y \end{array}\right]$ 上。给定任何向量，你都能用这条公式说出它的落点。 |

$$
L(\vec{\mathbf{v}}) = \begin{bmatrix}1x + 3y \\ -2x + 0y \: \end{bmatrix}
$$

| 原文 | 译文 |
|---|---|
| What all of this is saying is that the two-dimensional linear transformation is completely described by just four numbers: The two coordinates for where $\hat{\imath}$ lands, and the two coordinates for where $\hat{\jmath}$ lands. Isn't that cool? | 这一切所说的就是：二维线性变换完全由四个数就能描述——$\hat{\imath}$ 落点的两个坐标，加上 $\hat{\jmath}$ 落点的两个坐标。是不是很酷？ |
| It's common to package these four numbers into a 2x2 grid of numbers, called a "2x2 matrix", where you can interpret the columns as the two special vectors where $\hat{\imath}$ and $\hat{\jmath}$ land. | 人们常把这四个数打包成一个 2×2 的数字方阵，叫「2×2 矩阵」（2x2 matrix）；你可以把它的列解读为 $\hat{\imath}$ 和 $\hat{\jmath}$ 落点的那两个特殊向量。 |
| If you're given a 2x2 matrix describing a linear transformation, and a specific vector, and you want to know where the linear transformation takes that vector, you take the coordinates of that vector, multiply them by the corresponding column of the matrix, then add together what you get. This corresponds with the idea of adding scaled versions of our new basis vectors. | 如果给你一个描述线性变换的 2×2 矩阵和一个特定向量，你想知道这个线性变换把向量送到哪里：取这个向量的坐标，分别乘以矩阵中对应的列，再把所得相加。这正对应「把新基向量的缩放版相加」的想法。 |
| When you do this super generally, with a matrix that has entries $\left[\begin{array}{cc}a & b \\c & d\end{array}\right]$, and a vector $\left[\begin{array}{c} x \\ y \end{array}\right]$, what's the resulting vector? | Well, it will be $x \left[\begin{array}{c} a \\ c \end{array}\right] + y \left[\begin{array}{c} b \\ d \end{array}\right]$ and, putting this together, you get a vector $\left[\begin{array}{c} ax + by \\ cx + dy \end{array}\right]$. | 它就是 $x \left[\begin{array}{c} a \\ c \end{array}\right] + y \left[\begin{array}{c} b \\ d \end{array}\right]$，合在一起，你就得到向量 $\left[\begin{array}{c} ax + by \\ cx + dy \end{array}\right]$。 |
| You could even define this as "matrix vector multiplication" when you put the matrix to the left of the vector, like a function. Then you could make high schoolers memorize this formula for no apparent reason. | 你甚至可以就此把它定义为「矩阵-向量乘法」——把矩阵放在向量左边，就像一个函数那样。然后，你就可以让高中生毫无道理地背下这条公式。 |
| But isn't it more fun to think about the columns as the transformed versions of your basis vectors, and to think of the result as the appropriate linear combination of those vectors? | 但把列想成基向量变换后的版本、把结果想成这些向量的相应线性组合，岂不是更有意思？ |

## 形式化性质（Formal Properties）

| 原文 | 译文 |

| There's an unimaginably large number of possible transformations, many of which are rather complicated to think about. As we discussed, linear algebra limits itself to a special type of transformation called a _linear_ transformation which we defined as a transformation where grid lines remain parallel and evenly spaced. In addition to the geometric notion of "linearity," we can also express that a function is linear if it satisfies the following two properties: | 可能的变换多得难以想象，其中许多想起来相当复杂。正如我们讨论过的，线性代数只局限于一种特殊类型的变换，叫*线性*（linear）变换——我们把它定义为「网格线保持平行且等距」的变换。除了「线性」这个几何概念之外，我们也可以这样表述：如果一个函数满足下面两条性质，它就是线性的： |
| To help appreciate just how constraining these two properties are, and to reason about what this implies a linear transformation must _look_ like, consider the important fact from the [last chapter](https://www.3blue1brown.com/lessons/span) that when you write down a vector with coordinates, say $\vec{\mathbf{v}} = \begin{bmatrix}-1\\2\end{bmatrix}$, you are effectively writing it as a linear combination of two basis vectors. | 为了帮你体会这两条性质到底有多强的约束力，并推理出线性变换必然*长*什么样，想想[上一章](https://www.3blue1brown.com/lessons/span)的一个重要事实：当你写下带坐标的向量，比如 $\vec{\mathbf{v}} = \begin{bmatrix}-1\\2\end{bmatrix}$ 时，你实际上是在把它写成两个基向量的线性组合。 |
| If you consider how the transformation acts separately on the two vectors that make up the linear combination, respectively $-1\hat{\imath}$ and ${2\hat{\jmath}}$, then the consequence of the transformation preserving sums is that $L(\vec{\mathbf{v}}) =  L(-1 \hat{\imath})+L(2 \hat{\jmath})$. | 如果你分别考察变换如何作用于构成这个线性组合的那两个向量——即 $-1\hat{\imath}$ 和 $2\hat{\jmath}$——那么「变换保持和」的推论就是 $L(\vec{\mathbf{v}}) =  L(-1 \hat{\imath})+L(2 \hat{\jmath})$。 |
| Since the transformation preserves scaling, we can rewrite the linear combination as the transformed basis vectors multiplied by the coordinates of the input vector. | 又因为变换保持缩放，我们可以把这个线性组合改写成「变换后的基向量乘以输入向量的坐标」。 |
| This is why if you know where the two basis vectors $\hat{\imath}$ and $\hat{\jmath}$ go, everything else follows.
