阿里的 QwQ32B 大模型不支持 function call，只支持 stream 模式返回。而且他的价格也并不便宜，实际上和 deepseek-chat 的模型是一个价位，但是功能上相对少了不少，模型准确性也比不上 deepseek，除了可以开源部署外没有其他好处。
另外由于不支持 function call，也没有作为 agent 去使用，也就是还需要额外部署一个支持 function call 的大模型作为调度
