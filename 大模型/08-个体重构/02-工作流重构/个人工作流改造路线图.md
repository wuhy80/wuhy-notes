# 个人工作流改造路线图

> [!summary] 核心思路
> 个人工作流改造不适合一步到位，更适合按“记录标准化 -> 处理半自动化 -> 流程可编排 -> 结果可沉淀”的顺序推进。

## 第一阶段：先把输入收拢

目标是减少信息散落。

建议先统一：

- 想法入口
- 会议记录入口
- 任务记录入口
- 资料摘录入口

如果入口已经很多，不要先做复杂自动化，先保证能稳定归集。

## 第二阶段：把高频动作模板化

优先模板化这些动作：

- 纪要整理
- 周报生成
- 调研汇总
- 方案初稿
- 复盘提炼

这一阶段的关键不是“更聪明”，而是“更稳定”。

## 第三阶段：让 AI 参与流程而不是只参与对话

典型变化包括：

- 从“问一句答一句”升级为“持续补上下文并迭代”
- 从“生成文本”升级为“整理资料、分类任务、提炼结构”
- 从“聊天记录”升级为“写回知识库”

## 第四阶段：开始积累可复用资产

资产包括：

- 固定提示词
- 输出模板
- 检查清单
- 索引页
- 典型案例

> [!note] 判断标准
> 如果一项工作做过两次以上，就值得考虑是否沉淀成模板或流程资产。

## 第五阶段：尝试任务编排与多工具协同

适合进入这一阶段的前提：

- 你已经有比较稳定的输入结构
- 你已经知道哪些任务容易做错
- 你已经积累了可复用模板

这时再进入：

- MCP
- Agent
- 多步骤工作流
- 多模型协作

会更稳，也更容易真正落地。

## 一个现实排序

1. 先做记录和整理自动化
2. 再做分析和汇总自动化
3. 最后做复杂编排和多 Agent 协作
