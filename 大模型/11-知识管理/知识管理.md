# 大模型知识管理

本目录用于整理大模型参与知识采集、组织、检索、生成与维护的工具和方法。

## 项目索引

- [[LLMWiki]]：面向 Wiki/知识库场景的 LLM 知识管理方案。
- [[GBrain]]：LLMWiki 的工程实现，关注方案如何落地为可运行系统。
- [[知识库方案对比]]：知识库技术路线、开源平台、托管服务与选型框架。

## 统一研究框架

后续评估知识管理项目时，统一关注以下维度：

1. **知识来源**：网页、文件、代码仓库、对话、手工笔记等。
2. **知识加工**：清洗、分块、摘要、标签、实体与关系抽取。
3. **知识组织**：目录、Wiki、双向链接、知识图谱、向量索引。
4. **知识检索**：关键词检索、语义检索、图检索和混合检索。
5. **知识应用**：问答、写作、研究、决策辅助和 Agent 上下文。
6. **持续维护**：增量更新、版本追踪、冲突处理和过期知识识别。
7. **安全边界**：部署方式、权限控制、数据隔离和模型调用范围。

## LLMWiki 与 GBrain 的关系

```text
LLMWiki（知识管理方案与目标）
    └── GBrain（工程实现）
        ├── 数据采集与解析
        ├── 知识组织与索引
        ├── 检索与生成
        └── 应用界面与系统运维
```

| 层次 | 关注内容 |
| --- | --- |
| LLMWiki | 要解决什么知识管理问题，以及知识如何采集、组织、检索和维护 |
| GBrain | 如何通过具体架构、组件、数据模型和接口实现 LLMWiki |

>[!warning] 信息边界
>当前 GBrain 分析对应 [garrytan/gbrain](https://github.com/garrytan/gbrain)，已结合官方仓库核实；项目迭代较快，版本相关结论以各笔记记录的调研日期为准。
