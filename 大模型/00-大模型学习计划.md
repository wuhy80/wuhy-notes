## 三、12 周计划（2026-11-02 起）

### 阶段一：原理筑基（第 1-2 周，11-02 ~ 11-15）

**目标**：能把"从输入 Token 到输出 Token"的全链路讲清楚。

- 第 1 周：Token/Embedding → Transformer 整体结构 → QKV 机制 → 逐层分解；同步对照轩辕卷三（14-18 N-gram 到 LSTM）与卷四（19-24 注意力到层归一化）
- 第 2 周：预训练目标 → 后训练与对齐 → 推理生成过程 → 幻觉与可靠性；同步对照轩辕卷四（25-30 预训练到前沿）
- **论文精读**：《Attention Is All You Need》（2017，对照自己的逐层分解笔记精读一遍）；《Language Models are Few-Shot Learners》GPT-3（2020，重点读 few-shot/上下文学习章节）；《Scaling Laws for Neural Language Models》（Kaplan 2020）与 Chinchilla（2022）二选一精读、另一篇看要点
- **产出**：一篇自己的《从 N-gram 到 LLM 串讲》笔记（可基于轩辕 29-串讲扩写）；白板手推一次 attention 计算
- 打底材料：[[大模型/01-基础原理/大模型基础原理总览|大模型基础原理总览]]

### 阶段二：应用开发主线（第 3-4 周，11-16 ~ 11-29）

**目标**：跑通 RAG 与 MCP 两条主线，分清 Agent 与 Workflow 的边界。

- 第 3 周：精读 18 种 RAG 对比测试 → 重跑 5 分钟手把手 5（RAG 系统）→ 向量数据库 Qdrant 系列
- 第 4 周：MCP 概览/注意事项/疑难问题 → 浏览优秀 MCP 服务器清单 → 挑 1 个 MCP server 接入自己的日常工作流
- **产出**：一个可用的本地 RAG demo + 一篇 MCP 实践笔记
- 可选：[[大模型/07-教程与课程/5分钟手把手/2. 本地部署Graphrag（Pycharm+Ollama+LM Studio）|GraphRAG 部署]]

### 阶段三：Agent 专题（第 5-6 周，11-30 ~ 12-13）

**目标**：选 1-2 个主力框架深入，而不是泛泛比较 20 个。

- 第 5 周：Agent 导航 + 框架选型对比 → 三选一（OpenAI Agents SDK / LangGraph / AutoGen）精读并跑通官方 quickstart；对照 5 分钟手把手 3（Agent）和 6（多 Agent）
- 第 6 周：[[大模型/09-Agent/个人常驻智能体对比|个人常驻智能体对比]]、[[大模型/08-个体重构/05-案例观察/智能工作台中的多Agent工作流实践|多 Agent 工作流实践]]、[[大模型/09-Agent/2026 Agent 技术与论文追踪|Agent 技术与论文追踪]]、[[大模型/09-Agent/云玦 Yunjue Agent Tech Report 全文提取|云玦 Tech Report]]
- **论文精读**：ReAct（2022）→ Toolformer（2023）——Agent 两大源头各读一遍；辅读《A Survey of Context Engineering for LLMs》（arXiv:2507.13334），把「上下文工程」方法论文档化
- **产出**：一个真实场景的小 Agent 项目（可参考 [[大模型/08-个体重构/05-案例观察/PPT Agent 工作流：从需求调研到 SVG 设计稿|PPT Agent 工作流案例]]）

### 阶段四：部署与推理加速（第 7-8 周，12-14 ~ 12-27）

**目标**：掌握容量估算方法，独立完成一次本地部署调优。

- 第 7 周：[[大模型/01-基础原理/LLM推理加速技术地图|推理加速技术地图]]（量化 / KV cache / 投机解码 / 并行调度）→ KV Cache 预算 → 部署容量说明；**用公式给自己要部署的模型完整算一遍**
- 第 8 周：M3 ULTRA 部署 + Ollama 性能测试 + DeepInfer + 显卡吞吐测试；可选 Realtime 语音方案
- **论文精读**：FlashAttention v1/v2（2022-2023，理解 IO-aware 注意力为何是推理加速的地基）；DeepSeek-V3 技术报告（2024-12，重点看 MLA、MoE、FP8 的软硬协同设计）
- **产出**：一篇《我的部署容量测算与实测》笔记

### 阶段五：训练与微调（第 9-10 周，12-28 ~ 2027-01-10）

**目标**：完成一次可复现的领域微调，并把推理模型训练主线补上。

- 第 9 周：微调技术综述 → 数据集构造方式 → [[大模型/03-训练与微调/模型训练/Qwen3.8-27B 赛博治疗实录（一）：三周对症治疗|赛博治疗（一）]]（后训练全流程真实记录）
- 第 10 周：Unsloth（Colab）或 MLX（Mac）二选一跑通微调 → 对照 [[大模型/03-训练与微调/模型训练/Qwen3.8-27B 赛博治疗续作（二）：训练量化部署答疑|赛博治疗（二）]] 与 [[大模型/03-训练与微调/模型训练/Qwen3.8-27B Coder-390 后训练全纪实（赛博治疗完结篇）|完结篇]] 答疑
- **论文精读**：InstructGPT（2022，SFT→RM→PPO 对齐三阶段）→ DPO（2023，免 RL 的偏好优化）→ DeepSeek-R1（2025，GRPO + RLVR，纯强化学习涌现推理）——这条链是对齐与推理训练的主干，必须打通
- **产出**：一次微调实验记录（数据来源、参数、评估方法、失败现象）+ 一篇《推理模型与 RLVR 补课笔记》
- 可选深入：MOE 路由、TileLang 算子、《SFT Memorizes, RL Generalizes》（2025）

### 阶段六：行业视野与整合（第 11-12 周，2027-01-11 ~ 01-24）

**目标**：把 12 周所学串成自己的知识地图，并建立持续跟踪机制。

- 第 11 周：精读 2026 行业报告（从 [[大模型/06-论文与报告/行业报告/2026年 AI 报告与研究阅读地图（Stanford AI Index 扩展）|AI 报告阅读地图]] 进入，Stanford AI Index 解读优先）→ Simon Willison 年度回顾 → Karpathy《2025 LLM Year in Review》（六大范式转变：RLVR、锯齿状智能、Cursor 式应用层、Claude Code、Vibe coding、LLM GUI）

## 五、排序依据与调整原则

> [!note] 为什么这么排
> - P0 原理是一切技术讨论的公共语言，轩辕教程 2026-10-18 刚全文离线，正是消化窗口
> - Agent + MCP 是当前行业主线，也是你笔记密度最高的方向（09-Agent 28 篇）
> - 部署与推理加速是 2026-09 之后最新的关注点，资料最新最全
> - 微调依赖前面的原理与部署知识且成本高，所以放在部署之后
> - 行业报告放在最后整合：有一定技术判断力之后再读，收获更大

调整原则：

1. 每周至少保住 P0 项；P2 项可随时插入或顺延
2. 某阶段实操卡住（硬件/环境）时，先跳到该阶段理论部分，不要停整条线
3. 新热点出现时放进「持续输入」，不改变主线
