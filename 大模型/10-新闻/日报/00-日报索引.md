# AI 早报日报索引

> [!summary] 目录结构
> 日报按 **年 / 月** 分层存放，一个月最多 31 篇，避免一年 300+ 篇平铺在一起：
> ```
> 大模型/10-新闻/日报/
> ├── 00-日报索引.md          ← 本页
> └── YYYY/
>     ├── 00-YYYY 年索引.md   ← 汇总 12 个月
>     └── YYYY-MM/
>         ├── 00-YYYY-MM 月索引.md
>         └── YYYY-MM-DD AI 早报.md
> ```
> 来源是[橘鸦 AI 早报](https://daily.juya.uk/)（RSS + Markdown 端点），每天 11:30 由任务看板自动抓取。

## 年份索引

```dataview
LIST
FROM "大模型/10-新闻/日报"
WHERE type = "ai-daily-index" AND level = "year"
SORT file.name DESC
```

## 全部年份汇总

```dataview
TABLE WITHOUT ID
  key AS "年份",
  length(rows) AS "期数",
  dateformat(max(rows.created), "yyyy-MM-dd") AS "最新一期"
FROM "大模型/10-新闻/日报"
WHERE type = "ai-daily"
GROUP BY dateformat(created, "yyyy")
SORT key DESC
```

## 说明

- **日报**：每篇 frontmatter 带 `type: ai-daily`，`created` 为期号日期。
- **月索引**：每月一个，`type: ai-daily-index`、`level: month`，随当月日报自动更新。
- **年索引**：每年一个，`type: ai-daily-index`、`level: year`。
- 索引页用 Dataview 自动聚合，**新增日报无需手工维护索引**。

> [!note] 关于公开站点
> Dataview 代码块在 Obsidian 里渲染成表格，在公开站点（Quartz）上会显示为原始查询代码——这是本库所有索引页的既有行为（见 [[大模型/10-新闻/00-新闻索引|新闻索引]]）。
