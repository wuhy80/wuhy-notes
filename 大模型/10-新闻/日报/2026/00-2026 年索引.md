# 2026 年 AI 早报索引

> [!summary] 范围
> 2026 年的每日 AI 早报，按月归档，每月最多 31 篇。
> 上级索引：[[大模型/10-新闻/日报/00-日报索引|日报索引]]

## 月份汇总

```dataview
TABLE WITHOUT ID
  key AS "月份",
  length(rows) AS "期数",
  dateformat(min(rows.created), "MM-dd") AS "首期",
  dateformat(max(rows.created), "MM-dd") AS "最新"
FROM "大模型/10-新闻/日报/2026"
WHERE type = "ai-daily"
GROUP BY dateformat(created, "yyyy-MM")
SORT key DESC
```

## 月索引页

```dataview
LIST
FROM "大模型/10-新闻/日报/2026"
WHERE type = "ai-daily-index" AND level = "month"
SORT file.name DESC
```

## 最近 30 期

```dataview
TABLE WITHOUT ID
  file.link AS "日报",
  dateformat(created, "MM-dd") AS "日期",
  status AS "状态"
FROM "大模型/10-新闻/日报/2026"
WHERE type = "ai-daily"
SORT created DESC
LIMIT 30
```
