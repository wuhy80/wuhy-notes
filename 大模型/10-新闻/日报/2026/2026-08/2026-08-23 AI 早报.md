### DeepSeek 调整 API 计费：周末全天统一按低谷价收费 `#1`
> **DeepSeek** 于昨日晚间宣布，自 **8 月 23 日**（今日）零时起，`API` 周末全天不再区分峰谷时段，统一按低谷价计费。工作日继续执行原有峰谷分段计费。

**DeepSeek** 宣布，自北京时间 **2026 年 8 月 23 日（今日）00:00** 起调整峰谷计费规则。

周末（周六、周日）全天不再区分峰谷时段，统一按低谷时段价格收取调用费用。
工作日（周一至周五）继续执行原有峰谷分段计费。

新规则生效前的费用仍按原计费规则结算。

官方表示，此举旨在让用户在周末更灵活安排业务、无需担心高峰时段成本，同时平衡全网算力负载。

用户若在调整后继续使用服务即视为同意新计费方式。
不同意则可选择退出使用并申请退费。

### [Firecrawl 上线 Firecrawl Developer Index](https://firecrawl.dev/developer-index) `#2`
> **Firecrawl** 推出编程 Agent 专用检索索引 `Firecrawl Developer Index`。官方称其覆盖超 **7000** 万个一手来源，召回率在同类编程索引中最高。

**Firecrawl** 官方发布编程 **Agent** 专用检索索引 **Firecrawl Developer Index**，现已上线。

该索引可检索超 **7000 万** 个一手来源，覆盖仓库、文档和 `issue`，内容包括热门公共仓库与文档站点中的 `issue`、已合并 `PR` 和 `README`。

此索引用于让 `Agent` 自行回答代码行为、`API` 契约、报错信息和已知 `bug` 等问题。

根据官方数据，其在覆盖仓库、文档和 `PR` 的 **1179** 条真实开发者查询上达到 `63%` 的 `recall@10`，官方称比次优外部服务商高出约 **10%**。

### [Anthropic 回应降智质疑称测试 Claude Code 配置不影响性能](https://x.com/trq212/status/2091247114869432543) `#6`
> 针对 **Claude Code** 模型在“**high**”推理强度档显示“**10**”的降智质疑，**Anthropic** 成员 **Thariq** 称这是 `API` 服务配置测试造成的数值映射差异。他表示用户所选 `effort level` 不变，内部评估未发现性能回退。

此前用户发现，自 `Claude Code 2.1.237` 版本起，模型在**“high”**推理强度档读取的数值为 **100 中的 10**，与旧版**“low”**档数值相同。

**Anthropic** 团队成员 **Thariq** 回应称，团队有时会先在 `Claude Code` 中测试 **API** 服务配置再推广，当前正在运行的一个测试对数值型努力值的映射方式不同，因此部分用户会在 **high** 档看到**“10”**。

他表示该刻度并非 **0 到 100**，数字本身没有独立意义，用户选择的努力等级就是实际获得的努力等级，内部深度评估已确认这一变化不影响模型性能。

他补充模型本身没有任何变化，正在推出更便捷的反馈与回退报告机制，若用户发现明显回退，可通过 `/feedback` 提交并将 `ID` 发给他，将获得 **credits**。

他还承认 `Opus 5` 是一个表现**“尖峰化（spiky）”**的模型，让模型更一致、更**“像 Claude”**是团队的高度优先事项。
