# 大模型周报索引

> [!summary] 目录结构
> 周报按 **年 / 月** 分层存放，一个月最多 4–5 篇：
> ```
> 大模型/10-新闻/周报/
> ├── 00-周报索引.md          ← 本页
> └── YYYY/
>     ├── 00-YYYY 年索引.md   ← 汇总 12 个月
>     └── YYYY-MM/
>         ├── 00-YYYY-MM 月索引.md
>         └── YYYY-MM-DD 大模型一周新闻.md
> ```
> 每篇按「一周结论、重点新闻、观察、参考来源」整理，跟踪模型发布、Agent/Coding Agent、开源模型、企业采用、安全治理与中美 AI 竞争。

## 年份索引

```dataview
LIST
FROM "大模型/10-新闻/周报"
WHERE type = "weekly-news-index" AND level = "year"
SORT file.name DESC
```

## 全部年份汇总

```dataview
TABLE WITHOUT ID
  key AS "年份",
  length(rows) AS "期数",
  dateformat(max(rows.week_end), "yyyy-MM-dd") AS "最新一期"
FROM "大模型/10-新闻/周报"
WHERE type = "weekly-news"
GROUP BY dateformat(week_end, "yyyy")
SORT key DESC
```

## 说明

- **周报**：每篇 frontmatter 带 `type: weekly-news`，`week_end` 为该周结束日期（也是归档月份的判定依据）。
- **月索引**：每月一个，`type: weekly-news-index`、`level: month`。
- **年索引**：每年一个，`type: weekly-news-index`、`level: year`。
- 索引页用 Dataview 自动聚合，**新增周报无需手工维护索引**。

> [!note] 关于公开站点
> Dataview 代码块在 Obsidian 里渲染成表格，在公开站点（Quartz）上会显示为原始查询代码——这是本库所有索引页的既有行为。
