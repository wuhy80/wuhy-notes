# 2026-06-25 大模型一周新闻

> [!summary] 一周结论
> 2026-06-19 到 2026-06-25 这一周，Agentic AI 的真实采用数据开始出现：Codex 使用增长、CLI Coding Agent 在组织内扩散、Anthropic/Alibaba 争议继续升级。

## 重点新闻

### OpenAI Codex：Agentic AI 使用增长的实证数据

- arXiv 论文《The Shift to Agentic AI: Evidence from Codex》分析 Codex 使用数据，认为 2026 年上半年 agentic AI 使用快速增长。
- 论文提到 Codex 活跃用户在 2026 年上半年增长超过 5 倍，使用场景也从软件开发扩展到更多工作角色。
- 论文还提到多 Agent 并发、skills 使用、长任务请求比例上升等现象。

参考：

- [arXiv - The Shift to Agentic AI: Evidence from Codex](https://arxiv.org/abs/2606.26959)

### CLI Coding Agent：组织扩散受到同事网络影响

- 另一篇关于 Microsoft 早期 2026 年推广 Claude Code 与 GitHub Copilot CLI 的研究显示，首次采用主要受同事网络影响。
- 研究用 merged PR 作为粗略产出代理，发现采用者合并 PR 数量有明显提升，但作者也说明 PR 数量不等于业务价值。

参考：

- [arXiv - Adoption and Impact of Command-Line AI Coding Agents](https://arxiv.org/abs/2607.01418)

### Anthropic 与 Alibaba 争议继续发酵

- Business Insider、FT 等报道 Anthropic 对 Alibaba 的蒸馏指控在 6 月下旬公开传播。
- 这为后续 Claude Code 在中国安全争议埋下伏笔。

参考：

- [Business Insider - Anthropic is accusing China's Alibaba of exploiting its AI models](https://www.businessinsider.com/anthropic-china-alibaba-exploiting-ai-models-distillation-attack-2026-6)

> [!note] 观察
> Coding Agent 的采用不是单点工具替换，而是组织行为变化：谁先用、如何分享经验、是否建立模板/skills，会显著影响扩散速度。
