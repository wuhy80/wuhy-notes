# 2026-05-28 大模型一周新闻

> [!summary] 一周结论
> 2026-05-22 到 2026-05-28 这一周，Anthropic 以融资、估值和 Claude Opus 4.8 强化头部位置；同时学术界开始做 Claude Code 与 Codex 的真实任务对比。

## 重点新闻

### Anthropic：估值接近万亿美元，Claude Opus 4.8 发布

- Barron's、Business Insider 等报道 Anthropic 完成大规模融资，估值接近 1 万亿美元。
- 同期发布 Claude Opus 4.8，重点是编码、推理、通用知识和更细的 effort/cost 控制。
- Mythos 仍未全面开放，安全能力和访问限制继续影响 Anthropic 的产品节奏。
