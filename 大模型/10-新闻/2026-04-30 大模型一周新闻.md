# 2026-04-30 大模型一周新闻

> [!summary] 一周结论
> 2026-04-24 到 2026-04-30 这一周，OpenAI 关闭 Sora 应用成为标志性事件：高成本生成式消费产品开始让位于企业、Agent 和开发者工具。同时，Agentic SDLC 研究开始系统化总结 Coding Agent 对软件工程的改变。

## 重点新闻

### OpenAI：Sora 应用关闭，资源转向核心产品

- Sora 移动应用在 2026-04-26 关闭，API 计划后续停止。
- 公开资料将原因指向计算成本、版权压力、产品留存下降，以及 OpenAI 更重视企业和开发者产品的战略转向。

> [!note] 观察
> Sora 关闭说明“酷炫生成能力”不一定等于可持续业务。对大模型公司来说，算力要优先投向付费意愿更强、留存更稳定的工作流产品。

参考：

- [Sora text-to-video model - Wikipedia](https://en.wikipedia.org/wiki/Sora_%28text-to-video_model%29)

### 研究：Agentic AI 正在重塑软件开发生命周期

- arXiv 论文《Agentic AI in the Software Development Lifecycle》把 Claude Code、Codex、Jules、Devin、OpenHands 等纳入同一类 agentic software engineering 系统分析。
- 论文关注的重点不再是“补全一段代码”，而是 repository 级任务、长周期规划、测试执行和人类监督。

参考：

- [arXiv - Agentic AI in the Software Development Lifecycle](https://arxiv.org/abs/2604.26275)
