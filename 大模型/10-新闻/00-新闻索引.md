## 日报归档

> [!summary] 每日 AI 早报
> 每天 11:30 自动抓取[橘鸦 AI 早报](https://daily.juya.uk/)，按 **年 / 月** 分层归档，每月最多 31 篇。
> 入口：[[大模型/10-新闻/日报/00-日报索引|AI 早报日报索引]]

```dataview
TABLE WITHOUT ID
  file.link AS "日报",
  dateformat(created, "MM-dd") AS "日期"
FROM "大模型/10-新闻"
WHERE type = "ai-daily"
SORT created DESC
LIMIT 10
```

## 周报归档

```dataview
TABLE WITHOUT ID
  file.link AS "周报",
  dateformat(week_end, "yyyy-MM-dd") AS "周末",
  status AS "状态"
FROM "大模型/10-新闻"
WHERE type = "weekly-news"
SORT week_end DESC
```

> [!tip] 更新方式
> 新周报设置 `type: weekly-news` 和 `week_end: YYYY-MM-DD` 后，会自动进入上面的归档列表。
