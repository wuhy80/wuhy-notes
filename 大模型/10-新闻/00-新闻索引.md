# 大模型新闻索引

> [!summary] 范围
> 本目录分两条线归档，都按 **年 / 月** 分层：
> - **周报**：2026-04 起的大模型一周新闻，每篇按「一周结论、重点新闻、观察、参考来源」整理，跟踪模型发布、Agent/Coding Agent、开源模型、企业采用、安全治理和中美 AI 竞争。
> - **日报**：每天 11:30 自动抓取[橘鸦 AI 早报](https://daily.juya.uk/)，每月最多 31 篇。

## 日报归档

> [!summary] 每日 AI 早报
> 入口：[[大模型/10-新闻/日报/00-日报索引|AI 早报日报索引]]

```dataview
TABLE WITHOUT ID
  file.link AS "日报",
  dateformat(created, "MM-dd") AS "日期"
FROM "大模型/10-新闻/日报"
WHERE type = "ai-daily"
SORT created DESC
LIMIT 10
```

## 周报归档

> [!summary] 每周大模型新闻
> 入口：[[大模型/10-新闻/周报/00-周报索引|大模型周报索引]]

```dataview
TABLE WITHOUT ID
  file.link AS "周报",
  dateformat(week_end, "yyyy-MM-dd") AS "周末",
  status AS "状态"
FROM "大模型/10-新闻/周报"
WHERE type = "weekly-news"
SORT week_end DESC
```

> [!tip] 更新方式
> 周报设置 `type: weekly-news` 和 `week_end: YYYY-MM-DD`、日报设置 `type: ai-daily` 后，会自动进入上面的归档列表。
