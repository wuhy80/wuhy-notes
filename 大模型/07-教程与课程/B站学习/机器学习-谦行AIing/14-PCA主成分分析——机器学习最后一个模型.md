### 00:00 引言：PCA与高维问题

**[00:00]** 我们来看一下 PCA 主成分分析。它也是一个无监督学习的算法，主要用作对数据特征进行降维，也是我们机器学习课程系列要介绍的最后一个模型。在之前介绍的例子中，用的数据特征都非常的少，但是在日常的实践中，我们经常会遇到包含成百上千个特征的数据集。

**[00:21]** 当特征的维度不断的增长，也就是说特征的个数在不断的增长的时候呢，一系列的问题就会随之而来，被称为维度灾难。主要有几个：第一个就是计算成本急剧增长，在参数量变大的时候会导致严重的算力和时间的开销；再一个就是数据稀疏性与过拟合的风险，在高维的空间中，所谓的维度我们可以理解为特征的个数，数据就会变得非常的稀疏，我们要想训练出结果来，所需要的数据量往往就成指数级的增加了，非常导致我们在模型训练中它寄出噪声而产生过拟合现象；再一个就是距离的度量失效了，在高维的空间中任意两点的距离都趋向于相等了。

![[附件/机器学习-谦行AIing/BV1YMoDBuEm2-t0075.jpg|700]]

**[01:07]** 像我们 KNN、K-Means 等依赖基于距离做的算法基本上就要失效了。还有一个多重共线性的问题，有些特征之间往往存在着一些强相关性，比如说我们讲的波士顿房价的数据集里面，面积和房间的个数明显是正相关的，这种时候呢就会干扰模型的一些评估，成为多重共线性问题。而为了应对数据特征过多，我们就需要对数据进行预处理，其中有一个呢就是减少特征的数量，我们就称之为降维。一般会有两种做法，第一个就是特征选择，就直接从原始的特征库中挑选最有价值的特征的子集，把一些没用的特征或者我们觉得贡献度比较低的特征就给剔除掉。

### 01:40 降维方法对比

**[01:53]** 常见的一些方法也会有方差阈值啊、相关系数，还有 L1 正则化，这个我们之前介绍过，它会把一些特征给关掉它，但是也是有个缺点的，其实这个非常依赖人的判断，而且它是一个非此即彼的粗暴操作，你要么就用，要么就不用，它就导致直接把一些特征给丢弃掉了，但这些特征它虽然相关系数没那么大，但是里面是有一些有用的信息的，也被永久的丢弃掉了。另外一种我们称之为特征的提取，它就是把高维的原始的特征通过不断的做线性变换，线性映射到一个低维的新的特征空间里面去，比如说原来是一个十维的数据，我把它给经过特征变换之后呢，把它变成了一个六维的数据。

![[附件/机器学习-谦行AIing/BV1YMoDBuEm2-t0165.jpg|700]]

**[02:37]** 就变成了减少了四个特征嘛。新的特征呢常常是原始特征的组合，它不是一个粗暴的丢弃，它是把某些相关的特征组合成一些更少的特征，在这样在维度降低的同时呢，又最大程度的保留了原始特征的一些信息。最典型的就是我们今天要介绍的 PCA 主成分分析。PCA 是一种无监督的线性降维的算法，就是它并不需要有数据有标签，核心的思想就是将高维的数据投影到低维的空间中，同时尽可能的保留原来数据中存在的最大的方差，我们就称之为信息量。为什么说方差越大信息量越大呢？因为如果比如说一个特征它里面的数据呢

![[附件/机器学习-谦行AIing/BV1YMoDBuEm2-t0225.jpg|700]]

**[03:21]** 就是从 0.001 到 0.002 之间分布，我们可以认为它里面所有的数据基本都一样，在各个样本之间是没区别的。而数据之间的区别度越大，就是方差越大的时候，里面所蕴含的信息才越大，所以说呢 PCA 就是来找尽量的让我们的数据保留最大的方差。可以举一个例子啊，如果说我们有一个茶壶，我们知道茶壶是一个 3D 的，我们想保留它的二维的图像，给它照张照片，我们可以从不同的角度照。如果从正上方拍摄，可能拍到的就是一个这种我们只能看到一个圆，丢失了壶嘴或者是把手的一些信息。但如果我们选一个绝佳的侧面的角度，拍出来的照片呢就能完整的

**[04:04]** 把茶壶的全貌都看到了，所以说呢找不同的角度，对于我们从把三维的一张一个物体在二维的空间上表示的时候，不同的角度会导致信息量的程度是不一样的。而 PCA 呢就是利用数学空间中帮你找到这一个绝佳的角度的算法，这个角度我们称之为主成分，所以它也叫主成分分析。我们在了解它的数学运算之前，先给大家介绍几个例子，让大家能够直观的感受到。比如说呢现在我们在构建一个做健康风险预测的模型，数据集中是有一个人是有人的身高和体重两个特征的，我们就把这些特征呢都给再用一个二维的空间表示一下，我们会发现基本上身高越高的人

### 04:20 PCA直观理解与例子

![[附件/机器学习-谦行AIing/BV1YMoDBuEm2-t0285.jpg|700]]

**[04:52]** 他的体重相对而言也会往大里面去走，数据大小的是沿着这样一个对角线进行排列的，这两个特征之间也就是存在着强烈的正相关关系。而 PCA 就是找到一条最能代表数据走势的对角线的方向，大概就是这条红线，把所有的点都投影到这个线上，我们就把投影到原点的距离，这样就只是纯粹的一个数字了，来表示身高和体重之间的一个关系，这样就是原来需要身高体重两维的数据来表示它的信息，这样就通过一个数字就能表示了。这个数字呢其实就特别像是我们非常熟悉的 BMI 体重指数，就是一个体重除以身高的平方这样算出来了一个数字

![[附件/机器学习-谦行AIing/BV1YMoDBuEm2-t0304.jpg|700]]

**[05:38]** 来代表我们这两维数据之间的关系了，就是 PCA 在不了解相关医学的知识下，纯粹从数据的结构出发，就能自动的发现这个组合的特征，就通过一个数字就能代表原来两维数据了。这就是一个降维，PCA 的一个作用。我们再来看一个例子，比如说我们之前讲的房价预测模型，比如说在原始数据中，如果我们有六个特征，地铁的距离、公交的路数，还有就是商场的数量、学校的评分、医院的等级、公园的面积，这样六个特征。但是如果用它这六个的时候，会有些什么多重共线性？就是地铁和公交的线路其实它俩是高度相关的，特征冗余，这里面其实大量的信息是重复的，会增加模型的复杂度，

![[附件/机器学习-谦行AIing/BV1YMoDBuEm2-t0375.jpg|700]]

**[06:23]** 而且它也非常难以解释，因为特别多嘛。最后其实它背后是隐藏着一定的因子的，我们这个很清楚啊，地段，这六个特征表面上各不相同，但背后都与地段的好坏密切相关。就一个好的地段的小区呢往往同时具备着这种特点，他们携带的这些信息啊是有高度的重叠信息的。我们通过降维呢就是把尽可能重复的信息去掉，用低维度的数量的特征呢就能表示大部分信息。我们来看一下 PCA 是怎么处理这个复杂的特征关系的，它会自动分析这些特征之间的相关性，将六个特征压缩成少数的几个综合成分。比如说第一主成分我们称之为 PC1，它就约等于地段的综合分

![[附件/机器学习-谦行AIing/BV1YMoDBuEm2-t0465.jpg|700]]

**[07:08]** 是不少权重的做了不同的系数，有些呢可能是地铁距离，这个就是负的，因为离着地铁越远它可能越不重要，其他的可能公交站的数量、商场的数量，这些都是比较正相关的成分，都有权重。这样它可以解释原始数据中大约 70% 的方差信息，所以它还需要找第二个主要的成分，生活的便利性和自然环境，公园的数量、公交也是公交相关的、商场的可能地铁的就是一些负相关的了，就捕捉到另外一些维度的差异，就是郊区就是宜居，市中心就是商业，可能解释额外的 15% 的方差。就两个主成分加起来呢就解释了大约 85% 的信息了。所以说 PCA 呢就是通过数学的方法

**[07:52]** 把隐藏的因子挖掘出来，用少量的维度来替代大量的冗余特征，所以它不是一个简单粗暴的把六个特征丢掉四个变成两个了，而是对于这六个特征做一些综合的运算，把它们转换成两个特征。有了 PCA 的直观感受之后呢，我们来看一下它的数学原理，可能里面用的线性代数相关的知识会多一些，所以大家呢如果能够很好的掌握，这是最好的，理解了 PCA 是怎么工作的，其实呢如果说并不能完全的 get 也没有关系，因为后面的工具库其实都给我们封装的特别好了，里面的数学运算呢并不需要我们亲自去参与。在看 PCA 的数学原理之前呢

### 08:00 PCA数学原理

![[附件/机器学习-谦行AIing/BV1YMoDBuEm2-t0555.jpg|700]]

**[08:35]** 先给大家回顾一下两个最基础的概念，一个叫做方差，每个数呢减去它的均值再平方再求平均就是均方差。如果说数据越分散，就是方差就会越大，但如果说数据越密集，比如说所有的数据都一样，那么他们的每个数就和它的均值是一样的，它的平均平方之后再平均还是零，所以说说明它的数据越据点。所以说我们找的数据分散最大的地方，就是方差最大的方向。再一个就是协方差，方差是说的是每个变量自己之间的，每个特征自己的，而协方差是说两个特征之间，它们各自减去均值之后相乘再平均，它们的正负关系和它们的数值就反映了特征这两个变量之间是否是同步变化的。

![[附件/机器学习-谦行AIing/BV1YMoDBuEm2-t0594.jpg|700]]

**[09:25]** 如果它是个正数就说明它俩是正相关的，如果是零的就说明它俩几乎没什么关系，负数就说明它俩是此消彼长的关系，数值越大就说明它们的关系性越强。PCA 的底层逻辑就是建立在协方差矩阵和特征值分解上面。比如说我们有一个包含了 N 个样本的第一个特征的数据集，它做成一个矩阵是 X，就是 N 乘 D，我们希望把它变成了 K 维。大概的过程会有几个，就是原始的数据，这个是一个三维的，三维的，我们先来找方差，数据中在三维的空间中给它找一条线，让所有的数据都可以向这条线上投影取出来，就跟刚才咱们二维空间投影是一样的，三维也是都投影到这一条线上

**[10:12]** 让它方差是最大的，所以我们需要找到这条线，我们就称之为它是第一主成分。我们在正交的方向上找第二主成分，为什么要正交？因为其他的线大概率跟它都差不多，只有跟它垂直的，在三维空间中和它垂直的就是一个平面了，和它垂直的这条平面上找其中的一条线，这条线肯定和它正交，这样保证了和它的信息差距是最大的。在这里面再找方差第二大的，就是我们的第二主成分，再跟它正交，不断的找。当然如果我们是三维的，我们降成两维，只需要找两个主成分就可以了，把它投影到，就投影到两个，这样就变成二维的空间上，这样就对三维的数据就变成两维的了。我们来看一下

![[附件/机器学习-谦行AIing/BV1YMoDBuEm2-t0656.jpg|700]]

**[10:54]** 这其中的数学过程。首先我们对数据做一下去中心化的处理，什么叫去中心化？就是对于每个特征的数据减去该特征的均值。比如说我们有五个人的身高、坐高还有体重，有五个人，计算一下每个特征它的均值是多少，让每个值都减去它们的均值。在很多时候还会做一下标准化，来消除不同特征它的量纲还有量级之间有差异，我们这一个还好，其实差距不是特别大，所以说就只做一下中心化就好了。经过减去均值之后，会发现它都有正有负了，均值就为零了。这样接下来我们来计算一下协方差矩阵，协方差是用来衡量两个变量，就是两个特征之间的相关性的，刚才也提到了

![[附件/机器学习-谦行AIing/BV1YMoDBuEm2-t0705.jpg|700]]

**[11:41]** 我们对于去中心化的数据呢做一下运算，最后除以 N 减 1。为什么要除 N 减 1 不是除以 N 呢？这是一个贝塞尔修正，如果只是除 N 的话，会发现呢我们会低估方差，对它 N 减 1 就可以做一下修正。算出来的是一个 D 乘 D 的对称的矩阵，在对角线上的元素，各个特征身高、坐高还有体重，它的方差是多少，不在对角线上的，他们是两两之间是对称的，就不在对角线上就表示不同的特征两两之间的协方差是多少，他们的相关性是多少。比如说第一个是身高，身高和坐高之间的，我们就可以看到了他们大概 37.3，是一个非常正的相关。其实我们仔细来看，会发现这三个特征都是正相关的，

**[12:31]** 所以说他们之间肯定是有一定的冗余信息的，PCA 帮我们尽可能把冗余信息去掉，只保留它们的最大方向上的方差就可以了。就计算特征值与特征向量，特征向量呢其实就是我们刚才画的线中那一条红线的方向，我们也称之为主成分。特征值呢其实就是把找到这个主方向之后，让所有的数据点都向这个方向上进行投影，算出来呢其实就是方差的大小，也就是主成分的重要性，也称之为，在数学上称之为特征分解，就称之为特征值。当然根据公式的计算，其实公式非常简单，在推导之后可能就能够算出这两个特征值和特征向量分别是多少来解方程，比如说像刚才的

![[附件/机器学习-谦行AIing/BV1YMoDBuEm2-t0825.jpg|700]]

**[13:16]** 我们得出来的我们就能算出三个特征值分别是 300，这样子也会算出三个对应的特征向量大概是多少来。比如说大家可以看到 V1 它基本上全都是正的，这就说明了它是一个综合的体型的大小，三个都是正相关的。V2 第一个是身高，它是负的，坐高和体重为正，其实它就说的是同样的身高下面就是偏胖和偏瘦的这个维度来解释。第三个特征值呢就差不多等于零了，这就说明其实这个数据可以几乎完全落在一个二维平面上就可以表示了，第三维的数据是存在着一些比较强的冗余的。反正就是用数学方法我们计算出这两个来，我们再选取主成分并且构建投影矩阵

**[14:00]** 我们这个比较简单了，第三个都等于零了。可能对于复杂的特征特别多，比如说有一千个特征，那你从中取多少个出来，就降成多少维呢？一般就是看看解释方差率，说每个方我们算出来了，每个特征就是 lambda，其实都是方差是多少，我们就来算算方差除以方差的值的时候，前面的除以它的，每个方差其实就能再除以所有方差的和，其实就是这一个能够解释多少的方差。我们呢其实看看前几大的，算出来呢就能解释 95% 左右，我们就把它给替代的去行了。但像这个比较简单，前两个加起来就 100% 了对不对啊，第一个呢只到了 89%，它只能解释 89% 的方差，所以还不够

**[14:47]** 我们再加上第二个，它就能解释 10% 了，加起来 100% 了将近，所以对我们这个而言就是选 k 等于 2 就行了，把三维数据降成两维。如果说第一个主成分就可以解释掉 95% 以上了，那么我们后面的都可以不要了，就把它降成一维的就可以了。所以这就是解释方差率，我们拿到之后，如果只是前两个，我们就把前两个组成一个矩阵，刚才的特征向量把这两个组成一个矩阵，记为 W。最后一步就是做我们整体的数据投影，就是把我们去中心化，就是中心化这个矩阵的 X 乘以我们的投影矩阵，就得到了降维后的矩阵了，它是一个 N 乘 K 的了，这是我们原来三个特征

### 20:00 PCA与随机森林对比

**[20:01]** 来做降维，它们是有些区别的。第一个就是随机森林它可是监督学习，它是需要数据有标签的，PCA 是不需要数据有标签的。但是随机森林可以捕捉一些非线性的特征之间，PCA 是有线性假设的。再一个就是它的随机森林的解释性当然也特别的高，因为它用的都是原始的特征，把不用的就给丢掉了，而 PCA 实际上是对新的特征，是原来特征的一些线性组合，所以它的可解释性就会低一些了。适用的场景呢，当然随机森林首先你得监督的数据，有标签得有，所以说呢在业务强诉求要求可解释性的时候，还是可以用随机森林的。而 PCA 呢我奔着性能来的，特征高度相关

![[附件/机器学习-谦行AIing/BV1YMoDBuEm2-t1245.jpg|700]]

**[20:42]** 它们的线性重合度特别高的时候，就可以用 PCA 了。但实际技巧中，如果说数据中有标签啊，很多时候呢我们就会用随机森林来筛选掉一些明显没有作用的特征，再用 PCA 做一次二次的降维，往往就会达到一加一大于二的效果。最后再对 PCA 做一下总结，它的一些优势就是可以无人干预，完全基于数据的方差进行正交的变换，可以有效地消除特征之间的共线性，也能降低数据的噪音，缓解过拟合的问题，所以说它的用处也是非常多的，可以做一些以理这些数据探索。它也是有一些局限性的，首先它就是有线性假设，数据的主成分是线性的，对非线性的数据结构呢

**[21:24]** 就效果不佳了，就需要我们用其他的一些算法了。再一个刚才提到了它的可解释性呢是做了一定的丧失了，降维后的一些新的特征呢是原始特征的线性组合，就没有原来的业务含义了。它对极端的异常值是非常敏感的，会让它影响了方差的计算了，这个就是它的一些限定了。好，关于机器学习的模型呢我们基本上就可以介绍到这里了，最后一节课会给大家再做一个总结，和在工业的时候的一些做的一些用法。我们现在讲的这个还是比较偏原理的，而在工业实践中呢可能会有一些更好更自动化的做法，我们下个视频介绍，就给机器学习课程做一个总结就可以了。
