# 2026-11 大模型编程能力榜单汇总

> [!summary] 一句话结论
> 编码能力目前是 **Anthropic 领跑**（Claude Opus 5.5 / Fable 5.1 几乎霸榜前三），**OpenAI GPT-6.1 Sol** 在「网页生成 + 人类盲投」类榜单上反超且性价比最高，**Google Gemini 4（Carbon / Argon）** 稳居前三；国产阵营强在**开源权重、上下文长度和价格/性能比**——DeepSeek V4 Pro、Qwen3.7 Max、GLM-5.2、Kimi K3/K3.1 各自占位。

> [!warning] 别跨表比数字
> 同一个 SWE-bench Verified，不同站点从 80% 到 95% 都有；差异来自**是否带工具、harness 实现、重试次数、评测集版本**。下表每条都标了快照日期与来源，「谁在上升」比具体小数更可信。

## 二、SWE-bench 系（真实 GitHub issue）

### SWE-bench Verified（同榜多口径）

| 来源 | 头部结果 |
|---|---|
| respan.ai（73 模型，带工具/最优配置） | Fable 5 **95%**、Ember 1 92.2%、Opus 4.8 88.6%、Opus 4.7 87.6%、Sonnet 5 85.2%、Opus 4.5 80.9%、Inkling-Small 80.2%、GPT-5.2 80.0% |
| airating（2026-11-04） | Ornith-1.5-397B 86.0%、Ornith-1.0 82.4%、Beam 1.0 81.6%、**DeepSeek V4 Pro 80.6%**、MiniMax M3 80.5%、Kimi K2.6 80.2% |
| llmbenchmark.ai（2026-11-03，口径最保守） | Claude Opus 4.5 79.2%、Claude Sonnet 4 76.8% |

> [!note] 怎么读这张表
> 95% 与 79.2% 不是矛盾，而是「带工具 + 多次重试」与「单次无工具」的差别。做选型时，先确认对方的评测协议，再比数字。

### SWE-bench Pro V2（Scale AI，642 个专业仓任务，2026-10-27）

- Claude Opus 5 **99.4%**，前三名彼此只差 0.3 分；
- **最佳开源：Kimi K3 97.7%（第 4）**，落后榜首 1.7 分；
- 任务为「改 bug 或按需求实现功能」，要求新测试通过且既有测试不回归，最多 250 轮、无联网。

另一站（morphllm，2026-11-09 复核 Scale 榜）口径不同：Muse Spark 1.1 公开集 61.5%、OmniSet 51.5%；厂商汇总里 Opus 5.5 89.9%、Fable 5 80.0%；开源第一 Beam 1.0 66.1%，其后 Qwen3.8-Flash-Next 62.5%、GLM-5.2 62.1%。

## 五、按场景怎么选

| 场景 | 优先看 | 当前推荐 |
|---|---|---|
| 网页 / 前端一把梭 | LMArena WebDev + Terminal-Bench | **GPT-6.1 Sol**（性价比）；求质量 **Opus 5.5** |
| 真实仓库、多文件重构 | SWE-bench Verified / Pro V2 | **Opus 5.5 / Fable 5.1**；省钱 **DeepSeek V4 Pro** |
| 算法题、竞赛式推理 | Codeforces Elo、LiveCodeBench | **DeepSeek V4 Pro**、Gemini 3 Pro |
| 单文件补全、脚本、批处理 | BigCodeBench、Aider polyglot | Claude Opus 4.6、gpt-5 系 |
| 少返工、低 bug 率 | Bug Bench | **GPT-6.1 Sol / Sonnet 5.5**（避开 Opus 5.5） |
| 小屏 / 终端 Agent | Terminal-Bench 4.1 | Opus 5.5（Claude Code）解决率最高 |
| 本地可部署、成本敏感 | 开源梯队 | Kimi K3、GLM-5.2、Qwen3.6-35B-A3B |

## 六、数据可信度与更新节奏

> [!warning] 四条注意事项
> 1. **同模型跨站可差 10–15 个点**：工具、harness、重试次数、子集划分都不同；
> 2. **竞技场类是人主观投票**，日更且波动大，适合看趋势不适合抠排名；
> 3. **厂商自报的 90%+ 要打折看**，优先找第三方复测（Epoch AI、Artificial Analysis、Scale 等）；
> 4. 上面每张表都标了快照日期，做决策前请回到最新快照复核。

- 汇总站：BenchLM、LMMarketCap、Airating、llmbenchmark、ULTRABENCH（取数口径各异，务必看「source / 更新日期」字段）。
- 官方/准官方：LMArena（webdev-arena）、Scale AI SWE-bench Pro、Snorkel Terminal-Bench、Artificial Analysis、LiveBench、Epoch AI。
- 更新节奏：LMArena 每日、AA 每 1–2 周、SWE-bench 系随新模型发布、Terminal-Bench 按版本迭代。
