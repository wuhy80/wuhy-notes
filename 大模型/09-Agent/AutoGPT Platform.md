# AutoGPT Platform

> [!summary] 定位
> `AutoGPT Platform` 已经从早期 Auto-GPT 自主循环项目演进成一个面向 continuous agents 的平台，用于创建、部署和管理长期运行的 AI 工作流。

## 一、核心特征

- continuous agents
- workflow builder
- blocks / integrations
- marketplace
- triggers / schedules
- self-host 支持

## 二、和 Hermes / OpenClaw 的关系

`AutoGPT Platform` 和 [[Hermes]]、[[OpenClaw]] 的共同点是都强调“持续运行”和“替人执行任务”。

差别在于：

- AutoGPT 更平台化、工作流化
- OpenClaw / Hermes 更像个人常驻助理
- Agent Zero 更像本地智能体操作环境

## 三、适合场景

- 企业或个人自动化流程
- 定时任务
- 多工具集成
- 可视化构建 Agent workflow

## 四、风险

- 复杂 workflow 的调试成本
- LLM 调用成本
- 连接外部系统后的权限治理
