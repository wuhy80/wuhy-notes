# OpenHands

> [!summary] 定位
> `OpenHands` 是面向软件开发的智能体平台，提供 Agent Canvas、CLI、Cloud、Enterprise 和 Software Agent SDK，适合代码、终端、浏览器和工程自动化任务。

## 一、核心特征

- Agent Canvas
- CLI / Cloud / Enterprise
- Software Agent SDK
- GitHub / GitLab / Bitbucket 集成
- Slack / Jira / Linear 集成
- 代码、终端、浏览器和工程任务

## 二、和 Hermes / OpenClaw 的关系

它们都属于“能执行任务的智能体”。

差别是：

- OpenHands 明显偏软件开发
- OpenClaw / Hermes 更偏个人通用工作流
- Fellou 更偏网页自动化

## 三、适合场景

- 仓库任务处理
- 自动化测试
- 代码修改
- 依赖升级
- issue 到 PR 的工作流

## 四、风险

- 需要严格控制仓库和凭据权限
- 自动代码修改必须配合测试和 review
- 企业使用要看 RBAC、审计、预算和隔离能力
