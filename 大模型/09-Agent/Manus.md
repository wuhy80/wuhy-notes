# Manus

> [!summary] 定位
> `Manus` 是通用自主 Agent 产品，强调让 AI 接收复杂任务后跨浏览器、代码、文档、设计、报告等环境执行。

## 一、核心特征

- Web / Desktop / Mobile 产品入口
- 浏览器操作
- 网站和应用构建
- slides、设计、文档、研究等生产任务
- API、Slack、Mail Manus 等集成入口

## 二、和 OpenClaw / Hermes 的关系

共同点：

- 都是用户直接使用的 Agent 产品形态
- 都强调“替人完成任务”
- 都比普通聊天助手更偏执行

差别：

- Manus 更像云端通用自主 Agent 产品
- OpenClaw / Hermes 更偏个人常驻智能体或运行时
- Agent Zero 更偏本地智能体环境

## 三、适合场景

- 市场研究
- 竞品分析
- 资料整理
- 网站和应用原型
- slides / 文档生成

## 四、风险

- 闭源平台，内部执行细节不可控
- 需要关注数据、账号、文件上传和执行边界
- 对复杂任务的稳定性仍需实测
