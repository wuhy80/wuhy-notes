# Fellou

> [!summary] 定位
> `Fellou` 是 Agentic Browser，重点不是聊天，而是让浏览器自动完成网页和桌面上的多步骤任务。

## 一、核心特征

- Deep Action
- 自动生成执行计划
- 用户可审批、编辑和中途介入
- 多网页、多账号、多来源研究
- Agentic memory
- 任务调度
- 本地文件和桌面应用能力

## 二、和 OpenClaw / Hermes 的关系

[[OpenClaw]] / [[Hermes]] 更像个人常驻智能体。

`Fellou` 更像浏览器形态的智能体入口：

- 浏览器即工作台
- 网页自动化是主战场
- 账号、表单、网页内容和报告产出是核心场景

## 三、适合场景

- 网页调研
- 竞品分析
- 表单和数据录入
- 多账号内容整理
- 周报和资料汇总

## 四、风险

> [!warning] 网页自动化风险
> Fellou 这类浏览器智能体接入真实账号后，风险来自网页污染、prompt injection、误提交表单、误发消息和账号权限泄漏。
