# Google ADK

> [!summary] 定位
> `Google ADK`（Agent Development Kit）是 Google 提供的 Agent 开发框架，用于构建、评估和部署 Agent 系统。

## 一、为什么值得关注

只要 Google 持续投入 Agent 工程体系，这个方向就值得跟踪，因为它通常不只是一个库，而可能逐步演化为：

- 框架
- 评测体系
- 部署体系
- 云平台集成能力

## 二、我当前的判断

`Google ADK` 现在更适合列入“持续观察的主流框架”，而不是马上当成你的首选主框架。

原因不是它不重要，而是：

- 你的现有知识和实践更多落在 AutoGen / MCP / 多数据源工作流
- 目前你更需要的是成熟可落地的编排能力对比

## 三、适合场景

- 关注 Google Agent 工程路线
- 需要纳入 Google 云 / 模型 / 工具生态做统一思考
- 想对比不同大厂在 Agent 抽象上的差异

## 四、建议怎么用

先把它作为“观察对象”记录：

- 抽象层次怎么设计
- 工具 / memory / evaluation 怎么组织
- 是否适合企业级场景
