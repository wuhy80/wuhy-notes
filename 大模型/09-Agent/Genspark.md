# Genspark

> [!summary] 定位
> `Genspark` 更像一个 all-in-one AI workspace，覆盖搜索、文档、设计、表格、报告、网站生成等生产任务，并提供 `Genspark Claw` 等 Agent 产品入口。

## 一、核心特征

- AI workspace
- Skills / Workflows / Drive
- 文档、PPT、表格、网站、设计等工具集合
- `Genspark Claw` 作为 Agent 产品入口之一

## 二、和 Hermes / OpenClaw 的关系

Genspark 和 [[Hermes]]、[[OpenClaw]] 的共同点是都在往“AI 替你做事”的方向走。

差别是：

- Genspark 更平台化、工具集合化
- OpenClaw / Hermes 更偏个人常驻智能体
- Fellou 更偏浏览器自动化

## 三、适合场景

- 研究报告
- PPT / 文档
- 设计和网页原型
- 多工具生产流

## 四、风险

- 平台锁定
- 复杂任务是否可控要看实际执行日志和人工介入能力
- 私有资料上传和生成内容合规要评估
