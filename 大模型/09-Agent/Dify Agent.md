# Dify Agent

> [!summary] 定位
> `Dify` 更适合作为 Agent / Workflow 平台来理解，而不只是一个 SDK。它强调可视化编排、应用交付和较低的业务接入门槛。

## 一、适合什么人

- 想快速让内部 AI 工具上线
- 希望先把流程跑起来
- 不想一开始就从底层代码写起

## 二、优势

- 可视化
- 上手快
- 交付快
- 比较适合业务验证

## 三、局限

- 深度定制能力要看平台边界
- 很复杂的工程控制未必如代码框架灵活
- 长期看仍需要判断是否会遇到平台天花板

## 四、我的判断

如果目标是“尽快让一个 AI 工作流可用”，Dify 往往比底层 SDK 更快。  
如果目标是“做长期可扩展的核心系统”，还是需要把重点放回 [[LangGraph]]、[[OpenAI Agents SDK]]、[[AutoGen]] 这类代码框架。
