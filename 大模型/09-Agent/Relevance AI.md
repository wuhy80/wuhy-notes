# Relevance AI

> [!summary] 定位
> `Relevance AI` 更偏企业 AI workforce 平台，用于构建、治理和运行多个业务 Agent，让它们执行销售、客服、运营、研究等 playbook。

## 一、核心特征

- AI workforce
- no-code builder
- Invent 自然语言构建 Agent
- MCP 支持
- connectors
- evals
- RBAC
- audit logs
- human-in-the-loop
- production monitoring

## 二、和 Hermes / OpenClaw 的关系

[[Hermes]] / [[OpenClaw]] 更像个人常驻智能体。

`Relevance AI` 更像企业级数字员工平台：

- 多 Agent 分工
- 业务流程 playbook
- 质量评估
- 审计和权限治理
- 人工升级处理

## 三、适合场景

- 销售线索研究
- outbound SDR
- 客服分流
- 内容营销
- meeting preparation
- 运营流程自动化

## 四、风险

- 企业平台依赖
- 业务流程和权限配置复杂
- Agent 出错的影响可能直接进入客户流程
