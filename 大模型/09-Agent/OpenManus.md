# OpenManus

> [!summary] 定位
> `OpenManus` 是一个用于构建通用 AI Agent 的开源框架，名字上明显对标 Manus，但更偏开源实现和框架方向。

## 一、核心特征

- 通用 Agent 框架
- 工具集成
- 开源社区驱动
- 适合作为 Manus 类产品的开源学习对象

## 二、和 Manus 的关系

[[Manus]] 是商业化通用自主 Agent 产品。

`OpenManus` 更适合用来观察：

- 通用 Agent 架构怎么实现
- 工具调用怎么组织
- 是否能复现 Manus 类任务体验

## 三、适合场景

- 学习 Manus 类 Agent 的实现思路
- 做开源框架验证
- 自己搭建通用 Agent 原型

## 四、风险

- 项目成熟度和维护状态需要持续观察
- 不应直接等同于 Manus 官方产品
