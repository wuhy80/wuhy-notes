# Lindy

> [!summary] 定位
> `Lindy` 是面向工作日常的 AI assistant，重点在邮件、日程、会议、跟进、招聘、销售、客服等办公自动化场景。

## 一、核心特征

- 邮件整理和回复草稿
- 会议安排
- 会议记录和跟进
- reminders / action items
- Gmail / Outlook / Slack / Calendar 等集成
- 模板和行业用例

## 二、和 Hermes / OpenClaw 的关系

共同点：

- 都是“替人处理日常工作”的智能体方向
- 都需要接入个人或企业账号
- 都需要长期学习用户风格和偏好

差别：

- Lindy 更产品化、商业化、面向办公场景
- OpenClaw / Hermes 更偏通用个人常驻智能体或开源运行时方向

## 三、适合场景

- 邮件
- 日程
- 会议
- 跟进提醒
- 销售和招聘流程

## 四、风险

- 邮箱和日历权限很敏感
- 自动回复和自动安排会议需要人工确认策略
- 企业使用要关注合规、审计和数据训练政策
