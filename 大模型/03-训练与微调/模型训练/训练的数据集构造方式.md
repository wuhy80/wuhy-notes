## 常见数据格式

### 1. Instruction 格式

```json
{
    "instruction": "任务指令描述",
    "input": "用户输入内容",
    "output": "期望的模型输出"
}
```

### 2. Chat 格式（推荐）

```json
{
    "messages": [
        {"role": "system", "content": "系统提示词"},
        {"role": "user", "content": "用户问题"},
        {"role": "assistant", "content": "助手回答"}
    ]
}
```

### 3. Completion 格式

```json
{
    "prompt": "输入提示",
    "completion": "期望的补全内容"
}
```

> [!tip] 数据质量建议
> - 确保数据格式一致性
> - 覆盖各种边界情况
> - 数据量建议：1000-10000 条高质量样本
> - 训练集/验证集/测试集比例：8:1:1
