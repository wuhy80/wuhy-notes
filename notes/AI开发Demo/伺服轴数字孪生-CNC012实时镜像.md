# 伺服轴数字孪生 · CNC-012 实时镜像

> [!summary] 一句话
> 把一台数控机床（CNC-012）做成可交互的孪生体：健康度、三轴负载、刀具寿命、24h 趋势、门联锁状态全在一个画面里，再用**六个环节**把「报警 → 分析 → 研判 → 工单 → 下发」的闭环演完。

- 文件：`assets/demo-twin.html`（758 KB，单文件、零依赖，双击即开）
- **在线版**：<https://wuhy-notes.pages.dev/static/demos/cnc-twin.html>

## 一、画面构成

| 区域 | 内容 |
| --- | --- |
| 左上 HUD | 健康度弧形仪表（HEALTH / 良好 / 平稳趋势）、主轴 X·Y·Z 三轴负载、刀具寿命 %、VB 磨损值 |
| 右上 HUD | 随环节切换的解说面板：`环节 01 · 全域感知` → `环节 06 · 审核下发` |
| 底部状态条 | 主轴运行 / 冷却开启 / 门联锁闭合 / 润滑偏低——四项固定，覆盖「能不能继续干」 |
| 24h 趋势条 | 历史负载可视化，用来回答「为什么现在报警」 |
| 报警层 | 异常时整屏边缘泛红 + 顶部 toast + 对应面板高亮，三处同时变 |
| 3D 场景 | Canvas 绘制的机床本体，`外罩：开/关` 可切换看内部结构 |

## 二、六个环节（它真正想讲的东西）

| # | 环节 | 在演什么 |
| --- | --- | --- |
| 01 | 监控大屏 · 全域感知 | 设备在干什么、健康度怎么样 |
| 02 | 异常报警 · 参数超标 | 哪一项越界了，越了多少 |
| 03 | 数字人分析 · AI 解析 | 可能的原因是什么 |
| 04 | 人工研判 · 人机协同 | 人确认或否决 AI 的结论 |
| 05 | 工单方案 · 智能处置 | 建议怎么修、要什么备件 |
| 06 | 审核下发 · 派工 | 谁在什么时候去修 |

`▶ 自动演示` 会按 01→06 自动走一轮；也可以点环节标签手动跳。

> [!tip] 演示时的讲法
> 别一上来讲架构。先说「这台机床健康度 86」，再触发报警，最后落到「从报警到派工单，中间没有一次手工抄表」——闭环是靠这条链路立住的，不是靠大屏好看。

## 三、可复用的做法

1. **环节式推进**：把「智能运维」拆成 6 个可点击环节，比一张塞满指标的大屏更能讲清闭环。
2. **报警要有物理位置**：边缘泛红 + toast + 面板高亮，三处同时变，观众才找得到变化点。
3. **状态条固定四项**：主轴 / 冷却 / 门联锁 / 润滑，不多不少，正好是「能不能继续加工」的最小集。
4. **数字孪生 ≠ 3D 模型**：真正起作用的是参数、状态、趋势与报警之间的对应关系；3D 只是承载。
