# 软著说明书制作指南

## 一、文档基本要求

### 格式要求
- **文件格式**：Word文档（.docx）
- **页数要求**：30-60页（含图）
- **字体要求**：
  - 标题：黑体，三号或小三
  - 正文：宋体，小四
  - 图片说明：宋体，五号
- **页边距**：上下左右各2.5cm
- **行间距**：1.5倍行距

### 截图要求
- **分辨率**：建议1920×1080或更高
- **完整性**：必须包含浏览器地址栏、窗口标题栏
- **清晰度**：文字清晰可读，不模糊
- **尺寸**：图片宽度建议14-16cm（适应A4纸）
- **格式**：PNG或JPG，文件大小控制在500KB以内

## 三、截图操作步骤

### 3.1 准备工作

1. **浏览器设置**
   - 使用Chrome或Edge浏览器
   - 窗口最大化（F11全屏模式）
   - 缩放比例设为100%
   - 清除浏览器缓存，确保界面最新

2. **系统准备**
   - 准备测试数据（列表页面要有3-5条示例数据）
   - 确保数据真实但不涉密
   - 用户名使用本机测试账号（凭据不写入本库）

3. **截图工具**
   - 推荐工具：
     - Windows：Snipping Tool（Win + Shift + S）
     - 微信截图（Alt + A）
     - QQ截图（Ctrl + Alt + A）
   - 保存格式：PNG

### 3.2 截图标准流程

**每个界面截图时，务必包含：**

1. ✅ 浏览器地址栏（显示系统URL）
2. ✅ 浏览器标签页标题
3. ✅ 系统顶部导航栏
4. ✅ 左侧菜单栏（如果有）
5. ✅ 主要功能区域（完整显示）
6. ✅ 底部分页或操作按钮（如果有）

**截图时避免：**

1. ❌ 截图不完整（缺少顶部或底部）
2. ❌ 鼠标悬停状态的提示框
3. ❌ 遮挡关键信息
4. ❌ 包含真实敏感数据（客户信息、真实姓名等）
5. ❌ 分辨率过低导致文字模糊

### 3.3 截图命名规范

建议按以下格式命名截图文件：

```
01-登录界面.png
02-系统首页.png
03-用户管理-列表.png
04-用户管理-新增.png
05-模块1-列表.png
06-模块1-新增.png
07-模块1-详情.png
08-模块2-列表.png
...
```

**插入图片的Word操作：**
1. 光标定位到要插入图片的位置
2. 插入 → 图片 → 来自文件
3. 选择对应的截图文件

5. 图片下方添加图片说明（居中，五号字）

### 4.3 格式调整

**标题格式：**
- 一级标题（章）：黑体，三号，加粗，段前段后0.5行
- 二级标题（节）：黑体，小三，加粗，段前段后0.5行
- 三级标题：黑体，四号，加粗

**正文格式：**
- 字体：宋体，小四
- 行距：1.5倍行距
- 段落：首行缩进2字符

**图片说明格式：**
- 字体：宋体，五号
- 对齐：居中
- 编号：图X-X [说明文字]

## 六、常见问题

### Q1：截图太多，文档页数超过60页怎么办？
**A**：
- 合并相似功能的截图说明
- 减少文字描述的篇幅（保持在每张截图200-300字）
- 选择最具代表性的功能模块展示
- 将次要功能模块一笔带过

### Q2：系统功能很少，凑不到30页怎么办？
**A**：
- 增加文字说明的详细程度
- 每个操作步骤都配详细说明
- 添加系统特点、技术架构说明
- 增加用户操作流程图（可用流程图工具绘制）

### Q3：某些界面包含敏感信息怎么办？
**A**：
- 使用马赛克或模糊工具遮盖敏感信息
- 或使用测试数据重新截图
- 姓名可用"张三"、"李四"等替代
- 手机号可用"138****1234"格式

### Q4：弹窗类界面如何截图？
**A**：
- 打开弹窗后，确保弹窗完整显示
- 截图范围应包含弹窗和半透明的背景层
- 如果弹窗很大，可以单独截取弹窗内容

### Q5：列表数据很长如何截图？
**A**：
- 不需要截取全部数据
- 截取顶部（查询条件+前3-5行数据）即可
- 或分两张截图：上半部分和下半部分
