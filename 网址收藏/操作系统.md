# 操作系统

## 课程与资料

- [操作系统：设计与实现（2024 春季学期）](https://jyywiki.cn/OS/2024/)：南京大学蒋炎岩的操作系统课程站点，含讲义、PPT 与实验，内容硬核
- [WikiChip](https://en.wikichip.org/wiki/WikiChip)：WikiChip 芯片百科，收录各代 CPU 微架构、制程与规格细节，查硬件参数用
- [Linux Memory Management](https://hemantra.medium.com/linux-memory-management-all-you-need-to-know-d1dbdda8b386)：Medium 上的一篇 Linux 内存管理长文，从虚拟内存讲到页表与回收机制

## 命令行工具

- [x-cmd 安装指南](https://cn.x-cmd.com/start/)：x-cmd 中文站，一条命令装好常用命令行工具集，免去逐个配置
