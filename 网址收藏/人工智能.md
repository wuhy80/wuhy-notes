# 人工智能

## 模型与聚合平台

- [OpenRouter](https://openrouter.ai/)：OpenRouter是一个可以提供免费AI API的网站，例如可以用在Obsidian Copilot上面，这样不需要付费就可以使用
- [HuggingFace](https://huggingface.co/)：AI聚合网站，各种大模型的聚集地

## AI 助手

- [OpenAI](https://chat.openai.com/)：响应速度很快，使用体验最好的AI
- [智谱清言 (chatglm.cn)](https://chatglm.cn/main/alltoolsdetail)：智谱AI推出新一代基座模型 GLM-4，使用体验较好，相对于ChatGPT而言略有差异，但是集成度很高
- [360智脑](https://chat.360.com/chat)：360的AI大模型，使用体验凑合，可以用
- [Kimi](https://kimi.moonshot.cn/)：Kimi是一个阅读文献的AI工具，可以提交各种文件帮忙辅助阅读
- [Gemini](https://gemini.google.com/)：Google 的 Gemini

## AI 搜索

- [360 AI搜索](https://www.sou.com/?src=360zn_index)：使用感受还行，用AI搜索比普通搜索的好处就是搜索的内容是直接可以用的，而不是要二次点击进去之后再查找
- [密塔AI搜索](https://metaso.cn/)：很好很强大，输出的格式比360 AI看起来更直观

## 订阅与比价

- [agentplans.fyi](https://agentplans.fyi/)：按预算找最划算的 AI 套餐
- [PriceAI](https://priceai.cc/)：AI 低价卡网订阅与中转 API 比价雷达
- [AI Coding Plan 平台评测与对比](https://vibecoding.dreamfree.space/)：各家 Coding Plan 横向对比工具
- [禾维 AI](https://hvoy.ai/)：检测 Claude / Gemini API 中转站的真假

## 评测与雷达

- [AI雷达 | 什么值得蹬](https://codexradar.com/#model-ratings)：Codex Radar 的模型评分榜，横向对比各家 AI 编程模型的能力与性价比
- [Artificial Analysis Intelligence Index](https://artificialanalysis.ai/evaluations/artificial-analysis-intelligence-index)：Artificial Analysis 的智能指数榜，按统一评测给出各模型综合能力排名，选型时看它
- [模型脉动 · LLM Pulse](https://wuhy80.github.io/llm-news-tracker/)：自己做的 LLM 新闻追踪页
- [AI产品狙击手（techgogogo）](https://www.techgogogo.com/)：Kevin Zhu 维护的中文 AI 工具与模型测评站，专注大语言模型、文生图与视频生成等**免费** AI 工具的分享。已积累 1600+ 篇文章，设有「AI工具严选」（200+ 免费工具）、「LLM评测」（自建 Benchmark 跑新模型）、「模型参数和价格」（各家模型规格与定价对照）、「系列合集」四个栏目，更新很勤。适合用来查新模型测评、找开源替代品和免费额度信息

## 聚合面板与社区
