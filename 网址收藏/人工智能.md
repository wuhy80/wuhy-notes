# 人工智能

## 模型与聚合平台

- [OpenRouter](https://openrouter.ai/)：OpenRouter是一个可以提供免费AI API的网站，例如可以用在Obsidian Copilot上面，这样不需要付费就可以使用
- [HuggingFace](https://huggingface.co/)：HuggingFace，全球最大的模型与数据集社区，找开源权重、看模型卡和在线 demo 都从这里开始

## AI 助手

- [OpenAI](https://chat.openai.com/)：ChatGPT 网页版，OpenAI 官方对话入口，需账号并代理访问
- [智谱清言 (chatglm.cn)](https://chatglm.cn/main/alltoolsdetail)：智谱AI推出新一代基座模型 GLM-4，使用体验较好，相对于ChatGPT而言略有差异，但是集成度很高
- [360智脑](https://chat.360.com/chat)：360 智脑，360 的对话大模型，可作备用入口
- [Kimi](https://kimi.moonshot.cn/)：Kimi是一个阅读文献的AI工具，可以提交各种文件帮忙辅助阅读
- [Gemini](https://gemini.google.com/)：Google 的 Gemini 对话入口，长上下文与多模态能力强，需 Google 账号并代理访问
- [ChatGPT](https://chatgpt.com/)：OpenAI 官方对话入口（新域名），写作、分析、学习与创意工作的通用助手，需账号并代理访问

## AI 搜索

- [360 AI搜索](https://www.sou.com/?src=360zn_index)：使用感受还行，用AI搜索比普通搜索的好处就是搜索的内容是直接可以用的，而不是要二次点击进去之后再查找
- [密塔AI搜索](https://metaso.cn/)：很好很强大，输出的格式比360 AI看起来更直观

## 订阅与比价

- [agentplans.fyi](https://agentplans.fyi/)：Agent Plans，按预算横向比较各家 AI 产品套餐与价格，挑订阅时先看它
- [PriceAI](https://priceai.cc/)：AI 低价卡网订阅与中转 API 比价雷达
- [AI Coding Plan 平台评测与对比](https://vibecoding.dreamfree.space/)：各家 Coding Plan 横向对比工具
- [禾维 AI](https://hvoy.ai/)：检测 Claude / Gemini API 中转站的真假

## 评测与雷达

- [AI雷达 | 什么值得蹬](https://codexradar.com/#model-ratings)：Codex Radar 的模型评分榜，横向对比各家 AI 编程模型的能力与性价比
- [Artificial Analysis Intelligence Index](https://artificialanalysis.ai/evaluations/artificial-analysis-intelligence-index)：Artificial Analysis 的智能指数榜，按统一评测给出各模型综合能力排名，选型时看它
- [模型脉动 · LLM Pulse](https://wuhy80.github.io/llm-news-tracker/)：自己做的 LLM 新闻追踪页，聚合各来源的大模型动态并按时间线呈现
- [AI产品狙击手（techgogogo）](https://www.techgogogo.com/)：Kevin Zhu 维护的中文 AI 工具与模型测评站，专注大语言模型、文生图与视频生成等**免费** AI 工具的分享。已积累 1600+ 篇文章，设有「AI工具严选」（200+ 免费工具）、「LLM评测」（自建 Benchmark 跑新模型）、「模型参数和价格」（各家模型规格与定价对照）、「系列合集」四个栏目，更新很勤。适合用来查新模型测评、找开源替代品和免费额度信息

## 聚合面板与社区

- [AIHub 仪表盘](https://aihub.top/dashboard)：AIHub 仪表盘，把多个 AI 服务聚合到一个面板里，省去逐个站点登录
- [LINUX DO](https://linux.do/tag/444-tag/444)：LINUX DO 的人工智能标签页，社区讨论偏 AI 工具、模型与本地部署实践，信息密度高
- [网址收藏](https://wuhy80.github.io/bookmarks/)：自己维护的公开书签站，把 网址收藏 整理成分类目录，便于分享给别人

## API 中转与镜像

- [江湖驿站 - AI API Gateway](https://api.ranmeng.icu/dashboard)：江湖驿站的 AI API 网关控制台，提供多家模型的 API 转发入口，便于统一管理渠道
- [Foxnio](https://www.foxnio.com/)：Foxnio，提供免费额度的 API 中转服务，适合先试用再决定
- [agentrouter](https://agentrouter.org/console/)：AgentRouter 控制台，与 AnyRouter 类似的公益中转站，提供免费 Claude Code 额度
- [DuckCoding](https://duckcoding.com/)：OpenAI 接口聚合管理，支持多渠道（含 Azure）分发 key
- [ikuncode](https://api.ikuncode.cc/console)：ikuncode 的接口聚合控制台，把多家模型渠道合并成一个 OpenAI 兼容入口
- [Privnode](https://privnode.com/)：以较低价格体验前沿 AI 与 Claude Code、Codex
- [Privnode Pro 控制台](https://pro.privnode.com/console)：Privnode Pro 版控制台，提供 Claude Code、Codex 等前沿模型的接入
- [EOS3 大模型 API 服务](https://platform.tokenfreeai.com/dashboard)：EOS3 大模型 API 服务平台的控制台，提供多家大模型的 API 接入
- [PackyCode](https://www.packycode.com/dashboard)：PackyCode，面向 AI 编程的助手服务控制台，可接入 Claude Code 等工具
- [88code](https://www.88code.org/)：88code，面向团队的 Claude Code 中转服务，提供稳定的 API 接入
- [aicodewith](https://aicodewith.com/dashboard)：AICodeWith，Claude Code API 镜像服务，面向编程场景的接入方案
- [GACCode](https://gaccode.com/)：付费的 Claude Code 站点，稳定性一般
- [AnyRouter](https://anyrouter.top/console)：免费提供 Claude Code 服务，每天有赠送额度
- [AICodeMirror](https://www.aicodemirror.com/dashboard)：AICodeMirror，Claude 模型共享平台，支持较新的模型版本
- [HVoy AI](https://www.hvoyai.com/)：检测 Claude / Gemini API 中转站的真假与可用性，并给出中转服务排行（与 hvoy.ai 同源）
- [RelayPulse](https://relaypulse.top/)：实时展示各 API 中转服务的可用性矩阵，挑中转站前先看它的在线状态
