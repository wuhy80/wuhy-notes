# 技术学习

## 通用网站

- [Hacker News (ycombinator.com)](https://news.ycombinator.com/news)：Hacker News，技术圈信息密度最高的社区之一，界面复古但评论区质量高
- [菜鸟工具 - 不止于工具](https://www.jyshare.com/)：为开发设计人员提供在线工具与网址导航，含 PHP、Python、CSS、JS 在线调试与中文简繁体转换、进制转换等
- [DeepWiki](https://deepwiki.com/)：Which repo would you like to understand?
- [Context7 - Up-to-date documentation for LLMs and AI code editors](https://context7.com/)：Generate context with up-to-date documentation for LLMs and AI code editors
- [iCraft Editor - 3D 架构图绘制工具](https://icraft.gantcloud.com/zh-CN)：免费的 3D 架构图设计工具，可绘制系统架构图、软件架构图、云架构图与网络拓扑图，支持 AWS、GCP、Azure、AliCloud（国际版 icraft.design）
- [Geek_log - 极客时间课程浏览](https://uucz.github.io/Geek_log/)：第三方做的极客时间课程浏览工具，可按专栏/作者检索课程目录，方便挑课
- [MDN Web Docs](https://developer.mozilla.org/zh-CN/)：Mozilla 维护的 Web 技术权威文档，HTML/CSS/JavaScript 与浏览器 API 的规范说明，查语法、兼容性和用法首选
- [Stack Overflow](https://stackoverflow.com/)：全球最大的程序员问答社区，遇到具体报错先在这里搜，高票答案通常带可运行代码
