# DSH插件

- [dsh-drawai（DrawAI）](https://github.com/fourzkw/dsh-drawai)：DeepSeek Harness（DSH）的右侧栏可编辑画布插件——流程图、架构图、分镜表支持「自然语言对话 + 手动拖拽」混合编辑，模型通过 `diagram_read` / `diagram_apply` 工具直接读写画布节点与连线（带 `expectRevision` 版本冲突保护）；还能把图片复刻成可编辑 SVG、视频抽帧复刻，以及用视频节点和时间轴（配乐、旁白、Freesound 音效）制作动效视频成片。npm 包同名，安装：`dsh plugin --profile desktop add dsh-drawai@0.4.1`（Web 版把 desktop 换成 web），MIT 协议，175 star；文生图暂未开放
