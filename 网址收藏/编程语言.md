## JavaScript

### Vue

#### 官方与基础

- [Vue.js](https://vuejs.org/)：Vue官方站点，基于Vue3版本
- [Vue.js 中文官方](https://cn.vuejs.org/guide/introduction.html)：Vue 3 官方中文文档的「介绍」章节，读官方指南从这里开始
- [Vue RFC](https://github.com/vuejs/rfcs/tree/master/active-rfcs)：Vue RFC是Vue3版本之后所有语法特性改动的提案材料
- [API 参考 | Vue.js](https://cn.vuejs.org/api/)：Vue API列表，基于Vue3版本的
- [LearnVue Vue 3 Cheatsheet (PDF)](https://learnvue.co/LearnVue-Vue-3-Cheatsheet.pdf)：约 4 页，总结了 Vue3 的常用命令
- [Vue 3 备忘清单](https://quickref.me/zh-CN/docs/vue.html)：在线版本的 Vue3 备忘清单
- [vitejs/awesome-vite](https://github.com/vitejs/awesome-vite)：Awesome Vite

#### 界面

- [Element-Plus](https://element-plus.org/zh-CN/component/overview.html)：基于 Vue3 实现的一套界面框架，这是其中文文档
- [vue-element-plus-admin](https://github.com/kailong321200875/vue-element-plus-admin)：Vue Element-Plus Admin 模板

#### 状态管理

- [Pinia](https://pinia.vuejs.org/zh/)：符合直觉的 Vue.js 状态管理库
- [Vuex](https://vuex.vuejs.org/zh/guide/)：专为 Vue.js 应用程序开发的状态管理模式 + 库
- [RxJS 中文文档](https://cn.rx.js.org/manual/overview.html)：通过 observable 序列编写异步和基于事件的程序

#### 登录与工具

- [JWT 在线解析](https://www.jstoolset.com/jwt)：Token 在线解析站点，方便验证 Token 是否正确
- [Unix 时间戳转换](https://tool.chinaz.com/tools/unixtime.aspx)：在线 Tick 与时间互转
