# 编程语言

## 综合速查

- [CheatSheets.zip](https://cheatsheets.zip/)：CheatSheets.zip，英文速查表合集，涵盖语言、框架、命令行与运维
- [Quick Reference](https://quickref.me/zh-CN/index.html)：QuickRef 速查表合集（中文），覆盖几十种语言与工具的常用语法

## Python

### Jupyter

- [Project Jupyter](https://jupyter.org/)：开源的交互式计算平台，JupyterLab 与 Notebook 在浏览器里即可写代码、看图表、记文档，支持 40 多种语言，数据科学与机器学习场景的标配工具

## Go

### 官方信息

- [Go Packages](https://pkg.go.dev/)：Go 官方的包文档站点，可搜索标准库、golang.org/x 与社区第三方包，查 API、读文档、看源码都从这里进，相当于 Go 生态的包检索中心

### 学习资源

- [avelino/awesome-go](https://github.com/avelino/awesome-go)：社区维护的 Go 生态资源精选清单，按分类收录框架、库与工具，star 数极高且持续维护，为 Go 项目选型找库时先翻这里

### Gin

- [生活处处有BUG - 腾讯云开发者社区](https://cloud.tencent.com/developer/column/96708?tag=13617)：腾讯云开发者社区的「生活处处有BUG」专栏，记录开发中的踩坑与排查过程

### GORM

- [GORM GitHub](https://github.com/go-gorm/gorm)：Go 生态最主流的 ORM 库仓库，支持全类型关联、Hook、事务、预加载与自动迁移，测试完善、文档齐全，Go 项目操作数据库的事实标准
- [GORM官方站点](https://gorm.io/index.html)：GORM的官方站点，自动Migrate，提供对多种数据库的映射

## Rust

### 官方信息

- [Rust Programming Language](https://www.rust-lang.org/)：Rust 官方站点，提供安装指南、The Book 教程与在线 Playground，还有命令行、WebAssembly、嵌入式等方向的学习资源，入门 Rust 从这里开始

### 学习资源

- [Awesome Rust](https://github.com/rust-unofficial/awesome-rust)：Awesome Rust，社区维护的 Rust 库、工具与学习资源大全，找 crate 时先翻这里
- [RustDesk](https://rustdesk.com/)：RustDesk是一个类似向日葵的远程控制软件，如果部署一个服务器再使用，性能会比较好一些

## JavaScript

### Vue

#### 官方与基础

- [Vue.js](https://vuejs.org/)：Vue 3 官方站点（英文），文档、API 参考与生态入口都在这里
- [Vue.js 中文官方](https://cn.vuejs.org/guide/introduction.html)：Vue 3 官方中文文档的「介绍」章节，读官方指南从这里开始
- [Vue RFC](https://github.com/vuejs/rfcs/tree/master/active-rfcs)：Vue RFC是Vue3版本之后所有语法特性改动的提案材料
- [API 参考 | Vue.js](https://cn.vuejs.org/api/)：Vue 3 官方中文 API 参考，查组合式 API 与内置组件用
- [LearnVue Vue 3 Cheatsheet (PDF)](https://learnvue.co/LearnVue-Vue-3-Cheatsheet.pdf)：Vue 3 速查表 PDF（约 4 页），把常用命令与写法浓缩成一张纸
- [Vue 3 备忘清单](https://quickref.me/zh-CN/docs/vue.html)：QuickRef 的 Vue 3 速查表（中文），常用 API 与写法一页看完
- [vitejs/awesome-vite](https://github.com/vitejs/awesome-vite)：Awesome Vite，社区整理的 Vite 插件、模板与工具清单，选型时按分类翻

#### 界面

- [Element-Plus](https://element-plus.org/zh-CN/component/overview.html)：基于 Vue 3 的桌面端 UI 组件库（Element UI 的 Vue 3 版），约 80 个组件覆盖表单、数据展示、导航与反馈，中文文档完善，Vue 3 后台界面常用它搭建
- [vue-element-plus-admin](https://github.com/kailong321200875/vue-element-plus-admin)：基于 Vue 3、Vite、TypeScript 与 Element Plus 的后台管理模板，内置动态路由、多套布局、国际化与主题切换，做中后台项目可直接二次开发

#### 状态管理

- [Pinia](https://pinia.vuejs.org/zh/)：Pinia 官方中文文档，Vue 3 推荐的状态管理库，API 比 Vuex 更简洁
- [Vuex](https://vuex.vuejs.org/zh/guide/)：Vue 官方的状态管理库，集中存放组件共享状态，变更须走 mutation、可追踪可调试，Vue 2 时代的主流方案，维护旧项目时仍会遇到
- [RxJS 中文文档](https://cn.rx.js.org/manual/overview.html)：RxJS 官方中文文档，用 Observable 序列组织异步与事件流，操作符丰富、声明式组合逻辑，堪称「处理事件的 Lodash」，复杂异步场景利器

#### 登录与工具

- [JWT 在线解析](https://www.jstoolset.com/jwt)：免费的 JWT 在线解码工具，无广告，粘贴 Token 即可查看 header 与 payload，还能把解码结果存进分享链接，调试登录态时很顺手
- [Unix 时间戳转换](https://tool.chinaz.com/tools/unixtime.aspx)：站长工具的时间戳转换，Unix 时间戳与日期互转，调试日志时间时常用

## TypeScript

- [TypeScript: JavaScript With Syntax For Types.](https://www.typescriptlang.org/)：TypeScript is JavaScript with syntax for types. 一个可以在线练习 TypeScript 的站点
- [基础类型 - TypeScript中文网](https://www.tslang.cn/docs/handbook/basic-types.html)：TypeScript 中文网的手册（基础类型章节），翻译版本偏旧但基础概念仍可用
