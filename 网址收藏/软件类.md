## 编辑器

### Obsidian

- [Obsidian中文帮助](https://publish.obsidian.md/help-zh/%E7%94%B1%E6%AD%A4%E5%BC%80%E5%A7%8B)：中文版本的Obsidian手册，看起来比英文的要快一些，但是内容没有那么快更新
- [Obsidian英文帮助](https://help.obsidian.md/Home)：Obsidian 官方帮助文档（英文），功能说明写得详细，是查用法最权威的来源
- [Obsidian文档咖啡豆版](https://obsidian.vip/zh/)：Obsidian文档和使用技巧，本站由Obsidian构建
- [Obsidian 中文论坛](https://forum-zh.obsidian.md/)：Obsidian 中文论坛，插件用法、同步方案与中文场景问题的问答集中地
- [Obsidian 社区周报（2024-04-08）](https://pkmer.cn/Pkmer-Docs/10-obsidian/obsidian%E7%A4%BE%E5%8C%BA%E5%91%A8%E6%8A%A5/2024-04-08-obsidian-weekly/)：PKMer 的 Obsidian 社区周报，汇总插件更新与用法技巧，比逐个看 release 省事
- [Obsidian+Dataview：私人图书馆解决方案](https://zhuanlan.zhihu.com/p/614286218)：知乎文章，用 Dataview 做书籍管理和知识系统
- [Just Vim It](https://vim.nauxscript.com/)：关于 VIM 和 VSCode 的使用技巧

### VS Code

- [通义灵码](https://tongyi.aliyun.com/lingma/download)：通义灵码，阿里出的 AI 编程插件，支持主流 IDE，国内可直接用

## 浏览器

### Chrome

- [极简插件](https://chrome.zzzmh.cn/index)：chrome插件的国内镜像，可以直接下载插件

## 设计与效率工具

- [Figma](https://www.figma.com/)：在线产品设计与原型工具，支持多人实时协作，国内访问需代理
- [Dribbble](https://dribbble.com/)：设计师作品社区，看 UI、视觉与交互灵感，找参考风格时翻
- [Notion](https://www.notion.so/)：把笔记、文档、数据库和项目管理整合在一起的工作空间，团队协作常用
- [Excalidraw](https://excalidraw.com/)：手绘风格的在线白板，画流程图和架构草图很快；Obsidian 也有同名插件
