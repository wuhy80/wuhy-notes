# 软件类

## 服务

### EMQX

- [EMQX 最新版本的官方文档](https://www.emqx.io/docs/zh/latest/)：EMQX 官方中文文档（最新 5.x），MQTT Broker 的部署、配置与运维参考

## 软件推荐

### 文件管理

- [追光几何Lite版 (evercraft.co)](https://tools.evercraft.co/)：文件历史管理工具「追光几何」的 Lite 在线版，帮你留存和管理文件的历史版本，功能简约、无学习门槛，适合怕文件改丢、想找回旧版本的场景

### 终端连接

- [Termius](https://www.termius.com/free-ssh-client-for-windows)：跨平台 SSH/SFTP 客户端，支持 SSH、Mosh、Telnet 与串口连接，多标签分屏、密钥托管与端到端加密云同步，Windows/Mac/手机通用，管多台服务器比 PuTTY 省心

## 编辑器

### Obsidian

- [Obsidian中文帮助](https://publish.obsidian.md/help-zh/%E7%94%B1%E6%AD%A4%E5%BC%80%E5%A7%8B)：中文版本的Obsidian手册，看起来比英文的要快一些，但是内容没有那么快更新
- [Obsidian英文帮助](https://help.obsidian.md/Home)：Obsidian 官方帮助文档（英文），功能说明写得详细，是查用法最权威的来源
- [Obsidian文档咖啡豆版](https://obsidian.vip/zh/)：Obsidian 爱好者维护的中文第三方文档站，覆盖入门教程、Markdown 语法与核心/社区插件讲解，含 Bases 专栏与最佳实践，中文用户入门进阶都合适
- [Obsidian 中文论坛](https://forum-zh.obsidian.md/)：Obsidian 中文论坛，插件用法、同步方案与中文场景问题的问答集中地
- [Obsidian 社区周报（2024-04-08）](https://pkmer.cn/Pkmer-Docs/10-obsidian/obsidian%E7%A4%BE%E5%8C%BA%E5%91%A8%E6%8A%A5/2024-04-08-obsidian-weekly/)：PKMer 的 Obsidian 社区周报，汇总插件更新与用法技巧，比逐个看 release 省事
- [Obsidian+Dataview：私人图书馆解决方案](https://zhuanlan.zhihu.com/p/614286218)：知乎上的一篇 Obsidian 实践文章，围绕 Dataview 插件展开，介绍如何用它做书籍管理和搭建个人知识系统，想用 Dataview 整理阅读记录可参考
- [Just Vim It](https://vim.nauxscript.com/)：56 天训练营式 Vim 入门教程，从基础键位讲到 VSCode、浏览器、终端里的 Vim 用法，循序渐进附练习节奏，想摆脱鼠标依赖可跟着练

### VS Code

- [通义灵码](https://tongyi.aliyun.com/lingma/download)：通义灵码，阿里出的 AI 编程插件，支持主流 IDE，国内可直接用

## 浏览器

### Chrome

- [极简插件](https://chrome.zzzmh.cn/index)：面向国内用户的 Chrome 扩展下载站，按分类收录广告拦截、翻译、开发工具等插件，附功能介绍与国内直连下载，装扩展不用翻应用商店

## 设计与效率工具

- [Figma](https://www.figma.com/)：在线产品设计与原型工具，支持多人实时协作，国内访问需代理
- [Dribbble](https://dribbble.com/)：设计师作品社区，看 UI、视觉与交互灵感，找参考风格时翻
- [Notion](https://www.notion.so/)：把笔记、文档、数据库和项目管理整合在一起的工作空间，团队协作常用
- [Excalidraw](https://excalidraw.com/)：手绘风格的在线白板，画流程图和架构草图很快；Obsidian 也有同名插件
