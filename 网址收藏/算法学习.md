# 算法学习

## 性能与可视化

- [Numbers Every Programmer Should Know By Year](https://colin-scott.github.io/personal_website/research/interactive_latency.html)：Latency Numbers Every Programmer Should Know，里面是不同时间点的常用性能数据，CPU Cache 性能等等
- [数据结构可视化交互动画版](https://www.totuma.cn/)：图码是一个数据结构和算法可视化交互动画网站，旨在创建一个可以直观地学习编程、数据结构和算法的平台，囊括国内计算机考研、期末考试、408数据结构和面试的常见算法题

## 基础资料

- [Graph Data Structures in JavaScript for Beginners](https://adrianmejia.com/data-structures-for-beginners-graphs-time-complexity-tutorial/)：In this post, we are going to explore non-linear data structures like graphs.
- [saadahmadabbasi/dsaJS](https://github.com/saadahmadabbasi/dsaJS?tab=readme-ov-file)：Data Structures and Algorithms explained and implemented in JavaScript，图文并茂，用JS实现的算法内容，可以研究

## 练习平台

- [GeeksforGeeks SDE Sheet](https://practice.geeksforgeeks.org/explore?page=1&curated%5B%5D=1&sortBy=submissions&curated_names%5B%5D=SDE%20Sheet)：按题单练习数据结构与算法

## 讲解与课程

- [结构之法，算法之道](https://blog.csdn.net/v_JULY_v?type=blog)：CSDN 上 July 的算法博客，经典面试题与算法专题文章，内容偏早但仍有参考价值
- [The Art of Programming](https://github.com/julycoding/The-Art-Of-Programming-By-July)：编程艺术系列，源自微软面试 100 题
- [代码随想录](https://programmercarl.com/)：代码随想录，按专题组织的刷题路线与题解，配视频讲解，适合系统过一遍算法
- [LeetCode Cookbook](https://books.halfrost.com/leetcode/)：halfrost 的 LeetCode 题解书，用 Go 语言实现并逐题分析，可对照自己的解法
- [LeetCode-Go](https://github.com/halfrost/LeetCode-Go)：Cookbook 的 GitHub 仓库
- [Play with Algorithms](https://github.com/liuyubobobo/Play-with-Algorithms)：算法与数据结构课程代码仓库
- [吴师兄学算法](https://www.cxyxiaowu.com/)：程序员小吴的算法图解站，用动画和图示讲解算法题，适合入门与复习
- [图解九大常见数据结构](https://cloud.tencent.com/developer/article/1634155)：腾讯云开发者社区的一篇算法/数据结构文章，具体内容以页面为准
- [菜鸟教程：数据结构与算法](https://www.runoob.com/data-structures/data-structures-tutorial.html)：排序、堆、搜索树、并查集和图论
- [Java 全栈知识体系：算法](https://pdai.tech/md/algorithm/alg-basic-overview.html)：pdai 技术栈的算法基础总览，把数据结构与算法知识点串成体系，当学习路线看
- [Data Structure Visualizations](https://www.cs.usfca.edu/~galles/visualization/Algorithms.html)：旧金山大学的算法可视化工具集，用动画演示排序、树、图等算法的执行过程，理解原理时很直观
- [7 Best Data Structure Courses](https://medium.com/javarevisited/7-best-courses-to-learn-data-structure-and-algorithms-d5379ae2588)：Medium 上「7 门最佳数据结构与算法课程」的推荐合集，选课时可当参考
- [GeeksforGeeks Data Structures](https://www.geeksforgeeks.org/data-structures/?ref=lbp)：GeeksforGeeks 的数据结构教程，每种结构配实现代码与复杂度分析，当速查手册用

## 精选站点

- [LintCode 炼码](https://www.lintcode.com/course/90/)：Powerful coding training system
- [labuladong 的算法笔记](https://labuladong.online/algo/)：致力于把算法讲清楚，提供完善的算法刷题解决方案
