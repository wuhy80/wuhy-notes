# 双语精读笔记生成模板（给 ZCode 的提示词）

> 用途：把一篇英文原文（URL 或粘贴文本）加工成本库标准的**双语精读笔记**。
> 产物必须通过 `node scripts/check-bilingual.mjs`（0 硬错误），否则不算完成。
> 存放位置：`英语学习/外刊看世界/`（时事外刊）或 `英语学习/文章荟萃/`（短篇阅读）。

## 提示词（直接发给 ZCode/DSH）

```text
请把下面的英文文章整理成本库标准格式的双语精读笔记，写入
「<目标目录>/<标题>：双语精读.md」。

输入：<URL 或粘贴的原文>

格式要求（必须严格遵守，发布管线有自动校验）：

1. frontmatter：tags 含「英语学习/外刊精读」、created（今日）、source（原文 URL）、
   status: 精读。
2. H1 标题：《原题》：双语精读。
3. 文首 `> [!abstract] 文章信息` callout：标题 / 作者 / 出处链接 / 背景一句话 /
   说明（注明"左栏原文、右栏译文逐段对照；各节之间附词汇注释，文末有总词汇表"）。
4. 正文按原文自然节分段，每节一个小节标题（## 中文小节名）。
5. 每节的正文用**两列表格**呈现：「| 原文 | 译文 |」——
   - 一行一个自然段（长段可拆，但左右必须一一对应，两侧都不能为空单元格）；
   - 译文要求信达雅，保留原文的口语化语气与修辞，不增不减；
   - 专有名词首次出现时在译文里括注英文。
6. 每节表格之后紧跟 `> [!note]- 词汇注释 · <节名>` 折叠 callout，5–8 条，条目两种形态：
   - 单词：`- **word** /IPA/ —— 中文释义。搭配或要点。`（**必须带 IPA**，用标准英式或美式音标）
   - 短语/搭配：`- *a phrase from the text* —— 中文说明。`（斜体短语，不需要 IPA）
   - 也可以有纯中文的说明行（如「本节不引入新词……」）。
   选词标准：对理解原文关键的、或对学习者有复用价值的词与短语；不收专有名词。
7. 文末 `## 总词汇表`：四列表格「| 词汇 | 音标 | 释义 | 文中语境 |」，汇总全篇 10–20 个
   最有复用价值的条目（音标缺失的写 —）。
8. 全文不要使用 Dataview 等插件代码块；不要改写原文任何一句话。

完成后运行 `node scripts/check-bilingual.mjs`，必须 0 硬错误后再提交。
```

## 质量要点（人工校对清单）

- [ ] 每行左右严格成对，无空单元格（校验器 E2 会拦）
- [ ] 单词条都带 IPA（校验器 W1 会提醒；词组不需要）
- [ ] 词汇注释里的释义不是逐词直译，有搭配或辨析增量
- [ ] 译文的语气与原文一致（口语的口语、书面的书面）
- [ ] 总词汇表条目与正文词汇注释不重复罗列错误内容（同词取最全释义）
